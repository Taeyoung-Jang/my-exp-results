# Android (product)

Android is a Linux‑based mobile operating system developed by **Google** and used on a wide range of smartphones and tablets.

## Key privacy‑related facts from [[summaries/session-07_2024-07-14]]
- **Location permissions**: Android lets users set each app to *while using the app* and choose between precise and approximate location. This aligns with the recommendation to keep location off by default and enable it only when needed.
- **Background activity restriction**: The conversation highlights the *Battery → Restricted* setting for individual apps as the primary way to limit background activity, reducing unwanted tracking and saving battery.
- **Background data control**: Turning off mobile data for an app blocks its background data usage, complementing the background‑activity restriction.
- **Ad personalization**: Users are advised to disable ad personalization in Google account settings to curb profiling.
