# Text‑to‑Speech (TTS) for Audio Learning

Text‑to‑Speech (TTS) is the process of turning written material—articles, PDFs, webpages, or scanned documents—into spoken audio.  In the context of personal knowledge work on an iPhone, TTS acts as a bridge that lets users consume information without staring at a screen, supporting strategies like [[concepts/active-listening]] and [[concepts/selective-note-taking]].

## Core Tools Mentioned
- **Voice Dream Reader** – a dedicated TTS app that handles a wide range of file types and offers high‑quality voices.  It is frequently recommended for long‑form listening. [[entities/voice-dream-reader]]
- **Apple Speak Screen** – the built‑in accessibility feature that reads any screen content aloud once activated in the Accessibility settings. [[entities/apple]]

Both tools can be used on an [[entities/iphone]] and integrated into a broader workflow.

## Workflow Integration
The summary of **session‑34** describes a practical pipeline where TTS highlights are sent to a single hub (Apple Notes) via a custom Shortcut.  The Shortcut (see [[concepts/shortcuts-workflow]]) appends highlighted text, timestamps, and optional audio snippets to an "Audio Inbox" note ([[entities/apple-notes]], [[entities/apple-shortcuts]]).  This enables users to:

1. **Read hands‑free** – listen to articles while walking or doing chores, reducing visual fatigue.
2. **Capture key moments** – use the share‑sheet to push a highlighted excerpt directly to the inbox.
3. **Review later** – open the note, enable Speak Screen, and let Siri read the collected text, or tap embedded audio files.

## Learning Benefits
- **Active Listening**: By pausing and restating ideas (a practice linked to [[concepts/active-listening]]), learners reinforce memory.
- **Purposeful Preview**: TTS allows quick skimming of content to decide if deeper study is worthwhile, aligning with a [[concepts/triage-rule]] approach.
- **Selective Note‑Taking**: Highlights can be exported as concise snippets, supporting [[concepts/selective-note-taking]] without clutter.
