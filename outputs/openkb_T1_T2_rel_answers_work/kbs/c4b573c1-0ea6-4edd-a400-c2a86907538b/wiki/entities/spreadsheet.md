# Spreadsheet (product)

**What it is**

A spreadsheet is a generic tabular software product (e.g., Microsoft Excel, Google Sheets) that allows users to organize data in rows and columns. In the context of [[summaries/session-38_2024-12-16]], it is the recommended platform for building a **lightweight dashboard** that surfaces priorities, handoff risks, and work health signals.

**Key facts from the session**
- Used to implement the [[concepts/lightweight-dashboard]] suggested for chaotic teams.
- Hosts a concise table with columns: Project, Owner, Collaborator, Priority, Phase, Next Handoff, Handoff Date, What’s Needed Next, Health.
- Supports the objective [[concepts/handoff-risk-management]] rules (green/yellow/red) and the definition of “no progress” (unchanged "What’s Needed Next" for seven days).
- Enables an async weekly review cadence: owners update their rows before a set time, then a short written summary is shared.
- Mentioned alongside [[entities/notion]] as an alternative low‑overhead tool for the same purpose.

**Why it matters**
The spreadsheet’s simplicity keeps the artifact lightweight—updates take about a minute—while still providing the visibility needed for effective [[concepts/team-alignment]]. It avoids the overhead of full‑featured project‑management tools, aligning with the session’s goal of minimal process addition.
