# MakeMKV

MakeMKV is a **product** that reads Blu‑ray and DVD discs and creates lossless digital copies in MKV format. It is frequently used as the first step in personal media‑library workflows that aim to balance convenience with true ownership.

## Key Facts from [[summaries/session-05_2024-06-15]]
- Recommended in the session as the primary **disc ripping** tool for Blu‑rays.
- Works alongside **HandBrake** for encoding the ripped files into more space‑efficient formats.
- Suitable for use on a low‑power computer such as an [[entities/intel_nuc]] or a small NAS.
- The resulting MKV files can be served via media‑server software like [[entities/plex]] or [[entities/jellyfin]] for streaming to TVs, phones, and tablets.

## Related Concepts
- [[concepts/disc_ripping]] – the broader practice of converting physical media into digital files for personal use.
- [[concepts/convenience_vs_ownership]] – the trade‑off discussed in the session between easy access and true ownership.

## Related Entities
- [[entities/handbrake]] – used after MakeMKV to re‑encode or compress the ripped video.
- [[entities/intel_nuc]] – a typical hardware platform for running MakeMKV and the media server.
- [[entities/plex]] and [[entities/jellyfin]] – media‑server applications that stream the MKV files produced by MakeMKV.

## Usage Tips
1. Insert the Blu‑ray or DVD and run MakeMKV to create an MKV file.
2. Optionally process the MKV with HandBrake for size reduction.
3. Store the file on a NAS or a mini‑PC and back it up regularly.
4. Add the file to Plex or Jellyfin for convenient home‑network streaming.
