# macOS

macOS is the operating system that runs on Apple’s Mac computers. In the context of personal data protection, macOS provides built‑in tools such as **Time Machine** for automated backups and **FileVault** for full‑disk encryption.

## Role in Backup Strategy

- Works with a **cloud‑backup** approach to keep files synced across devices.
- Supports an **external‑drive backup** workflow, where users can schedule periodic copies of their data.
- Encryption via FileVault ensures that an external drive remains secure, aligning with the recommended [[concepts/encryption]] practices.

## Key Features Mentioned in Session 11

- **Time Machine**: Recommended as a simple, versioned backup solution for macOS users.
- **FileVault**: Suggested for encrypting external drives to protect data if the drive is lost or stolen.
- Integration with a broader [[concepts/backup-strategy]] that combines cloud storage and local encrypted backups.
