# Summary of session-11_2025-07-14

**Main Idea**: For everyday users, a simple and reliable backup plan combines automatic [[concepts/cloud-backup]] with a periodically updated, encrypted external drive.

## Key Recommendations

1. **Combine cloud and local backup** – Cloud storage provides continuous, device‑agnostic protection, while an external drive offers an offline copy in case of sync errors, accidental deletions, or account issues.  
2. **Backup frequency** – Connect the external drive **once a month** for most users; power users may prefer a **weekly** cadence. See backup frequency for guidance.  
3. **Encryption** – Encrypt the external drive (e.g., macOS [[entities/filevault]], Windows [[entities/bitlocker]]) and store the password/recovery key safely. Encryption does **not** complicate restores as long as the key is available. [[concepts/encryption]]  
4. **Built‑in backup tools** –  
   * macOS: **[[entities/time-machine]]** works well for automatic, versioned backups.  
   * Windows: **[[entities/file-history]]** is sufficient for personal files; for full‑system images, the legacy **[[entities/backup-and-restore-windows-7]]** utility can be used.  
5. **Full system image** – Not required if the goal is merely to protect photos and documents. Cloud + encrypted drive covers the essential data; a system image is useful only for restoring the exact OS configuration and applications.

## Takeaway

A **3‑2‑1**‑style approach (three copies, two media types, one off‑site) can be achieved with **cloud storage + an encrypted external drive** updated monthly, using the operating system’s native backup utilities for ease of use.
