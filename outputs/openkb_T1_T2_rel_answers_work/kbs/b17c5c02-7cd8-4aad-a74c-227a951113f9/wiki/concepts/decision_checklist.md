# Decision Checklist

## Definition
A Decision Checklist is a lightweight, tabular framework that helps individuals objectively compare staying in their current residence versus moving by scoring and weighting relevant factors.

## Core Components
| Category | Weight | Stay Score | Stay Total | Move Score | Move Total |
|---|---|---|---|---|---|
| Money (rent + upfront costs) | 3 |   |   |   |   |
| Commute / time | 2 |   |   |   |   |
| Flexibility | 3 |   |   |   |   |
| Lifestyle fit / comfort | 2 |   |   |   |   |
| Stability / stress level | 2 |   |   |   |   |

- **Score (1‑5)**: 1 = poor fit, 5 = excellent fit.
- **Weight** reflects the importance of each category to the user.
- **Total** = Score × Weight; sum all totals for a final comparison.

## How to Use
1. **Identify categories** relevant to your housing decision (the template above provides a common set).
2. **Assign weights** based on personal priorities.
3. **Score each option** (stay vs. move) for every category.
4. **Calculate totals** and compare; the higher total suggests the more favorable option.

## Example (from [[summaries/session-32_2025-07-27]])
| Category | Weight | Stay Score | Stay Total | Move Score | Move Total |
|---|---|---|---|---|---|
| Money | 3 | 4 | 12 | 2 | 6 |
| Commute / time | 2 | 3 | 6 | 5 | 10 |
| Flexibility | 3 | 5 | 15 | 3 | 9 |
| Lifestyle fit | 2 | 3 | 6 | 4 | 8 |
| Stability | 2 | 4 | 8 | 3 | 6 |
**Total Stay** = 47, **Total Move** = 39.

## Benefits
- **Objectivity**: Reduces emotional bias by quantifying factors.
- **Flexibility**: Users can add, remove, or re‑weight categories.
- **Actionable**: Highlights which areas (e.g., cost, commute) most influence the decision.
