## Placeholders for Template Customization

**Definition**: A *placeholder* is a bracketed token (e.g., `[DAY]`, `[TIME]`, `[LOCATION]`) inserted into a reusable text template to mark spots where specific information will be filled in later. This technique lets a single draft serve many instances by simply swapping the placeholder values.

**Why use placeholders?**
- **Speed** – Users can paste the template and replace a handful of tokens instead of rewriting the whole message.
- **Consistency** – The surrounding wording, tone, and structure remain unchanged, ensuring uniform communication across multiple posts.
- **Flexibility** – Different events or details (date, time, parking, contact) can be accommodated without creating entirely new drafts.

**Key placeholders in the session‑15 draft**
| Placeholder | Intended content |
|-------------|-------------------|
| `[DAY]` | Day of the clean‑up (e.g., Saturday) |
| `[TIME]` | Start time (e.g., 9 a.m.) |
| `[LOCATION]` | Meeting spot (e.g., playground entrance on Oak Street) |
| `[PARKING INFO]` | Where volunteers can park |
| `[CONTACT NAME/NUMBER]` | Person to text for late arrivals |
| `[SIGN‑UP LINK]` | URL to the volunteer sign‑up sheet |

These tokens appear in both the short and longer versions of the [[concepts/volunteer-recruitment-message]] created for the [[entities/neighborhood-clean-up]] event, illustrating how placeholders streamline the production of clear, upbeat outreach messages.

**Relationship to other concepts**
- The placeholders support the overall **logistics** of the event, tying into [[concepts/community-event-logistics]] such as timing, location, parking, and contact details.
- By separating variable data from static copy, placeholders improve the reusability of volunteer recruitment templates.
