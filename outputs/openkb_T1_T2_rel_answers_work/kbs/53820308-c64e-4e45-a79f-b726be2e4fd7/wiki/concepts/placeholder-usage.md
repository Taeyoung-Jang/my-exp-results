# Placeholder Usage

**Definition**: Placeholder usage is the practice of inserting bracketed tokens (e.g., `[Name]`, `[Role]`, `[Contribution]`) in a text template so that the same copy can be quickly personalized for different individuals.

**Context in [[summaries/session-11_2023-05-24]]**: In the member‑spotlight draft, the assistant introduced these placeholders to let the user drop in their name, club role, and a specific contribution. This allowed rapid generation of multiple tone variants while keeping the core message stable.

**Benefits**
- Streamlines editing workflow.
- Reduces risk of inconsistent phrasing across versions.
- Makes it easy to generate copy for multiple recipients.

**Relation to other concepts**: Placeholder usage supports the creation of [[concepts/member-spotlight]] copy and works hand‑in‑hand with [[concepts/tone-variation]] by providing a stable skeleton that can be re‑worded for formal, professional‑casual, or casual tones.

**Best practices**
1. Use clear, descriptive token names inside square brackets.
2. Keep placeholders consistent across all versions of a template.
3. Document the intended replacement values next to the template for future editors.
