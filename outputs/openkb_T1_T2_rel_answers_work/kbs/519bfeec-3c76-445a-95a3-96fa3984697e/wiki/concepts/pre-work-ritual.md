# Pre‑Work Ritual

**Definition** – A pre‑work ritual is a brief, ordered sequence of low‑effort actions performed right before leaving for a shift. Its purpose is to automate essential preparations, reduce decision fatigue, and create a reliable launch point for the workday.

**Core Elements (from [[summaries/session-33_2025-08-15]])**
- **Fixed timing** – lunch packed at 4 p.m., coffee started just before departure.
- **Cue‑action pairs** – e.g., *start coffee maker* → *brew while you finish other steps*.
- **Essential sweep** – badge, keys, wallet, phone, **charger** checked in one motion.
- **Check‑off format** – a copy‑ready checkbox list suitable for a [[entities/notes-app]] or any task manager.

**Typical 10–15 minute checklist**
```
[ ] Pack lunch at 4 p.m. and put it in the same fridge spot
[ ] Start coffee maker
[ ] Place badge note on counter
[ ] Eat dinner
[ ] Check essentials: badge, keys, wallet, phone, charger
[ ] Grab lunch
[ ] Pour coffee into travel mug
[ ] Head out
```

**One‑minute fallback (minimum‑fallback)**
```
[ ] Grab badge
[ ] Grab lunch or quick backup snack
[ ] Grab bottled caffeine
[ ] Go
```

**Evening reset** – a short “reset” step after returning home to prime the next day’s ritual:
```
[ ] Put badge in its go‑spot
[ ] Wash containers or refill lunch snacks
[ ] Restock quick‑grab snacks if needed
```

**Why it works**
- **[[concepts/habit-anchoring]]** – the ritual anchors the end of the evening to the start of the night shift, creating a reliable mental cue.
- **[[concepts/habit-stacking]]** – each step builds on the previous one (e.g., packing lunch → starting coffee → checking essentials), forming a cascade that reinforces habit strength.
- **[[concepts/minimum-fallback]]** – the one‑minute version offers a minimal viable routine for days when time is scarce, ensuring the core needs (badge, fuel, caffeine) are still met.
- **[[concepts/night-shift-productivity]]** – for irregular schedules like a night shift at a [[entities/distribution-center]], a consistent pre‑work ritual mitigates the chaos of atypical hours.

**Related Tools & Items**
- **[[entities/coffee-maker]]** – pre‑set to start automatically.
- **[[entities/bottled-caffeine]]** – used in the fallback plan.
- **[[entities/travel-mug]]** – holds brewed coffee for the commute.
- **[[entities/notes-app]]** – stores the checklist for quick copy‑paste.

**Implementation Tips**
1. Keep the list under 10 items to stay within a 15‑minute window.
2. Store all high‑frequency items (badge, charger, coffee supplies) in a dedicated “go‑spot” near the door.
3. Review the checklist each night before bed to prime the habit (habit anchoring).
4. Periodically adjust the list to reflect changes in routine or work demands.
