# Habit Stacking

**Definition**: Habit stacking is the practice of linking several tiny, existing habits together in a fixed order so that each cue triggers the next action, creating a chain that runs on autopilot.

---

## How it works
1. **Select anchor habits** – Choose a few already‑stable actions (e.g., “start coffee maker”).
2. **Add a new micro‑habit** – Attach a new step immediately after each anchor (e.g., “place badge note”).
3. **Maintain order** – Perform the steps in the same sequence every time to reinforce the chain.
4. **Keep it short** – Each added habit should take no more than a minute to avoid overload.

---

## Example from [[summaries/session-33_2025-08-15]]
The night‑shift checklist demonstrates habit stacking:
- **Pack lunch at 4 p.m.** (anchor for later retrieval)
- **Start coffee maker** (triggered right after lunch prep)
- **Place badge note on counter** (paired with the brewing cue)
- **Eat dinner** (follow‑up after the note is set)
- **Check essentials** (badge, keys, wallet, phone, charger) – a concise audit that follows dinner.
- **Grab lunch** → **Pour coffee into travel mug** → **Head out**

Each step smoothly leads into the next, turning a potentially chaotic pre‑work scramble into a 10‑15‑minute flow.

---

## Benefits
- **Reduced decision fatigue** – The brain only needs to remember one sequence.
- **Increased consistency** – Fixed order creates a strong cue‑response loop.
- **Scalable** – New micro‑habits can be added once the existing stack feels automatic.
