## GitHub

**Type:** Product  
**Description:** GitHub is a web‑based platform that hosts Git repositories, enabling version control, collaboration, and code sharing.

**Key facts from [[summaries/session-01_2023-06-15]]**
- The assistant emphasizes polishing the **GitHub surface** as the first step for developers seeking jobs.
- Recommendations include pinning high‑impact repositories, improving README files, and updating the profile README.
- A checklist for README improvement aligns with [[concepts/readme-checklist-recruiters]].
- The scoring approach for selecting pinned repos follows the [[concepts/repo-scoring-rubric]].
- Overall guidance on making the GitHub presence recruiter‑friendly is captured in [[concepts/github-surface-polish]].

**Key facts from [[summaries/session-39_2025-06-15]]**
- GitHub can host *observable artifacts* such as sanitized case studies, short write‑ups, and small open‑source tools that serve as proof of work. [[concepts/observable-artifacts]]
- Public side projects on GitHub provide recruiters with measurable impact evidence (e.g., performance improvements, automation tools) without exposing proprietary code. [[concepts/measurable-impact]]
- Engineers are encouraged to create and share [[concepts/sanitized-case-studies]] on GitHub, using redacted screenshots or high‑level descriptions to demonstrate problem‑solving skills while protecting confidential information.
- Linking to these public artifacts on a résumé or LinkedIn profile is presented as a standard, recruiter‑friendly practice.
