# Summary of Session 07 (2024-06-15)

This document provides a comprehensive workflow for exporting high‑resolution 4K video projects while minimizing render time and system crashes. It covers best‑practice [[concepts/export-settings]], a reliable [[concepts/two-step-workflow]], and exact configuration checklists for both archival mezzanine masters and YouTube delivery.

## Key Concepts
- **Export Settings** – Match source resolution/frame rate, choose a codec balancing quality and speed (ProRes/DNxHR for mezzanine, H.264/H.265 for delivery).  
- **Mezzanine Master** – High‑quality intermediate file (MOV or MXF) using [[entities/prores]] 422/422 HQ or [[entities/dnxhr]] HQX, 10‑bit, 4:2:2, PCM audio. Enables fast, crash‑resistant renders.  
- **Two‑Step Workflow** – First export the mezzanine, then run a dedicated encoder for final delivery, separating creative rendering from heavy compression.  
- **Bitrate Optimization** – Use variable bitrate (VBR) with target/max ranges appropriate to codec (e.g., 40‑60 Mbps H.264, 20‑35 Mbps H.265).  
- **Container Choice** – MOV for archival mezzanine, MP4 for YouTube upload.  
- **Encoding Tweaks** – Enable 2‑pass (especially for H.264), keep CABAC on, set keyframe interval to ~2 seconds for streaming stability.

## Workflow Overview
1. **Prepare Proxy/Optimized Media** – Use lower‑resolution proxies during editing; switch to full‑res for final export.  
2. **Export Mezzanine Master** –  
   - Choose [[entities/prores]] 422 (macOS) or [[entities/dnxhr]] HQX (Windows).  
   - Settings: 3840×2160, 23.976 fps, 10‑bit, 4:2:2, PCM 48 kHz 24‑bit.  
   - Container: MOV (or MXF for DNxHR).  
3. **Second‑Pass Encode for YouTube** –  
   - H.265 (Main10) preferred: 28‑35 Mbps target, 40‑50 Mbps max.  
   - If H.264 required: High profile at Level 5.2, 50‑55 Mbps target, 75‑90 Mbps max, 2‑pass enabled.  
   - Audio: AAC 48 kHz 320 kbps, keyframe interval 2 s, CABAC on.  
   - Tools such as [[entities/adobe-media-encoder]], [[entities/handbrake]] or similar can be used.

## Copy‑Paste Checklists
- **Archival Mezzanine – ProRes**  
  - Container: MOV  
  - Codec: [[entities/prores]] 422 (or 422 HQ)  
  - Resolution: 3840×2160  
  - FPS: 23.976  
  - Bit depth: 10‑bit  
  - Chroma: 4:2:2  
  - Audio: PCM 48 kHz 24‑bit  
  - Keyframe: default  
  - 2‑pass: Off  
  - CABAC: N/A  

- **Archival Mezzanine – DNxHR**  
  - Container: MOV or MXF  
  - Codec: [[entities/dnxhr]] HQX  
  - Same video/audio specs as ProRes.  

- **YouTube – H.264**  
  - Container: MP4  
  - Codec: [[entities/h264]]  
  - Profile: High, Level: 5.2  
  - Resolution: 3840×2160  
  - FPS: 23.976  
  - Bit depth: 8‑bit, Chroma: 4:2:0  
  - VBR target: 50–55 Mbps, max: 75–90 Mbps  
  - Keyframe interval: 2 seconds  
  - 2‑pass: On (recommended)  
  - CABAC: On  
  - Audio: AAC 48 kHz 320 kbps  

- **YouTube – H.265** (recommended if allowed)  
  - Container: MP4  
  - Codec: [[entities/hevc]] (Main10)  
  - Resolution: 3840×2160  
  - FPS: 23.976  
  - Bit depth: 10‑bit, Chroma: 4:2:0  
  - VBR target: 28–35 Mbps, max: 40–50 Mbps  
  - Keyframe interval: 2 seconds  
  - 2‑pass: Optional  
  - CABAC: On (default in HEVC)  
  - Audio: AAC 48 kHz 320 kbps  

These guidelines help users with limited hardware achieve stable, high‑quality 4K exports and YouTube‑ready files without extensive trial‑and‑error.
