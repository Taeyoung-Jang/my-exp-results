## Focus Mode (iOS)

**What it is**
Focus Mode on [[entities/ios]] (often accessed via the Settings app on an [[entities/iphone]]) lets you create custom notification filters that allow only chosen contacts and apps to break through while silencing everything else. This capability is central to implementing a *Morning Quick Check* routine that balances staying reachable with reducing distraction.

**Why use it for mornings**
- Provides a clear, time‑boxed window for a quick scan of essential messages and calendar events.
- Acts as an [[concepts/attention-friction]] mechanism by removing visual and auditory cues from non‑essential apps.
- Supports a larger [[concepts/morning-routine]] and [[concepts/phone-free-productivity]] strategy by preventing the habit loop of endless scrolling.

**Key Settings (from [[summaries/session-39_2024-12-16]])**
1. **Create a new Focus**
   - Settings → Focus → **+** → *Morning Quick Check*.
2. **People**
   - Add only the contacts whose calls or messages you need immediately. This allows urgent communication through while silencing all other callers.
3. **Apps**
   - Enable *Messages* (and optionally *Calendar*) so texts and appointment reminders appear. Leave all other apps unchecked; this blocks, for example, Instagram DMs.
4. **Lock‑screen customisation**
   - *Hide Notification Previews* – prevents preview snippets from drawing attention.
   - *Customize* → choose a layout with **no widgets**.
   - *Dim Lock Screen* – reduces visual stimulation when the phone is first powered on.
5. **Schedule**
   - Set the Focus to turn on automatically at your wake‑up time and to run for about one hour. This automates the routine and removes the need to remember activation.

**How it fits into the routine**
- Treat the check like brushing teeth: a defined start (activating the Focus) and end (the Focus deactivates after the set duration).
- Place the phone out of arm’s reach (e.g., on a kitchen counter) to add physical [[concepts/attention-friction]] and reinforce the habit.
- After the quick check, move directly to the next morning activity (shower, coffee, etc.) to prevent the *just‑one‑more‑minute* temptation.
