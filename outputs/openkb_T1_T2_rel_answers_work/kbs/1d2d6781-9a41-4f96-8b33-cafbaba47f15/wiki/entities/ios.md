# iOS (product)

**iOS** is Apple’s proprietary mobile operating system that runs on the iPhone and iPad. It provides the underlying platform for features such as **Focus mode**, notification management, and lock‑screen customization.

## Key facts from [[summaries/session-39_2024-12-16]]
- The user asked for step‑by‑step instructions to create a **Morning Quick Check** Focus on an iPhone. The solution relies on iOS’s Focus settings to allow only selected contacts (e.g., via the **Messages** app) and to silence all other notifications.
- Specific iOS settings mentioned include:
  - Enabling **Do Not Disturb** / Focus with a custom allowed list of people.
  - Allowing the **Messages** app while blocking social apps like Instagram.
  - Hiding notification previews and removing lock‑screen widgets to reduce temptation.
  - Using the **Dim Lock Screen** option for a less stimulating visual experience.
- The guidance also suggests using iOS’s built‑in friction mechanisms (e.g., placing the phone out of arm’s reach) to support a healthier [[concepts/morning-routine]].

- iOS Focus modes can be scheduled to activate automatically at a chosen wake‑up time, providing a hands‑free way to enforce the quick‑check routine.
