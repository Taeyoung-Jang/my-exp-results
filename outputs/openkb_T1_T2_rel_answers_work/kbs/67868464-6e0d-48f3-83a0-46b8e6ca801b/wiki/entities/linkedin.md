# LinkedIn (organization)

## Overview
LinkedIn is a professional networking service that allows users to create online profiles, share résumés, and connect with recruiters.

## Relevance to session‑13_2022‑06‑15

- Suggested phrasing for permanent‑resident status to be added to a LinkedIn profile for U.S. software‑engineering roles.
- Emphasized that recruiters can see this note without it dominating the profile.
