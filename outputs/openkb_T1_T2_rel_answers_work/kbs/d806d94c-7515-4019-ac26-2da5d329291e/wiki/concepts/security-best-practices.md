# Security Best Practices

**Source:** [[summaries/session-38_2024-12-16]]

Security best practices outline how to keep both physical and digital records safe from damage, loss, and unauthorized access. The guidance in the source document focuses on a few core pillars:

## 1. Physical Security
- **Fire‑proof storage:** Keep items that must be retained forever (e.g., birth certificates, passports, titles) in a fire‑proof lockbox or small home safe.
- **Shredding bin:** Maintain a locked shredding bin for documents that are ready to be discarded. Immediate shredding prevents identity theft.

## 2. Digital Security
- **Encrypted cloud storage:** Scan important documents and store them in a reputable cloud service that provides automatic encryption at rest and in transit.
- **Password manager:** Use a password manager for all account logins rather than re‑using or writing down passwords.
- **Avoid unprotected copies:** Do not leave scans on an unencrypted desktop, in email attachments, or on unsecured external drives.

## 3. Access Controls
- **Role‑based access:** Grant access only to those who need it. For personal records, this usually means the account owner alone.
- **Two‑factor authentication (2FA):** Enable 2FA on cloud accounts to add a second verification layer.

## 4. Redundancy & Backup
- **Multiple locations:** Keep the original paper copies in a safe location and a digital backup in the cloud. Consider a secondary encrypted backup on an external drive stored off‑site.
- **Regular checks:** Perform a quick audit every few months to verify that backups are intact and that encryption keys/passwords are still accessible.

## 5. Integration with Document Management
- Security practices are tightly linked with [[concepts/document-organization]] and [[concepts/record-retention]]. A clear folder structure simplifies applying retention rules and ensures that only the necessary documents are stored in secure locations.

**Practical Checklist** (derived from the source):
1. Store forever‑type paper documents in a fire‑proof safe.
2. Scan and upload those documents to an encrypted cloud folder.
3. Use a password manager for all related account credentials.
4. Enable 2FA on the cloud storage service.
5. Keep a locked shredding bin for disposable papers.
6. Perform a quarterly security audit of both physical and digital repositories.
