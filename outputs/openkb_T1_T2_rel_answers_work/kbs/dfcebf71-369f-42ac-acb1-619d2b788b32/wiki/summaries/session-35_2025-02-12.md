# Summary of session-35_2025-02-12

**Date:** 2025-02-12  

## Core Goal
Provide a practical, low‑overhead system for a caregiver to manage calls, texts, and reminders on an [[entities/iphone]] without feeling overwhelmed.

## Key Recommendations
- **Contact grouping**: Create a “Mom – …” prefix for all care‑related contacts and place essential numbers in Favorites. See [[concepts/contact-naming-convention]] for the naming pattern.  
- **iPhone Focus mode**:  
  - Create a custom Focus (e.g., *Caregiving*) following [[concepts/focus-mode-setup]].  
  - Add allowed people: home‑health aide, doctor, pharmacy, etc.  
  - Enable **Allow Repeated Calls** to catch emergencies, as described in [[concepts/repeated-calls-emergency-handling]].  
  - Set a schedule or toggle via Control Center.  
- **Handling unknown medical numbers**: Save all clinic numbers under a single “Mom – Clinic” contact; rely on the repeated‑call allowance for any stray numbers.  
- **Text management**: Direct messages from allowed contacts come through; mute group chats (Hide Alerts) to silence bulk notifications.  
- **Reminder strategy**: One daily reminder for meds plus a second for time‑sensitive tasks; use voice entry for quick adds.

## Compact Checklist (copy‑paste for Notes)

### Clinic
- Main office number  
- Nurse/triage line  
- Appointment callback line  
- After‑hours line  
- Lab/results line  

**Naming:** `Mom – Clinic Main`, `Mom – Clinic Nurse`, `Mom – Clinic Callback`, `Mom – Clinic After Hours`, `Mom – Clinic Lab` (link to [[entities/clinic]] for reference).

### Pharmacy
- Main line  
- Refill/automated line  
- Text‑callback (if any)  

**Naming:** `Mom – Pharmacy Main`, `Mom – Pharmacy Refill`, `Mom – Pharmacy Text` (link to [[entities/pharmacy]]).

### Home Health Agency
- Main office  
- Scheduler/coordinator  
- On‑call nurse (after hours)  

**Naming:** `Mom – Home Health Main`, `Mom – Home Health Scheduler`, `Mom – Home Health On‑Call` (link to [[entities/home-health-agency]]).

### Emergency / Local
- Hospital main line  
- ER desk/nurse station  
- Non‑emergency police line  

**Naming:** `Mom – Hospital Main`, `Mom – Hospital ER`, `Local – Police Non‑Emergency` (links to [[entities/hospital]] and [[entities/non-emergency-police]]).

### Family (urgent only)
- Save only the few who need real‑time updates with the `Mom – [Name]` format.

## Ask Script for Clinics & Agencies
```
Hi, I’m caregiving for my mother and trying to make sure I don’t miss important calls. Could you tell me all the numbers you use to contact patients—your main line, nurse or triage line, any callback or automated lines, and the after‑hours number? I’d like to save them all under one contact.
```
