# Focus Mode Setup

## Overview
Focus Mode Setup refers to the step‑by‑step configuration of the **iPhone Focus** feature so that a caregiver can filter calls, messages, and notifications, letting through only the most urgent contacts while silencing everything else. The goal is to reduce cognitive overload during caregiving periods.

## Core Elements (from [[summaries/session-35_2025-02-12]])
1. **Create a custom Focus** – e.g., name it *Caregiving*.
2. **Allowed People** – Add the home‑health aide, doctor, pharmacy, and any other essential contacts. Use a clear naming scheme such as `Mom – Clinic Nurse` to make the allowed list obvious.
3. **Repeated Calls** – Enable the *Allow Repeated Calls* toggle so that a second call within three minutes bypasses the filter, providing an emergency fallback. This aligns with the [[concepts/repeated-calls-emergency-handling]] concept.
4. **Notification Silencing** – Set *Silence Notifications* to *From silenced people* so that only allowed contacts can break through.
5. **Scheduling** – Optionally schedule the Focus to activate automatically during evenings or overnight, or toggle it manually from the Control Center.
6. **Device Context** – The steps apply to [[entities/ios]] devices, specifically the [[entities/iphone]].

## Practical Tips
- **Group Contacts**: Store all clinic numbers under a single contact (e.g., *Mom – Clinic*) to simplify the allowed list. This complements the [[concepts/contact-naming-convention]] concept.
- **Emergency Handling**: Rely on the repeated‑calls feature for unexpected medical numbers that aren’t saved.
- **Testing**: After setup, place a test call from an allowed and a non‑allowed number to confirm behavior.
