# Communication Preferences

**Definition**: A set of practices that specify how, when, and through which channels a person prefers to be contacted, balancing responsiveness with deep‑work focus.

## Core Elements

- **Preferred Channels**: Use Slack for routine, non‑urgent communication; reserve text or call for truly urgent matters.
- **Timing**: Indicate periods of high availability (e.g., mornings, lunchtime) and protected focus windows (e.g., 2–5 pm) where interruptions are minimized.
- **Response Expectations**: Set clear expectations such as “Slack messages will be answered after 5 pm” to manage teammate expectations.
- **Meeting Guidance**: Request that meetings be avoided during focus windows unless essential, framing it as a preference rather than a rule.

## Example from [[summaries/session-39_2024-12-07]]

The source document provides a concise three‑line casual message that illustrates communication preferences:

> *“Hey all, just a heads‑up that I’m easiest to reach in the morning or around lunch. I’m usually in deep‑work mode from 2–5, so I’d appreciate keeping meetings out of that window when possible. If you ping me on Slack I’ll get back to you after 5, and text or call only for anything truly urgent.”*

Key points extracted:
- **Channel hierarchy**: Slack first, then text/call for emergencies.
- **Availability windows**: Morning and lunch are high‑response periods; afternoons are focus zones.
- **Tone**: Friendly, preference‑based language rather than strict mandates.
