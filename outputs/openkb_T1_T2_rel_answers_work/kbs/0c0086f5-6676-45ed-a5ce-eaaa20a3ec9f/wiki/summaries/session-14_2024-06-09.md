# Session 14 – Daily Routine Design (2024-06-09)

## Main Advice
- Treat the day as **zones**: deep‑focus block, communication windows, meeting cluster, and buffer.  
- Protect 8‑11 am for uninterrupted deep work.  
- Use short email/message check‑ins (≈10‑15 min) after the focus block and before the day ends.  
- Batch similar tasks and group meetings together to minimize context switching.  
- Include a brief buffer at the end of the day for wrap‑up and planning.  

## Handling Urgent Pings
- During the 8‑11 focus window, allow a **quick glance** at the top of each hour (≤30 s) only for true emergencies.  

## Example Schedule (base)
| Time | Activity |
|------|----------|
| 08:00‑11:00 | Deep focus work |
| 11:00‑11:15 | Email / message check‑in |
| 11:30‑12:30 | Meeting 1 |
| 12:30‑13:00 | Lunch |
| 13:00‑15:30 | Meeting 2‑3 (cluster) |
| 15:30‑16:30 | Light solo work |
| 16:30‑16:45 | Second email / message check‑in |
| 16:45‑17:00 | Buffer / planning |

## Day‑type Variations
### Meeting‑heavy day (3+ meetings)
- Same focus block.  
- Emergency glance each hour.  
- Meetings from 11:30 to 15:30 continuously.  
- Light solo work and buffer after 15:30.  

### Maker day (0‑1 meeting)
- Focus block + quick emergency glance.  
- Long solo block 11:30‑13:00.  
- One meeting around 13:30.  
- Extended solo work 14:30‑16:30.  
- End‑day check‑in and cooldown.
