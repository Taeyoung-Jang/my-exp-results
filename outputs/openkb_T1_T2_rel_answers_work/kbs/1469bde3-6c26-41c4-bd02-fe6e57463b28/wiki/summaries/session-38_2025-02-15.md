# Summary of session-38_2025-02-15

**Goal**: Provide a reproducible workflow to keep a Windows 11 Home laptop and an iPhone stable during the workweek while still receiving essential security updates.

## Key Recommendations

1. **Windows 11 (Home)**
   - Set **Active Hours** to block installations/reboots during work time — see [[concepts/windows-active-hours]].
   - Use **Pause updates** (up to 1 week) for short crunch periods.
   - Since true **feature‑update deferral** is unavailable on Home, simply avoid clicking **Download and install** on feature‑update banners.
   - Turn off **Get the latest updates as soon as they’re available** (if present) via *Settings → Windows Update → Advanced options*.
   - Skip any **Optional/Preview** updates and driver updates unless needed.
   - Disable **Microsoft Store** auto‑updates (Store → Profile → App Settings) – see [[entities/microsoft-store]].

2. **iPhone (iOS)**
   - Navigate to *Settings → General → Software Update → Automatic Updates*.
   - Turn off **Install iOS Updates**; you may keep **Download iOS Updates** on – the phone will pre‑download but not install or restart.
   - Keep **Security Responses & System Files** enabled (or manually install) to stay protected – see [[concepts/ios-automatic-updates]].
   - Disable **App Store** automatic app updates (Settings → App Store → Automatic Downloads → App Updates) – see [[entities/iphone]] and [[entities/ios]].

3. **Weekend Update Routine**
   - Restart devices.
   - On Windows: run *Windows Update* → install all pending patches, then update Microsoft Store apps manually.
   - On iPhone: install any pending iOS updates, then run *App Store → Updates*.
   - Perform a final restart if major updates were applied.

## Gotchas & Risks

- Turning off all automation can lead to **security‑patch drift** if the weekly routine is missed.
- Missing the **Get the latest updates…** toggle (common on some Home builds) means relying on the manual avoidance of feature‑update prompts.
- Pre‑downloaded iOS updates occupy storage but do not cause unexpected restarts.
