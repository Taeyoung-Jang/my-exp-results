# Windows Update

**Type:** Product

Windows Update is Microsoft’s built‑in service for delivering operating‑system patches, security fixes, driver updates, and optional feature upgrades to Windows devices, notably Windows 11 Home and Pro.

## Key facts from [[summaries/session-38_2025-02-15]]
- Provides **Active Hours** to prevent installations and reboots during designated work periods.  See [[concepts/windows-active-hours]].
- Allows users to **Pause updates** for up to one week, useful during deadline crunches.
- On Windows 11 Home, true **feature‑update deferral** is unavailable; the practical approach is to avoid clicking the “Download and install” button for feature updates.
- The **Advanced options** page may expose a toggle named “Get the latest updates as soon as they’re available”; if missing, users must manually ignore preview/optional updates.
- **Optional/preview updates** and driver updates appear under an “Optional updates” section and are skipped unless manually selected.
- Interacts with the **Microsoft Store**; disabling Store auto‑updates prevents surprise app changes.
