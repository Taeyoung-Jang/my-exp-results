# Time Machine

Time Machine is a backup utility built into macOS that automatically creates incremental snapshots of the entire system, enabling easy restoration of files, folders, or the whole machine.

## Key facts from [[summaries/session-02_2024-06-15]]
- **Role in beta‑testing workflow**: Recommended in the checklist for backing up a laptop before installing beta updates.
- **Verification step**: Users are advised to check timestamps, confirm the backup file exists, and open the restore interface to ensure the backup is valid.
- **Rollback support**: In case a beta update fails, Time Machine provides a straightforward path to revert the system to a pre‑beta state, often within an hour.
