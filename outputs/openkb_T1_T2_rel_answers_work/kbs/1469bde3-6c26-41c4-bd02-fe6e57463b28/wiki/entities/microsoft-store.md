# Microsoft Store (product)

Microsoft Store is the official app marketplace bundled with **Windows 11**, provided by [[entities/microsoft]]. It delivers desktop apps, games, and utilities, and can be configured to control automatic updates.

## Relevance in session-38_2025-02-15
- The user is advised to **disable automatic app updates** in the Store to avoid mid‑week surprises.  
  Path: *Microsoft Store → Profile (icon) → App Settings → Automatic app updates* → Off.
- Disabling this aligns with a broader **[[concepts/software-update-strategy]]** that favors manual, weekend‑only updates.
- The recommendation complements the use of **[[concepts/windows-active-hours]]** and [[entities/windows-update]] to keep system patches predictable while postponing optional or preview updates.
- The page is referenced in the summary [[summaries/session-38_2025-02-15]].

## Typical Settings
| Setting | Recommended value |
|---------|-------------------|
| Automatic app updates | Off |
| Install optional (preview) updates | Manual selection only |
| Driver updates | Manual (via Optional updates) |

By turning off Store auto‑updates, the user can synchronize app refreshes with their weekly **[[concepts/software-update-strategy]]** routine, reducing unexpected UI changes while still receiving critical security patches through Windows Update.
