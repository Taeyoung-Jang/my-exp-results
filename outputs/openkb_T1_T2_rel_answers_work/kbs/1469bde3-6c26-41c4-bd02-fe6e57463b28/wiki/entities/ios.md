# iOS

**Type**: Mobile operating system (product) developed by [[entities/apple]].

**Primary devices**: Runs on [[entities/iphone]] and iPad hardware.

## Update Management (as discussed in [[summaries/session-38_2025-02-15]])

- **Automatic update controls** are found under *Settings → General → Software Update → Automatic Updates*.
- The **"Install iOS Updates"** toggle can be turned off to prevent the OS from installing major releases automatically.  Leaving **"Download iOS Updates"** enabled will pre‑download the update but will not install or restart the device mid‑week.
- **Security Responses & System Files** can be kept on (or manually installed) to receive critical security patches without a full OS upgrade.
- Disabling automatic iOS upgrades helps maintain a stable environment during work periods while still allowing a manual **weekend update routine**.
