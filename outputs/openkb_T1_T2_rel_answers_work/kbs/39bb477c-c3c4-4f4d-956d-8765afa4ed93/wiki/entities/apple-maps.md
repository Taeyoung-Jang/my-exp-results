# Apple Maps (product)

Apple Maps is the built‑in navigation and mapping application on iOS, tightly integrated with the operating system and services like [[entities/icloud]].  In the "minimal iPhone" advice from [[summaries/session-33_2025-02-14]], it is listed as one of the core native apps that should remain installed because its native implementation offers smoother performance, reliable location services, and better integration with other system apps compared to its web counterpart.

## Key facts from Session 33 (2025‑02‑14)
- **Core app recommendation**: Included in the suggested list of ~10‑15 essential apps for a "browser‑first phone" strategy.
- **Reason to keep native**: Provides tighter integration with iOS location permissions and background‑activity handling, which are important for low‑maintenance usage.
- **Related settings**: Users are advised to set its location permission to "While Using the App" under iOS Settings → Privacy → Location Services.
