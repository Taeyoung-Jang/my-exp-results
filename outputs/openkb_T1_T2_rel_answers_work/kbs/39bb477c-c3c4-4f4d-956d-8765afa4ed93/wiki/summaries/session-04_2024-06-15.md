# Summary of session-04_2024-06-15

**Date:** 2024‑06‑15

## Core Idea
A practical method for decluttering a smartphone by evaluating each app against a weighted scorecard, selecting a single “best” app per functional category, and arranging a minimal‑folder home‑screen layout for [[entities/iphone]].

## Scorecard Template
| Criterion | Weight | Scoring (0‑10) |
|---|---|---|
| Essential function fit | 0.30 | |
| Speed & ease of use | 0.20 | |
| Reliability & sync | 0.20 | |
| Focus & lack of clutter | 0.15 | |
| Trust & longevity | 0.15 | |

- **Total score** is the weighted sum (max 100). Keep the app that scores **≥ 70**.

## Category‑Specific Must‑Haves
- **Notes:** fast capture, reliable search, offline access, effortless organization.
- **Tasks:** quick entry, reminders, recurring tasks, flexible views, dependable alerts.
- **Calendar:** clean layout, easy event creation, month/week views, reliable sync.
- **Email:** fast inbox, good filtering, dependable notifications, simple compose.
- **Files:** iCloud integration, offline access, clear folder navigation.
- **Passwords:** zero‑knowledge encryption, autofill, secure sync, strong generator.
- **Scanning:** quick capture, auto‑crop, accurate OCR, export to Files/Notes.
- **Budgeting:** overview, easy transaction entry, recurring categories, export options.

## Home‑Screen Layout (iPhone)
- **Dock:** Phone, Messages, Browser, Main productivity hub (e.g., Notes or Tasks).
- **First Screen:** 3‑4 top‑used apps (no folders) for instant access.
- **Folders (2‑3 total):**
  1. **Work Essentials** – apps used for professional tasks.
  2. **Personal / Admin** – finance, health, utilities.
  3. **Occasional Utilities** – scanning, budgeting, etc.

This structure keeps the most‑used tools front‑and‑center while grouping the rest into a few broad containers, reducing visual clutter while respecting a one‑app‑per‑category rule.
