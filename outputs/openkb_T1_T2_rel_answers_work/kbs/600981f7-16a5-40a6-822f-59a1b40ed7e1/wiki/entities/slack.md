# Slack (product)

Slack is a cloud‑based collaboration tool that provides real‑time messaging, file sharing, and integration with other work applications. It is widely used by teams to coordinate, discuss, and share updates.

## Role in [[summaries/session-12_2025-05-18]]
In the *session‑12* conversation, Slack is referenced as the medium for boundary‑script messages that help the user protect focus time during migration work. Two scripts were provided:
- A non‑urgent script to politely defer replies.
- An urgent‑triage script to allow quick issue assessment.
These scripts support the user's [[concepts/time-blocking]] strategy by managing interruptions.
