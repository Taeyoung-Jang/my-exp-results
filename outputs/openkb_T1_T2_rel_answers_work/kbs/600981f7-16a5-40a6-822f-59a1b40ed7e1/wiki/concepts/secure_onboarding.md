# Secure Onboarding

**Definition**: A structured approach for new employees to set up personal security hygiene—password management, multi‑factor authentication, device updates, and basic configuration—immediately after receiving their hardware, while staying within default organizational policies.

## Core Elements (derived from [[summaries/session-31_2025-06-08]])
1. **Password manager activation** – Install and add all work credentials to a reputable manager before the first workday.
2. **Multi‑factor authentication (MFA)** – Enable MFA on every supported account and verify log‑in success to avoid lock‑outs.
3. **System updates & device hardening** – Apply required OS/firmware updates, set screen‑lock timeouts, and ensure encryption is enabled.
4. **Basic communication setup** – Configure email signature and log into collaboration tools such as Microsoft Teams and Slack so the new hire is reachable on day one.

## What to Defer Until After Manager/IT Alignment
- Custom email filtering rules
- VPN or network configuration changes
- Installation of non‑mandatory software
- Re‑organization of shared‑drive structures
- Adjustments to enterprise security policies or group policies

## Benefits
- Reduces risk of early account lock‑outs.
- Shows professionalism without overstepping IT boundaries.
- Provides a reliable, low‑maintenance foundation for productivity from day one.
