# Efficient Task Prioritization

**Type:** Concept

**Description:** A systematic approach to sequence high‑impact, low‑risk actions when time is constrained, ensuring core readiness while avoiding premature policy‑dependent changes.

## Core Principles
1. **Identify blockers** – tasks that, if incomplete, will prevent you from working on day 1 (e.g., password manager setup, MFA, system updates).
2. **Prioritize by impact** – rank actions by how much they reduce risk of lock‑outs or productivity loss.
3. **Defer policy‑sensitive changes** – postpone any configuration that may conflict with IT or team standards until you receive guidance.
4. **Time‑box execution** – allocate a fixed short window (e.g., one hour) and complete the highest‑impact items first.

## Practical Application (from [[summaries/session-31_2025-06-08]])
- **High‑impact, safe to do tonight**
  - Install/configure a **password manager** and add all work credentials.
  - Enable **multi‑factor authentication (MFA)** on every supported account.
  - Apply required **system updates** and reboot if needed.
  - Set device security defaults (screen‑lock timeout, encryption).
  - Verify email send/receive and add a simple professional signature.
  - Log in to collaboration tools such as **[[entities/microsoft-teams]]** or **[[entities/slack]]** to be reachable.
- **Defer until after manager/IT meeting**
  - Creating complex email rules.
  - Modifying VPN, network, or proxy settings.
  - Installing non‑essential software.
  - Re‑organising shared‑drive structures.
  - Adjusting advanced device or security policies.

## Relationship to Other Concepts
- Supports [[concepts/first_day_impression]] by enabling a low‑profile, prepared presence.
- Aligns with [[concepts/secure_onboarding]] by establishing personal security hygiene early.

## How to Use This Concept
1. **List** all potential setup actions.
2. **Score** each by impact (e.g., prevent lock‑out) and risk (policy violation).
3. **Select** the top‑scoring items that can be completed within your available time.
4. **Execute** them sequentially, confirming success after each step.
5. **Document** any deferred items to revisit after your introductory meetings.

By following this efficient task prioritization framework, new employees can maximize readiness for day 1 while respecting organizational boundaries.
