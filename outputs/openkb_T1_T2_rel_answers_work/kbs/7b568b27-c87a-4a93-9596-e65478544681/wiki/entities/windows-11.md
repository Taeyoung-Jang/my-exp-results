# Windows 11

**Type:** product

**Description:** Microsoft’s modern desktop operating system released in 2021, supporting a range of built‑in backup and file‑management tools.

## Role in session‑11_2025‑06‑15
The document uses Windows 11 as the target platform for a **local‑only file organization** strategy. Specific Windows 11 utilities are recommended:
- **File History** for continuous versioned backups (see [[entities/file-history]]).
- **Backup and Restore (Windows 7)** for creating periodic system images (see [[entities/windows-backup-restore]]).

These tools are combined into a **two‑layer backup** approach that emphasizes redundancy and offline protection (see [[concepts/two-layer-backup]] and [[concepts/versioning]]).
