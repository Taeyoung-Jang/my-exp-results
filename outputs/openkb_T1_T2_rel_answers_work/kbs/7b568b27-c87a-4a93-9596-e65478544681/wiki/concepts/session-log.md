# Session Log

A **session log** is a concise, date‑stamped note that acts as a bookmark for your workflow. It records what you finished, what remains in progress, the first action you need to take next time, and any relevant blockers or observations. The purpose is to minimise re‑orientation time when switching devices or returning after a break.

---

## Core Template
```
Session Log
- Date: 
- What I completed: 
- What’s in progress: 
- What I need to do first next time: 
- Any notes or blockers: 
```

## How to Use It
1. **Create a single, cloud‑synced note** (e.g., in Google Keep, Notion, or any web‑based notes app) titled *Session Log*.
2. **Add an entry at the end of each work session** using the template above.
3. **Review the previous entry** before starting a new session to quickly recall context.
4. **Keep the log lightweight** – a few short lines are enough; avoid long narratives.

## Benefits
- **Fast re‑orientation** – you see at a glance what you were doing and what to pick up next.
- **Device‑agnostic continuity** – because the note lives in the cloud, any device can access it.
- **Reduced cognitive load** – externalising the “what’s next” reduces mental overhead.
- **Supports security‑focused workflows** on shared machines by providing a quick, temporary record that can be cleared with the browser cache if needed.

---

## Best Practices for Public / Library Computers
- Use a **private/incognito window** when opening the cloud‑synced note.
- **Sign out** of the notes service before leaving the machine.
- **Clear browser data** (history, cookies, cache) after the session.
- Do not download the log locally; keep it fully online.
