# Security Hygiene

Security Hygiene refers to systematic steps that protect personal information and leave no trace when using shared or public computers. It builds on the workflow strategies described in [[summaries/session-34_2025-09-15]] and complements concepts like [[concepts/cloud-sync]] and [[concepts/session-log]].

## Core Practices

- **Use private/incognito browsing** from the start to prevent local storage of history, cookies, and caches.
- **Sign out of every service** (email, cloud storage, social platforms) before leaving the machine.
- **Clear browser data** – delete recent history, cookies, cache, and any auto‑filled credentials.
- **Delete local files** – open the Downloads folder and remove any files saved during the session.
- **Avoid saving passwords or enabling "remember me"** prompts; reject any offers to store credentials.
- **Close all browser windows/tabs** and ensure the browser process has terminated.
- **Do not install software, extensions, or plug in removable drives** unless absolutely necessary.

## Supporting Tools

- Keep a running **[[concepts/session-log]]** in a cloud‑synced notes app so you can quickly record sign‑out actions and any residual files.
- Store all work in a single cloud service (see [[concepts/cloud-sync]]) so you never need to leave copies on the public machine.

## Checklist Example (Library PC)

1. Verify no files remain in the **Downloads** folder.
2. Check for stray auto‑filled login fields and clear them.
3. Sign out of all accounts used.
4. Clear browser history, cookies, and cache.
5. Close all windows and quit the browser.
6. Confirm no USB or external drives are connected.

Following these steps creates a clean exit, protecting your data and reducing the risk of accidental exposure on shared hardware.
