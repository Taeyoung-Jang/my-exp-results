## Cloud Sync

**Definition**: Cloud Sync is the practice of storing active work files in a single cloud‑based storage service and maintaining a consistent, predictable folder structure so that the same data is instantly available on any device.

**Key aspects**
- **Single service** – Choose one cloud provider (e.g., Google Drive, OneDrive, Dropbox) and keep all work‑related files there. This reduces fragmentation and makes it easy to locate documents.
- **Predictable hierarchy** – Organize files into clear, top‑level folders (e.g., `Projects/`, `References/`, `Personal/`). A simple structure eliminates guesswork when switching devices.
- **Automatic synchronization** – Ensure the client or web app continuously updates changes so the latest version is always in the cloud.
- **Cross‑device accessibility** – With sync in place, you can start a task on a laptop, continue on a library PC, and finish on a phone without missing a beat.

**Why it matters**
In [[summaries/session-34_2025-09-15]], the author emphasizes that a reliable Cloud Sync setup is the backbone of a portable workflow. By keeping everything lightweight and cloud‑based, the user can travel with only a notebook, rely on any public or library computer, and avoid the friction of transferring files manually.

**Related concepts**
- [[concepts/session-log]] – A cloud‑synced note that records what you were doing, tying together the sync strategy with task continuity.
- [[concepts/security-hygiene]] – When using public machines, proper sign‑out and data‑clearance practices complement Cloud Sync to keep personal data safe.

**Practical tips**
1. **Select one provider** and stick with it for all active work.
2. **Create a top‑level folder** (e.g., `Workspace/`) and sub‑folders for each project.
3. **Enable offline access** for critical files, but rely on the cloud for the master copy.
4. **Periodically verify** that the sync client is up‑to‑date and that no local copies remain on shared machines.
5. **Combine with versioning** (if supported) to retain historical snapshots of important files.

By following these guidelines, you turn your “workspace” into a portable, cloud‑backed environment that works seamlessly across any computer.
