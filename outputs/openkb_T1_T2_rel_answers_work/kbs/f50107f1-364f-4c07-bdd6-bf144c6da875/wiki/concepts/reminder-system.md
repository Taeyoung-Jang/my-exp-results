# Reminder System

**Type:** Concept  
**Description:** A phone‑based reminder setup to track borrowed items and prompt return checks.

## Overview
The Reminder System is a lightweight method for keeping borrowed items top‑of‑mind by using the reminders or calendar app on a smartphone. When an item is borrowed, a reminder is created for the expected return date (or the day before) and, if the return timing is uncertain, a recurring “check‑in” reminder is set.

## Key Practices from [[summaries/session-15_2025-02-15]]
- **Immediate reminder:** Create a reminder as soon as you borrow something, attaching a short note about the item.
- **Pre‑return alert:** Set the reminder for the day before you plan to return the item so you can prepare.
- **Flexible check‑in:** If you don’t know when you’ll see the owner, set a weekly reminder that asks “Do I know when I’ll see them next?” and snooze it until you have a concrete date.
- **Snoozing:** Use the snooze function to push the reminder forward without creating new entries.

## How It Works
1. **Capture the item** – (often paired with [[concepts/visual-cue-logging]]) take a photo and note the item.
2. **Create a reminder** – open your phone’s reminders app, write a brief description, and set the date/time.
3. **Adjust for uncertainty** – add a secondary weekly reminder for “check‑in” when the return date is unclear.
4. **Clear after return** – delete or mark the reminder as completed once the item is handed back.

## Benefits
- Reduces reliance on memory.
- Provides a visual cue and timed prompt.
- Flexible for both fixed and uncertain return schedules.
