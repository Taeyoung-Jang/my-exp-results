## Packing System

The **Packing System** is a structured approach to organizing, labeling, and prioritizing boxes during a move. It combines a room‑based color cue with a numeric identifier and a concise label format, enabling both the mover and the owner to locate and unload items efficiently.

### Core Elements

1. **Room‑based color coding**
   - Assign a distinct color (e.g., a sticker or tape) to each room (Kitchen, Bedroom, etc.).
   - Colors provide an immediate visual cue for where the contents belong.

2. **Numeric box identifier**
   - Number each box sequentially within its room (e.g., Kitchen #4).
   - The number helps keep a quick inventory list on a phone or paper.

3. **Standard label layout**
   ```
   Room: <Room>
   Box #: <Number>
   Contents: <Brief description>
   Priority: <P1/P2/P3> (optional)
   Notes: <Additional info>
   ```
   - The layout is consistent across all boxes, reducing guesswork.
   - Adding a **Priority** line integrates the [[concepts/priority-scheme]] for fast handling decisions.

4. **Digital inventory list**
   - Record each box’s details in a notes app, linking the room color and number to the contents. This list acts as a backup to the physical labels.

### Interaction with Other Concepts

- The **Open‑First Box** concept complements the Packing System by designating a small, high‑priority box that stays with you for immediate needs. See [[concepts/open-first-box]].
- The three‑level priority code (P1, P2, P3) described in [[concepts/priority-scheme]] can be appended to the label to signal handling order:
  - **P1 (Red)** – stays with you or rides in your car.
  - **P2 (Yellow)** – unload first after the truck arrives.
  - **P3 (Blue)** – standard loading, can wait.
