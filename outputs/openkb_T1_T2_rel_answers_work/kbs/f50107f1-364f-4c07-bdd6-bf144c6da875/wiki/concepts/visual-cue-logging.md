# Visual Cue Logging

**Definition**: Visual Cue Logging is the practice of capturing a photograph of a borrowed item and attaching a brief note, then storing that image in a reminder or note‑taking app to serve as a visual reminder of what needs to be returned.

**Why it works**
- A picture provides an immediate, unmistakable cue that text alone may lack.
- Pairing the photo with a reminder creates a timed prompt, linking the visual cue to a specific future action.

**How to implement (based on [[summaries/session-15_2025-02-15]])**
1. As soon as you borrow an item, snap a quick photo with your phone.
2. Send the photo to yourself (e.g., via email, messaging app, or directly into your reminders app) and add a short note such as “John’s throw blanket – return by …”.
3. Set a reminder for the day before you intend to return the item.
4. Keep the reminder entry accessible; the image will appear whenever the reminder triggers, reinforcing the memory of the specific object.

**Connections to other concepts**
- Part of a broader [[concepts/borrowed-item-tracking]] system that treats each borrowed item as a tiny calendar event.
- Relies on a [[concepts/reminder-system]] to schedule check‑ins and return dates.

**Benefits**
- Reduces reliance on memory alone.
- Provides a concrete visual anchor, especially useful for items that blend in with personal belongings (e.g., blankets, books).
- Makes it easy to verify you have the correct item when returning it.

**Tips**
- Store photos in a dedicated folder or tag them for quick reference.
- Use consistent naming (e.g., “borrowed‑blanket‑John.jpg”) to aid searching.
