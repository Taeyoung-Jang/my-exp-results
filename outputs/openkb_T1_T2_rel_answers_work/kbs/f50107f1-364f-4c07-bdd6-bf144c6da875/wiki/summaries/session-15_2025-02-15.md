## Summary

- **Core idea**: Treat each borrowed item as a tiny calendar event using a photo, a note, and a reminder. This creates a visual cue and a timed prompt to keep the item on your radar.  
- **Designated storage**: Keep all borrowed items in a single, obvious spot (e.g., a shelf or basket) so you can quickly see what isn’t yours.  
- **Flexible check‑in**: If you don’t know when you’ll see the owner again, set a weekly “check‑in” reminder to ask yourself if you have a meeting scheduled. Snooze until you have a concrete date.  
- **Proximity placement**: Store the borrowed item near things you always take when leaving home (keys, bag, shoes) to reduce forgetfulness.  
- **Casual return communication**: Use short, friendly text messages that acknowledge you still have the item and propose simple return options (drop‑off or bring next time). Sample messages were provided for a throw blanket.
