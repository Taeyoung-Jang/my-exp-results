# Parking Sensors (product)

Parking sensors are ultrasonic or electromagnetic devices mounted on a vehicle's front and/or rear bumpers that emit signals to detect nearby obstacles during low‑speed maneuvers. When an object enters the sensor's detection zone, the system provides audible beeps or visual cues, helping the driver gauge distances and avoid collisions.

## Key points from [[summaries/session-33_2024-06-15]]
- **Stress reduction**: The assistant recommends checking the sensor sensitivity in the vehicle’s settings menu to ensure early warnings, especially in tight city parking situations.
- **Parallel‑parking routine**: Sensors are cited as part of the cue set for judging curb proximity, complementing visual references such as the rear door handle alignment.
- **Adjustment tips**: Drivers can increase sensor sensitivity, and combine sensor feedback with mirror positioning for optimal curb detection.

## Practical usage tips
1. **Calibrate sensitivity**: Access the vehicle’s settings menu and set the sensor range to a higher level for early alerts in narrow streets.
2. **Combine cues**: Use sensor beeps together with mirror checks and visual reference points (e.g., rear‑door‑handle alignment) for precise positioning.
3. **Maintain sensors**: Keep bumper areas clean of dirt and snow, as obstructions can degrade detection accuracy.
4. **Leverage visual aids**: Pair sensors with a convex stick‑on mirror on the passenger‑side for a clearer view of the curb when visibility is low.
