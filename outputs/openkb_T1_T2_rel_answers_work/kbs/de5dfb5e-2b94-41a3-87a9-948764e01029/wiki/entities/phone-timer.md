# Phone Timer

**Type:** Product

The *Phone Timer* is a low‑tech tool described in [[summaries/session-37_2025-10-17]] for managing evening screen time. Its primary function is to serve as a **mechanical cue** that removes reliance on willpower when enforcing a scrolling cutoff.

## Key facts from the session
- **Purpose:** Acts as a concrete enforcement mechanism for the scrolling‑cutoff rule.
- **Duration:** Set to a single ten‑minute interval, labeled “scroll time.”
- **Placement:** The phone (with the timer active) is placed across the room as soon as the main evening activity begins, creating a physical barrier.
- **Workflow:** When the timer expires, the phone remains where it is, signalling the end of the allowed scrolling window and prompting the user to transition to bedtime activities.

## Related concepts
- The timer supports the broader strategy of [[concepts/scrolling-cutoff-mechanics]], which advocates using external devices or cues to limit digital distraction.
- It fits within an overall [[concepts/evening-routine-design]] that structures the two‑hour evening block.
- By defining a fixed, short window for scrolling, it aligns with the principle of [[concepts/transition-ritual]] that helps users move smoothly from purposeful tasks to rest.

## Usage tips
1. **Set the timer** as soon as you begin your main evening activity (e.g., reading, cooking, exercising).
2. **Place the phone** on a surface out of immediate reach to reduce temptation.
3. **Label the timer** clearly so that the ten‑minute window is unmistakable.
4. **When the timer rings**, treat it as a cue to put the phone away and proceed with your wind‑down routine.

This simple product exemplifies how a modest, tangible tool can reinforce intentional habit formation without demanding ongoing self‑control.
