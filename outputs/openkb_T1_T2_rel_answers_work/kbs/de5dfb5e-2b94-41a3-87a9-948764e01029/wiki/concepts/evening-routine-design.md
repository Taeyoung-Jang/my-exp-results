# Evening Routine Design

## Definition
Evening Routine Design is a framework for shaping the hours after work into purposeful, flexible activities that guard against mindless scrolling and promote wellbeing.

## Core Elements
1. **Transition Ritual** – a short, consistent habit (e.g., changing clothes, making tea) that signals the shift from work mode to personal time. [[concepts/transition-ritual]]
2. **Time‑Blocking** – allocating the available evening window (often ~2 hours) into three loosely defined phases: reset, meaningful activity, and calming wind‑down.
3. **Energy‑Based Flexibility** – allowing the order or intensity of activities to adapt to how tired you feel, rather than a rigid schedule. [[concepts/flexible-blocks]]
4. **Scrolling Cutoff Mechanics** – a low‑effort system (phone placed across the room, timed 10‑minute scroll window) that eliminates reliance on willpower. [[concepts/scrolling-cutoff-mechanics]]
5. **Micro‑Task Menu** – a small set of concrete activity pairings (e.g., “read + sketch”, “walk + cook”) that can be swapped in as needed. [[concepts/micro-task-menu]]

## Example Templates (from [[summaries/session-37_2025-10-17]])
- **Quiet Creative** – transition (10 min) → reading (40 min) → hands‑on creative (30 min) → soft landing (20 min).
- **Active‑then‑Cozy** – short walk/stretch (10 min) → simple cooking & mindful eating (50 min) → optional media or book (30 min).
- **Flexible Energy‑Based** – if energized: goal‑oriented activity (1 h) then shower + light reading; if tired: start with restorative activity then optional engagement.

## Implementing the Scrolling Cutoff
- Place the phone across the room when the main activity begins.
- Set a **10‑minute timer** (often using a phone‑based timer device) labeled “scroll time”.
- When the timer ends, the phone remains out of reach and you transition to bedtime.

## Benefits
- Reduces autopilot scrolling.
- Provides structure without feeling like a chore.
- Supports adaptation to daily energy fluctuations.
