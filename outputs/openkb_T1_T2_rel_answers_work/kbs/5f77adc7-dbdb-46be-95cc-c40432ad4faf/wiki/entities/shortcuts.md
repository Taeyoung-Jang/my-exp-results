# Shortcuts (product)

Shortcuts is Apple's built‑in automation **product** for iOS that lets users create custom workflows that can run locally on the device.  In the context of the beta‑software discussion in [[summaries/session-31_2025-02-15]], Shortcuts is a core feature the user wants to keep functional while tweaking system settings to reduce battery drain and heat.

## Key facts from the session
- The user installed a developer beta specifically to access new **on‑device transcription** and **automation shortcuts**.
- Recommended settings changes explicitly advise **leaving Shortcuts automations on** to preserve the new functionality.
- Adjustments such as disabling background refresh for non‑essential apps, turning off analytics, and tweaking location services are suggested **without disabling Shortcuts**.
- Shortcuts relies on services like **Siri** for on‑device processing and may use **iCloud Drive** for storing shortcut data.
