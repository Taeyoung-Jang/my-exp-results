# On‑Call Sustainability

**Definition**: A set of habits, policies, and team practices that make rotating on‑call duties manageable over the long term, preserving personal well‑being and system reliability.

## Core Elements (derived from [[summaries/session-40_2025-10-15]])

1. **Clear expectations**
   - Document what counts as a page, response windows, and responsibilities.
   - Use written runbooks or guidelines to reduce mental load when off‑call.
2. **Sleep management**
   - Shift bedtime earlier during rotation.
   - Return to sleep immediately after a page; use short naps the next day.
3. **Boundary setting**
   - Limit activities that conflict with on‑call (e.g., alcohol, long drives, extra project work).
   - Communicate limits to the team to avoid guilt.
4. **Burnout monitoring**
   - Track page frequency and repeat incidents.
   - Push for reliability work or automation when patterns emerge.  See [[concepts/burnout-prevention]].
5. **Recovery time**
   - Ensure at least one quiet day after a shift to reset.
6. **Settle‑in window**
   - Introduce a 5–10 minute period at shift start to log in, review dashboards, and hand off alerts.  See [[concepts/settle-in-window]].
7. **Interruption management**
   - Treat on‑call as a predictable mode; avoid “instant triage” expectations by negotiating a brief handoff period.  See [[concepts/interruption-management]].
8. **Time‑blocking & check‑ins**
   - Use dedicated blocks for deep work and regular check‑ins to maintain focus.  See [[concepts/time-blocking]] and [[concepts/check-in-windows]].

## Benefits
- Reduces mental fatigue and risk of chronic stress.
- Improves incident response quality by ensuring context before action.
- Encourages systemic improvements rather than fire‑fighting.
- Supports team morale and retention.

## Implementation Checklist
- [ ] Create a written on‑call guideline (pages, response windows, exclusions).
- [ ] Agree on a settle‑in window with the rotation lead.
- [ ] Set personal sleep and recovery routines.
- [ ] Track page metrics and flag repeat incidents.
- [ ] Schedule regular retrospectives to address burnout signals.
