# Philips Hue White Ambiance

**Type:** Product (smart LED bulb)

**Description:** A Wi‑Fi‑enabled, dimmable A19 LED bulb from Philips Hue that can be set to various warm color temperatures, commonly used to create migraine‑friendly lighting.

**Key facts from [[summaries/session-13_2023-07-22]]:**
- Recommended as a *smart‑bulb* alternative to using a wall dimmer.
- Provides stable, flicker‑free output suitable for users sensitive to flicker [[concepts/flicker-free-dimming]].
- Can be tuned to ~3000 K for office work while staying within the warm‑light range that eases migraine symptoms [[concepts/warm-lighting-for-migraines]].
- Works with a standard on/off switch; for deeper dimming control it can be paired with a Lutron dimmer such as [[entities/lutron-caseta-pd-6wcl-wh]] or [[entities/lutron-diva-dvcl-153p-wh]], though the bulb’s own app typically handles dimming.
- Compatible with the LED dimmer compatibility guidelines outlined in [[concepts/led-dimmer-compatibility]].

**Typical use cases:**
- Living‑room lighting together with table lamps or floor lamps, using fabric shades to diffuse light.
- Office overhead or desk lamps where adjustable color temperature and dimming are needed.
