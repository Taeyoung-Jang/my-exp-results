# Summary of session-32_2024-12-13

**Main idea**: A low‑effort, repeatable workflow for organizing, backing up, and archiving travel photos and videos on Windows.

## Key Steps
1. **Incoming folder** – Create a permanent **Photos Incoming** folder on the laptop. Dump all new media from phone/camera here immediately after each trip. [[concepts/incoming-folder]]
2. **Quick cloud backup** – Let an automatic cloud service (e.g., OneDrive, [[entities/google-photos]]) sync the Incoming folder in the background for instant protection. [[concepts/cloud-backup]]
3. **Rapid cleanup** – Perform a fast pass: delete obvious junk, duplicates, and blurry shots. [[concepts/duplicate-removal]]
4. **Trip‑folder naming** – Move cleaned files into a sub‑folder named with date and place, e.g., `2025-02 Japan`. [[concepts/trip-folder-naming]]
5. **Dual local copy** – Keep the primary copy on the laptop and mirror the archive folder to an external drive. [[concepts/local-backup]]
6. **Plug‑and‑forget mirroring** – Use Windows [[entities/file-history]] to automatically sync the archive folder to the external drive whenever it is connected. [[concepts/external-drive-mirroring]] [[concepts/plug-and-forget-backup]]

## Tool Recommendations
- **Windows [[entities/file-history]]** – Preferred for its simple, automatic, “plug‑in‑and‑forget” behaviour.
- **[[entities/freefilesync]]** – More control but requires manual launch or scheduled tasks; less suited for the described low‑maintenance goal.

## Workflow Benefits
- Minimal manual steps after the initial dump.
- Continuous cloud protection plus a separate local copy for redundancy.
- Consistent folder structure makes future retrieval easy.
- Automated external‑drive sync eliminates the need to remember extra actions.
