# Utility Setup Process

The **Utility Setup Process** outlines the sequential actions a new resident in Austin should take to activate essential services—electricity, water, natural gas, internet, trash/recycling, parking permits, and renter's insurance—so that everything is functional on move‑in day.

## Core Steps
1. **Identify providers**
   - Electricity: [[entities/austin-energy]] (city‑served)
   - Water & wastewater: [[entities/austin-water]] (city‑served)
   - Natural gas (if applicable): [[entities/texas-gas-service]]
   - Internet: [[entities/att-fiber]], [[entities/google-fiber]], or fallback [[entities/spectrum]]
   - Trash & recycling: [[entities/austin-resource-recovery]] (linked to water service)
   - Parking permits: [[entities/city-of-austin-parking-division]]
   - Renter’s insurance: providers such as Lemonade, State Farm, USAA

2. **Gather required documentation**
   - Lease start date
   - Government‑issued ID
   - Payment method (card or bank account)
   - Any deposit information (electric/gas if no credit history)
   - Proof of residence for parking permits

3. **Contact providers**
   - Use the official **Customer Care portal** (coautilities.com) for both [[entities/austin-energy]] and [[entities/austin-water]].
   - Start gas service via https://texasgasservice.com/startservice.
   - Check internet availability with the **address lookup** tools of AT&T and Google Fiber (see [[concepts/address-lookup]]). If the address format is finicky, try the building name or omit the unit number.

4. **Schedule start dates**
   - Follow the [[concepts/service-start-timeline]]: submit electricity, water, and gas requests **3–4 days** before move‑in; schedule internet **~7 days** ahead to allow for kit delivery or technician appointment; confirm trash pickup (auto‑linked to water) and apply for parking permits mid‑week.

5. **Confirm and track**
   - Record confirmation numbers for each provider.
   - Verify that trash/recycling will begin on the same day as water service.
   - Ensure renter’s insurance is active on move‑in.

## Overlap & Transfer
Existing occupants do **not** need to coordinate directly with the new tenant. Each utility provider can end the prior resident’s service on their move‑out date and start the new resident’s service on the lease start date, automatically handling any overlap. The only exception is **master‑metered** buildings, where the property management coordinates the switch.
