# Swollen Lithium‑Battery Handling

**Definition**: Safe practices, communication protocols, and policy considerations for dealing with swollen lithium‑ion batteries in consumer electronic repair contexts.

## Core Elements

1. **Safety Assessment**
   - Verify whether the device and battery are safe to transport.  
   - Ask the service provider if the swollen battery has been retained or properly disposed of.
2. **Policy Clarity**
   - Request written clarification of the kiosk or retailer’s procedure for handling swollen batteries.
   - Include a request for a written diagnosis that covers battery condition.
3. **Data‑Recovery Considerations**
   - Clarify whether any data‑recovery attempts were made, as swollen batteries can affect data integrity.
4. **Consumer Communication**
   - Use a firm‑but‑polite tone when requesting information (see [[concepts/email-drafting]]).
   - Provide a clear response deadline (see [[concepts/response-deadline]]).
5. **Documentation**
   - Attach safe, non‑sensitive photos of the device and battery when appropriate (see [[concepts/attachment-guidelines]]).
