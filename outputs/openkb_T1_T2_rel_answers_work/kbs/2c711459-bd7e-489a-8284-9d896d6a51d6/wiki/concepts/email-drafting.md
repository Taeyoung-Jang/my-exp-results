# Email Drafting

**Email drafting** is the practice of composing written messages that convey a request or information in a clear, polite, and actionable manner. Effective drafts balance firmness with courtesy, use structured placeholders, and include specific calls‑to‑action such as a [[concepts/response-deadline]].

## Core Elements

1. **Personalized placeholders** – Include fields for the recipient name, organization, location, date, and time so the same template can be reused across different incidents.
2. **Concise bullet‑point requests** – List each item the sender needs (e.g., a written diagnosis, data‑recovery confirmation, refund options, safety verification). Bullet points make the email scannable and help the recipient address each point systematically.
3. **Clear tone** – Adopt a steady, non‑confrontational voice that signals the sender is seeking resolution rather than assigning blame. This aligns with best practices for [[concepts/customer-complaint]] communications.
4. **Explicit deadline** – State a reasonable response window (commonly five business days) to encourage timely replies and set expectations.
5. **Safety and policy queries** – When dealing with technical issues such as a swollen lithium‑ion battery, ask directly about device safety and battery disposition. This ties into [[concepts/swollen-lithium-battery-handling]].
6. **Attachment guidance** – Recommend attaching clear photos if they aid understanding, while avoiding personal data exposure. See [[concepts/attachment-guidelines]] for details.

The emails created for the repair‑kiosk scenario illustrate these principles:
