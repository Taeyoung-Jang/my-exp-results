# Flexible Scheduling

**Definition**: Flexible scheduling is a planning approach that combines a few fixed *anchor points* with modest *buffer time* and optional “floating” tasks, allowing the day to adapt to real‑time variations without feeling rigid.

## Core Elements
- **Anchor points** – Core moments that provide structure (e.g., start work, lunch, wrap‑up). See [[concepts/anchor-points]].
- **Buffer time** – Extra time (typically 25‑30 % of a task’s estimate or a fixed cushion) that absorbs delays. See [[concepts/buffer-time]].
- **Floating tasks** – Low‑priority activities kept in reserve to fill any leftover gaps.

## How It Appears in Session 07
The conversation in [[summaries/session-07_2024-06-15]] proposes a weekday template:
1. Set a handful of anchors (morning ready‑to‑leave, lunch, afternoon wrap‑up, evening wind‑down).
2. Allocate 25‑30 % additional time for tasks that matter, creating *buffers* between anchors.
3. Keep one or two optional tasks that can be completed if extra minutes remain – these are the *floating* tasks.

This structure yields a day that feels **supportive**, not dictated by the clock, while still ensuring punctuality for key events.

## Benefits
- Reduces anxiety by limiting the need for constant time‑checking.
- Allows natural variations (e.g., a meeting running longer) without derailing the whole schedule.
- Encourages reflection: users adjust anchors and buffers after a few days based on what actually worked.

## Practical Tips
- Start with 3‑4 anchors per day; add more only if needed.
- Apply the 25‑30 % buffer rule only to high‑impact tasks, not every activity.
- Review each day’s outcomes and tweak anchor times or buffer sizes.
