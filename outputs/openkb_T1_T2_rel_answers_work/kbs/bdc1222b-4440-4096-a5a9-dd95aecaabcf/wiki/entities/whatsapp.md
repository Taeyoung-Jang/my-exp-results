# WhatsApp (product)

WhatsApp is a widely used cross‑platform instant‑messaging application owned by Meta Platforms. It supports text, voice, video calls, and media sharing, and offers cloud backups via Google Drive on Android devices.

## Key facts from session‑15 (2024‑06‑15)
- **Backup method**: On Android, WhatsApp stores chat backups on Google Drive, which can be restored during device migration.
- **Migration checklist**: The session recommends creating a full Google Drive backup (Settings → Chats → Chat backup) before moving to a new Pixel device, then restoring that backup after installing WhatsApp on the new phone.
- **Common gotchas**: Users often forget to run the backup before wiping the old phone, resulting in lost chat history.
