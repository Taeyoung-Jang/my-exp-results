# Android

**Type:** product

Android is Google’s open‑source mobile operating system that powers a diverse ecosystem of smartphones and tablets. It offers deep customization, multiple hardware options, and integration with Google services such as Google Photos, Google Messages, and Google Authenticator.

## Key points from [[summaries/session-15_2024-06-15]]
- **Control vs. convenience:** Android provides more user control and customization compared with [[entities/ios]], but this can introduce manufacturer‑added bloat and variable update schedules.
- **Update longevity:** High‑end Android devices (e.g., [[entities/pixel-9]], [[entities/pixel-9-pro]], [[entities/galaxy-s24]]) now often receive 5‑7 years of security and OS updates, aligning with the [[concepts/long_term_phone_support]] discussion.
- **Backup & migration:** Android relies on Google’s backup ecosystem. Users should verify Google Photos sync, system backup (Settings → System → Backup), and app‑specific cloud sync. This aligns with the [[concepts/google_backup]] concept.
- **Ecosystem choices:** For a Google‑centric workflow, the Pixel line offers a near‑stock experience with minimal bloat, while Samsung’s Galaxy S series adds extra features and UI layers (One UI), leading to slightly slower updates.

## Practical considerations
- **Bloatware:** Many Android OEMs pre‑install apps and services, which can affect storage and performance.
- **Update cadence:** While Google releases Android updates promptly, actual roll‑out depends on the device manufacturer.
- **Data migration:** Successful migration hinges on completing Google backups (photos, messages, app data) before switching devices and using device‑to‑device transfers for apps like Signal.
