# MP4

**MP4** (MPEG‑4 Part 14) is a digital video container format that combines video, audio, and metadata streams. It is noted for its broad compatibility across operating systems, devices, and media players, making it a practical choice for long‑term personal archives.

## Why MP4 in a Future‑Proof Archive?
- **Open‑format alignment** – MP4 is an internationally standardized format and is listed under the [[concepts/open-formats]] recommendation in the archival strategy from [[summaries/session-36_2024-12-15]].
- **Efficient compression** – It balances quality and file size, which helps keep storage costs reasonable while preserving visual fidelity.
- **Metadata support** – MP4 containers can embed XMP side‑car data, allowing important context to travel with the file.

## Recommended Usage
1. **Store as primary video format** within the `Video/` top‑level folder of the archive.
2. **Name files** using the chronological convention `YYYY‑MM‑DD‑keyword‑description.mp4` to keep them sortable and self‑describing.
3. **Embed essential metadata** (creation date, descriptive tags) directly in the file when possible; supplement with a project‑level `README.md` for additional context.

## Backup Considerations
- Treat MP4 files like any other critical asset: include them in the 3‑2‑1 backup scheme described in [[concepts/backup-strategy]].
- Verify integrity periodically using checksums; corrupted video files are often hard to notice without verification.

## Related Formats
- For still images the archive recommends [[entities/jpeg]] and [[entities/png]].
- For text‑based notes, the preferred format is [[entities/markdown]].
