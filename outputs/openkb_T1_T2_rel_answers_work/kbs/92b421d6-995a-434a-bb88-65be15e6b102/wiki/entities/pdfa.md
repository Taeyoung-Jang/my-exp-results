# PDF/A

PDF/A (Portable Document Format Archival) is an ISO‑standardized version of PDF that removes features unsuitable for long‑term preservation, such as encryption and external references, ensuring that documents remain readable and render consistently over decades.

## Key facts from [[summaries/session-36_2024-12-15]]
- The session recommends using **PDF/A** for any document that needs to be kept readable far into the future.  It is listed alongside plain‑text, Markdown, JPEG, PNG, and MP4 as part of a suite of **open formats** that survive changing software ecosystems.
- In the suggested backup strategy, PDF/A files benefit from the same 3‑2‑1 redundancy model, with integrity checks (e.g., checksums) to catch silent corruption.

## Related concepts and entities
- Part of the broader **open‑formats** approach discussed in [[concepts/open-formats]].
- Works well with embedded metadata standards like EXIF and XMP for other file types, though PDF/A itself stores metadata internally in a standardized way.
- Complementary to the overall **backup strategy** outlined in [[concepts/backup-strategy]] and the **folder‑structure** recommendations in [[concepts/folder-structure]].
