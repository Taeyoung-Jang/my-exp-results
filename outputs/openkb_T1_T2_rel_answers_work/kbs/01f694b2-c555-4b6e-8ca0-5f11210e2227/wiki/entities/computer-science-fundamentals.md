# Computer Science Fundamentals (Minor/Certificate)

**Type:** other

The *Computer Science Fundamentals* minor (or certificate) provides a solid grounding in core computing concepts—programming, data structures, algorithms, and basic software development. It is positioned as a **high‑leverage** credential that complements a wide range of majors, especially those leaning toward policy/economics or data/technology.

## Key Facts from Session 12 (2019‑04‑14)
- Recommended as one of the three **high‑leverage minors/certificates** that keep both policy/econ and data/tech pathways open. [[concepts/high-leverage-minors]]
- Helps students develop **core skills** (quantitative literacy, technical fluency, problem‑solving) required for a flexible curriculum. [[concepts/core-skills]]
- Supports the **flexible‑curriculum** approach by giving non‑CS majors a practical technical foundation without forcing a full CS degree. [[concepts/flexible-curriculum]]
- Mentioned explicitly in the summary of the document: [[summaries/session-12_2019-04-14]].

## Typical Coursework
- Introduction to Programming (Python/Java)
- Data Structures and Algorithms
- Computer Systems Basics (operating systems, networking fundamentals)
- Applied Project or Capstone (often a small software prototype or data‑analysis tool)

## Benefits
- Enhances employability across sectors (consulting, public policy, tech startups).
- Enables deeper engagement with data‑intensive courses such as econometrics or machine learning.
- Provides a common technical language that facilitates interdisciplinary collaboration.

## Related Entities
- **Data Analytics** minor – another recommended high‑leverage credential. [[entities/data-analytics]]
- **Public Policy** minor – complements CS fundamentals for policy‑tech roles. [[entities/public-policy]]
