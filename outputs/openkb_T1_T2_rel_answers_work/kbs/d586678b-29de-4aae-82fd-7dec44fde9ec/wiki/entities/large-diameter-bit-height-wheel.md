# Large‑Diameter Bit‑Height Wheel

**Type:** Product

**Description:** A oversized wheel used to adjust the height of router bits from above the table, providing a larger lever arm and smoother, low‑effort motion. It is especially useful for users seeking a *light‑touch workflow* that minimizes wrist twisting.

## Key Features
- **Large diameter** (typically 4–6 inches) gives greater mechanical advantage compared to standard knurled knobs.
- **Smooth rotation** with low friction bearings, allowing fine height changes using the palm or shoulder rather than a finger squeeze.
- **Easy installation** on most router tables via a simple threaded adapter.
- Often paired with **quick‑release** accessories (e.g., [[entities/quick-release-visor]]) for rapid tool changes.

## Benefits in Workshop Ergonomics
- Reduces the need for repetitive micro‑turns of a small knob, aligning with the **[[concepts/light-touch-workflow]]** advocated for wrist‑injury mitigation.
- Allows the user to make adjustments while keeping the arm in the **[[concepts/arm-reach-zone]]**, keeping the wrist neutral.
- Works well with the **[[concepts/shim-based-depth-adjustment]]** technique: once the wheel sets a baseline height, fine tuning can be done by adding or removing shims rather than further wheel turns.
