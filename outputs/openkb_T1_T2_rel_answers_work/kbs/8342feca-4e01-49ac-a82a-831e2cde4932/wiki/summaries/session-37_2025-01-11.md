# Summary of session‑37_2025-01-11

**Main contribution**: A set of concrete, cue‑based after‑work routines to help the user reliably attend a weekday salsa class, including timed scripts, night‑before preparation steps, phone‑reminder wording, and a minimum‑viable fallback.

## Key Concepts
- [[concepts/after-work-routine]] – tiny transitional actions bridging the gap between arriving home and heading out again.  
- [[concepts/cue-based-habit]] – using objects (gym bag, snack, clothes) as physical triggers.  
- [[concepts/minimum-viable-fallback]] – a low‑effort version that still counts toward the habit.  
- [[concepts/energy-management]] – handling tiredness by structuring the routine around brief, active steps.  

## Structured Scripts (with target times)
| Time | Action | Notes |
|------|--------|-------|
| **5:30** | Leave work | Mental rename: “I’m already on the way, with a quick stop at home.” |
| **6:00** | Arrive home | **Do not sit.** Change into class clothes, grab the pre‑packed snack, pick up the salsa bag (see [[entities/salsa-class]]). Optionally play one upbeat song and stay upright until it ends. |
| **6:20** | Head out | Get in the car, tell yourself you’ll reassess after a 5‑minute drive if needed. |
| **6:45** | Arrive class | The drive serves as the real decompression period. |

### Script Variants
1. **Continuous‑motion script** – immediate bag grab, no pause; if tired, say “I’ll decide after I’m outside.”  
2. **Quick‑reset script** – change, hydrate, play a song → leave after the song ends.  
3. **Two‑minute promise** – set a 2‑minute timer, use it to change, snack, pack, then exit.

## Night‑Before Checklist
- Pack the salsa bag fully and place it by the door with keys.  
- Lay out class clothes on the dresser.  
- Put an easy‑grab snack (banana, bar, yogurt) at the front of the fridge.  
- Set a phone reminder for ~5:20 PM (e.g., **“Change clothes first, decide after.”**)

## Minimum‑Viable Fallback (still counts)
- Follow the same steps up to getting into the car.  
- If exhausted, drive to the studio parking lot and allow yourself to skip the class there.  
- If even that feels too much, do a 5‑minute dance warm‑up at home in salsa clothes; the cue stays alive so the habit doesn’t break.

## Phone Reminder Wording (non‑cheesy examples)
- “You’re already on your way.”  
- “Just start the routine.”  
- “Change clothes first, decide after.”  
- “Grab bag, go.”

These components together form a flexible, low‑friction habit system that turns the home‑arrival‑to‑couch trap into a brief, purposeful pit stop, while providing a graceful low‑energy alternative to keep consistency.
