# Break‑Even Analysis

**Definition**

Break‑Even Analysis is a financial technique used to determine the point at which the total costs of two alternatives are the same. It isolates the variable cost component that changes with usage and compares it against fixed costs to find the usage level (e.g., number of days, miles, trips) where the expenses intersect.

**Key Elements**
- **Fixed Costs**: Expenses that do not vary with usage (e.g., insurance, monthly parking permits, maintenance). 
- **Variable Costs**: Expenses that scale with usage (e.g., fuel, per‑mile car‑share fees, daily parking fees).
- **Break‑Even Point**: The quantity of usage at which total cost of option A equals total cost of option B.

**Application in [[summaries/session-01_2024-06-15]]**

The session examined two parking cost structures for a personal‑car user:
1. **Monthly parking pass** – $180 per month, regardless of how many days the car is parked.
2. **Daily parking** – $18 per day.

The analysis calculated the break‑even threshold as:

```
$180 / $18 per day = 10 days per month
```

Thus, if the driver parks fewer than ten days in a month, paying daily is cheaper. The user’s planned driving pattern (1‑2 days per week, roughly 4‑8 days per month) falls below this threshold, indicating a financial advantage to dropping the monthly pass.

**Broader Use Cases**
- Comparing a personal car’s total cost versus public transit or bike costs.
- Deciding between a monthly subscription (e.g., transit pass) and per‑trip fares.
- Evaluating the cost impact of switching from ride‑hailing to car‑share services.

- [[concepts/cost-comparison]] – broader evaluation of multiple transportation options.

**How to Perform a Simple Break‑Even Analysis**
1. List all fixed costs for each option.
2. Identify the variable cost per unit of usage (e.g., per day, per mile).
3. Set the total cost equations equal and solve for the usage variable.
4. Compare the result to the expected usage to decide the cheaper option.
