# Default Dish

A **default dish** is a familiar, preferred menu item that diners treat as a reliable fallback. It serves as a *home base* for ordering decisions, especially when faced with rotating **daily specials**. The concept is also a core part of a broader [[concepts/cuisine-exploration-strategy]]: it lets diners experiment while keeping a safety net.

## Role in Decision‑Making
- **Baseline Comparison**: The default dish provides a reference point for evaluating the risk of trying something new. If a special lacks a clear reason—such as a seasonal ingredient or a flavor profile that aligns with the default—the diner is advised to stick with the familiar.
- **Mood Alignment**: Even a well‑executed special can fall flat if it doesn’t match the diner’s current cravings. The default dish helps gauge personal mood before deviating.
- **Risk Mitigation**: Choosing a special that is a *twist* on the default dish reduces uncertainty compared to an entirely unfamiliar option.
- **Exploration Anchor**: When using the [[concepts/questioning-script-restaurant]] (e.g., asking about flavor, spice, texture), the default dish acts as a benchmark for interpreting server answers and deciding whether a special feels “gentle” or “bold.”
- **Fermented Flavor Check**: For diners curious about fermented notes, the default dish can help gauge intensity. Refer to [[concepts/beginner-friendly-fermented-flavors]] to spot “good funk” options that are still approachable.

## Practical Example
In the conversation summarized in [[summaries/session-11_2025-08-14]], the user’s default is **grilled salmon** (see [[entities/grilled-salmon]]). The assistant suggests only deviating from the grilled salmon when the server can provide concrete, enthusiastic details about the **daily special** (see [[entities/daily-special]]), such as:
- Seasonal ingredients the chef wants to showcase.
- A flavor combination that mirrors the default’s strengths.
- Answers that fit the [[concepts/questioning-script-restaurant]] (e.g., “mild vs. bold,” “spice level,” “texture”).

Session‑39 expands this by recommending practical tactics: order a small‑plate or tasting portion, ask the quick‑question script, and use “gentler cousin” pivots (e.g., swapping stinky tofu for mild fermented bean curd) to stay within a comfortable flavor range while still exploring.

## When to Stay with the Default Dish
- The server hasn’t tried the special or gives vague answers.
- The special lacks a clear seasonal or flavor rationale.
- The kitchen appears rushed or uncertain.
- Answers to the questioning script indicate the dish is “bold,” “pungent,” or “acquired taste” without a gentler alternative.
- The diner is unsure about fermented intensity and cannot find a beginner‑friendly counterpart.

By treating the default dish as a reliable anchor, diners can make quicker, more satisfying choices while still remaining open to compelling specials.
