# Wrist‑Friendly Tool Design

**Definition**: A set of ergonomic principles and product features that enable effective one‑handed use while minimizing stress on the wrist, especially when one wrist is injured or limited.

## Core Principles
1. **Weight Distribution** – Tools should offload force away from the wrist, using gravity, leverage, or stabilizing surfaces.
2. **Stabilization Aid** – Incorporate non‑slip materials (e.g., [[entities/dycem]]) or built‑in spikes/guards (e.g., [[entities/swedish-cutting-board]], [[entities/sammons-preston]]) so the user does not need to press down with the wrist.
3. **One‑Handed Actuation** – Mechanisms that can be operated with a single grip or twist, such as a V‑shaped jar opener that mounts under a cabinet ([[entities/ez-off]]) or a rocker‑style knife ([[entities/rocker-knife]]).
4. **Minimal Grip Force** – Use ergonomic handles and assisted motions (e.g., lever‑assist, pump‑style dispensing) to reduce the effort required from the hand and wrist.
5. **Adjustable Positioning** – Allow the tool to be placed in a location that aligns with the user’s functional hand, avoiding awkward wrist angles.

## Examples from [[summaries/session-39_2025-03-14]]
- **Dycem non‑slip mat** – Provides a high‑friction surface without sticky residue, keeping bowls and cutting boards stable so the user does not need to hold them with the injured wrist.
- **EZ Off under‑cabinet jar opener** – Mounted on the front underside of an upper cabinet; the jar is trapped in V‑shaped teeth and twisted with the good hand, requiring no wrist pressure from the injured side.
- **Swedish cutting board** – Features spikes and a corner guard that secure food items, allowing the user to cut without pressing down with the wrist.
- **Rocker knife** – Cuts by a rocking motion, eliminating the need for a downward push that would strain the wrist.
- **One‑handed can opener (OXO Good Grips or [[entities/kohn-rikon]])** – Clamps the can and turns with a single hand, avoiding the need for a second‑hand grip.
- **Pump‑style soap dispenser** – Enables dispensing with a simple press, no wrist torque required.

## Design Recommendations
- Use **non‑slip mats** (e.g., Dycem) on countertops to create a stable base.
- Mount under‑cabinet devices like EZ Off within easy reach of the functional hand.
- Choose cutting boards with built‑in spikes or guards to secure food without manual pressure.
- Opt for tools with ergonomic handles and lever‑assist mechanisms (rocker knives, pump dispensers, assisted can openers).
- Position tools so that the user can rest their forearm or elbow for balance, not the wrist.
