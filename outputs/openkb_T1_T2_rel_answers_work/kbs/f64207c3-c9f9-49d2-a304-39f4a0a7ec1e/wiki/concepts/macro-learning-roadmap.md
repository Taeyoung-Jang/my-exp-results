# Macro Learning Roadmap

**Definition**: A staged, checklist‑driven framework that guides learners through the core topics of macroeconomics—measurement, short‑run models, expectations, labor markets, policy, open‑economy issues, and financial crises—while staying strictly within a pre‑selected set of texts.

---

## Purpose
The roadmap is designed to:
- Provide a **clear sequential order** for studying macroeconomics, building each layer on the previous one.
- Use **mastery questions** and **common confusion alerts** to promote active recall and self‑assessment.
- Define **"good enough" mastery** as the ability to explain concepts and redraw key diagrams using only the terminology and illustrations from the reader’s own materials.
- Keep the learning process **self‑contained**, avoiding the need for additional readings.

---

## How to Use the Roadmap
1. **Read** the assigned chapters from your curated list.
2. **Answer** the mastery questions for the current stage using only the book’s language, diagrams, and examples.
3. **Self‑Assess**: you have reached "good enough" when you can explain the core ideas aloud for a minute and redraw the textbook’s key figures without looking.
4. **Check** the "common confusions" list to ensure you are not slipping into common misconceptions.
5. **Proceed** to the next stage only after meeting the self‑assessment criteria.
