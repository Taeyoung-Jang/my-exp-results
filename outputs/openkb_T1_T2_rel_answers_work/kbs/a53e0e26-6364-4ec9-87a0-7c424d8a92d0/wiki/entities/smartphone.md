# Smartphone

A **smartphone** is a handheld computer that combines telephony, computing, and a rich set of sensors. In the context of the conversation on smart technology, the smartphone is highlighted as a platform where **background automation** can make the device feel like an *invisible helper*.

## Key Points from [[summaries/session-04_2024-06-15]]
- **Automatic brightness** and **focus modes** that adapt to time or location exemplify [[concepts/background_automation]].
- Intelligent notification sorting reduces the need for user intervention, supporting [[concepts/mental_load_reduction]].
- When these features work reliably, the phone follows a [[concepts/low_maintenance_design]] pattern, requiring little ongoing tweaking.

## Related Devices
- The **smartwatch** (see [[entities/smartwatch]]) provides complementary passive health tracking that aligns with the same design principles.
- Home‑centric devices like [[entities/smart-bulb]], [[entities/smart-thermostat]], and [[entities/smart-speaker]] also pursue background automation, extending the ecosystem of low‑maintenance smart products.

## Design Implications
- Prioritize **clear defaults** and **context awareness** so the phone can act autonomously.
- Avoid over‑customizable notification categories that lead to constant adjustments, which would break the low‑maintenance ethos.

Overall, the smartphone serves as a central hub for implementing smart, low‑maintenance features that alleviate mental load in daily life.
