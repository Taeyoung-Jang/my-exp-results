# Spouse Check‑In Workflow

The **Spouse Check‑In Workflow** is a lightweight, repeatable agenda that couples use each Sunday to review and synchronize their upcoming week. It supports the broader [[concepts/block-scheduling]] approach by ensuring that non‑negotiable items, shared responsibilities, and flexible “float” blocks are visible to both partners before the schedule is finalized.

---

## Why It Matters
- Guarantees that any **shared commitments** (e.g., errands, childcare, joint appointments) are coordinated.
- Keeps personal and flexible blocks private, reducing unnecessary negotiation.
- Provides a clear point for applying the [[concepts/midweek-change-rule]] when mid‑week adjustments affect the other partner.

---

## Core Steps (derived from [[summaries/session-10_2022-05-23]])
1. **Prepare Draft Block Maps**
   - Each partner creates a simple visual or listed map of the week, highlighting:
     - Non‑negotiable commitments (work, fixed appointments).
     - Proposed deep‑work, life‑admin, and downtime blocks.
     - One or two “float” blocks for unexpected tasks.
2. **Sunday Check‑In Agenda** (≈10 minutes)
   - **Pass 1 – Non‑Negotiables**: Each person reads aloud their fixed commitments.
   - **Pass 2 – Shared Items**: Discuss errands, coverage needs, and any timing that impacts both partners.
   - **Pass 3 – Flexible Blocks & Flex Points**: Confirm personal blocks and identify where each can absorb surprises.
3. **Shared Notes Document**
   - A single running note (e.g., a shared Google Doc) with the following sections:
     ```markdown
     # This Week
     ## Fixed Commitments
     - Partner A: …
     - Partner B: …

     ## Shared Responsibilities
     - …

     ## Agreed Flex Points
     - …

     ## Change Log (mid‑week updates)
     - Date – change description – resolution
     ```
   - This document becomes the reference for the week and records any mid‑week changes.
4. **Confirm Non‑Negotiables & Float Capacity**
   - Agree which blocks are truly fixed and which can shift to accommodate changes.

---

## Applying the Mid‑Week Change Rule
When a partner needs to adjust a block that **affects shared responsibilities**, the rule from [[concepts/midweek-change-rule]] is triggered:
- **Notify promptly** (as soon as the change is known).
- **Include**: what changed, any support needed, and a proposed new time.
- **Communicate via text** for simple updates; switch to a quick call only if the change creates a conflict that requires joint decision‑making.

---

## Benefits
- Minimal time investment (≈10 min weekly).
- Clear, documented understanding of each partner’s schedule.
- Flexibility to absorb unexpected events without constant renegotiation.
