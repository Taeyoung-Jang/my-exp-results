# Summary of Session 10 (2022‑05‑23)

## Core Idea: Block‑Based Weekly Planning
- Use **blocks** instead of precise time slots to structure the week. [[concepts/block-scheduling]]
- Anchor the schedule with **non‑negotiable moments** (work hours, appointments, essential errands).
- Fill remaining time with flexible blocks such as:
  - **Deep‑work blocks** (2‑3 h, 2–3 per week)
  - **Life‑admin / errand blocks** (mid‑week & weekend)
  - **Downtime blocks** (evening, Sunday afternoon)
- Include a **float block** (once or twice a week) to absorb unexpected tasks.
- Blocks can shift within the day, keeping the plan resilient.

## Spouse Coordination Workflow
- **Constraint:** Schedule must be reviewed and approved by spouse before finalizing.
- **Workflow Steps:**
  1. Each partner drafts a weekly block map (personal & shared items).
  2. In a brief **Sunday check‑in**, compare only the pieces that affect each other (shared errands, coverage needs, high‑demand commitments). [[concepts/spouse-checkin-workflow]]
  3. Confirm shared responsibilities, flag conflicts, and agree on which blocks are truly non‑negotiable.
  4. Keep personal/flexible decisions separate.
- **Mid‑week changes:** Notify the partner **only** if the change impacts a shared responsibility. Use a **text** with change description, needed support, and proposed solution; upgrade to a **quick call** when a conflict requires joint resolution. [[concepts/midweek-change-rule]]

## Concrete Template: Sunday Check‑in
### Agenda (3 passes)
1. **Non‑negotiables** – each partner reads fixed appointments and commitments.
2. **Shared items** – discuss joint errands, coverage, timing that matters to both.
3. **Flexible blocks & flex points** – confirm personal blocks and identify where surprises can be absorbed.

### Shared Notes Format (single document)
```
# This Week
## Fixed Commitments
- Partner A: …
- Partner B: …

## Shared Responsibilities
- …

## Agreed Flex Points
- …

## Change Log (mid‑week updates)
- Date – change description – resolution
```

## Default Rule for Midweek Changes
- **Notice:** As soon as a shared‑impacting change is known.
- **Info to include:** what changed, required support, proposed new timing.
- **Communication channel:** text for simple updates; call for conflicts needing negotiation. [[concepts/midweek-change-rule]]
