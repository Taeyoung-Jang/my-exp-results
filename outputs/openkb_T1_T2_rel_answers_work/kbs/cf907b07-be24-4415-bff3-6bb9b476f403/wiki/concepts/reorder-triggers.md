# Reorder Triggers

**Definition**: Simple, threshold‑based cues that tell you exactly when an item is running low enough to require restocking, minimizing decision fatigue and surprise shortages.

---

## Why they matter
- **Cognitive load reduction** – Instead of guessing, you act only when a predefined condition is met.
- **Consistency** – Uniform cues (e.g., "half pack left") keep restocking regular and prevent emergency trips.
- **Time efficiency** – Decisions happen instantly during the daily "house brain" check, keeping the routine under two minutes.

---

## Core principles (drawn from [[summaries/session-39_2025-04-17]])
1. **Clear numeric or visual threshold** – e.g., "half pack of diapers", "one unopened formula container left".
2. **Immediate capture** – When you notice the trigger, add the item to the *Running Low* section of your House Brain note.
3. **Single‑step action** – The trigger tells you exactly what to do: add to list, place an order, or buy at next errand.
4. **Contextual grouping** – Keep triggers alongside related items (Baby Essentials, Adult Essentials) for quick scanning.

## Example triggers from the source
| Category | Item | Trigger |
|----------|------|---------|
| **Baby Essentials** | diapers (current size) | add when open pack is halfway used |
| | diapers (next size) | check weekly; add when current size feels snug |
| | wipes | add when only one unopened pack remains |
| | diaper cream | add when tube is under ¼ left |
| | formula | add when one unopened container remains |
| | breast‑milk storage bags | add when box has ≤10 bags left |
| **Adult/Household** | milk | add when 1‑day supply remains |
| | coffee beans | add when half of the usual weekly stash is gone |
| | paper towels | add when only one roll left |

## How to integrate with other concepts
- Use the **[[concepts/house-brain]]** note structure to store the *Running Low* list where triggers are logged.
- Pair the daily check with a **[[concepts/daily-habit-loop]]** (e.g., after morning coffee) to ensure the cue is spotted every day.
- Combine with a **[[concepts/purchase-decision-checklist]]** to decide whether to subscribe, buy bulk, or order on‑demand when a trigger fires.

---

## Tips for maintaining effective triggers
- **Keep it simple** – One‑sentence cue per item; avoid complex calculations.
- **Make it visual** – Use symbols (★, !) or bold text to flag urgent triggers.
- **Review weekly** – During the weekly House Brain review, verify that thresholds still make sense and adjust as consumption changes.
- **Add next‑size tracking** – For growing babies, link triggers to the **[[entities/next-size-tracker]]** to anticipate upcoming size changes.
