# Next‑Size Tracker

**Entity Type:** other

The *Next‑Size Tracker* is a simple checklist component introduced in [[summaries/session-39_2025-04-17]] to help parents anticipate the point at which baby‑related items (diapers, clothes, shoes) and a few household essentials will need to be upgraded or replaced.

## Core Function
- Lists items that will soon outgrow their current size.
- Provides a **weekly** (or monthly) review cue to add a new purchase or note when the current item becomes tight or worn.
- Uses clear, low‑effort triggers (e.g., *"check when current size feels snug"*), keeping the process under two minutes a day.

## How It Appears in the House‑Brain System
- Integrated as a dedicated section within the broader **House Brain** note [[concepts/house-brain]].
- Works hand‑in‑hand with the **Baby Essentials** subsection and its **reorder triggers** [[concepts/reorder-triggers]].
- The daily check habit ties into the overall **daily‑habit‑loop** suggested for the system [[concepts/daily-habit-loop]].

## Example Entries (Copy‑Paste Template)
```markdown
Next‑Size Tracker
clothes (next size) – check weekly; add when current size fits snugger
 diapers (next size) – check weekly; add when current size feels snug
 shoes/socks – check monthly; add when they start leaving marks
```

## Related Entities & Concepts
- Related to the broader **Baby Essentials** collection [[entities/baby-essentials]].
- Part of the same organizational framework that includes concepts such as [[concepts/house-brain]], [[concepts/reorder-triggers]], and [[concepts/daily-habit-loop]].

## Benefits
1. **Prevents surprise shortages** by catching size transitions early.
2. **Reduces decision fatigue** – the trigger tells you exactly when to act.
3. **Keeps the overall system lightweight**, fitting the goal of a < 2‑minute daily review.
