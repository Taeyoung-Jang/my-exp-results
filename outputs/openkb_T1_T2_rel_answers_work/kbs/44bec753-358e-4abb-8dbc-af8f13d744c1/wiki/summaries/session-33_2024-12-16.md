## Summary of session-33_2024-12-16

**Context:** The user needs a reliable system to plan a gala‑style event without losing track of guest counts, dietary restrictions, vendors, timelines, and budget.

**Key Recommendations**
- Create a single **source of truth** – a shared spreadsheet that houses all event data.
- Structure the spreadsheet with four tabs: **Guest List**, **Vendors**, **Run of Show**, **Budget**.
- Use specific column headers for each tab to capture essential information (e.g., RSVP Status, Meal Type, Deposit Due Date, etc.).
- Add live calculations: headcount, dietary totals, budget summaries.
- Implement **conditional formatting** to flag missing meals, overdue payments, or unassigned responsibilities.

**Final Headcount Protection**
1. Add a separate **Final** tab that references the live headcount.
2. Protect the entire **Final** sheet (or just the final‑headcount cell) so only the owner can edit it.
3. Hide or lock the live‑count cell in the Guest List tab to avoid accidental edits.

**Caterer Export Tab**
- A dedicated tab that only pulls the protected final headcount and dietary counts.
- Formulas (Google Sheets syntax) used:
  - `=COUNTIF('Guest List'!D:D,"Yes") + COUNTIF('Guest List'!H:H,"<>")` → Final Headcount (incl. plus‑ones)
  - `=COUNTIF('Guest List'!E:E,"Vegetarian") + COUNTIF('Guest List'!H:H,"Vegetarian")` → Vegetarian total
  - `=COUNTIF('Guest List'!E:E,"Vegan") + COUNTIF('Guest List'!H:H,"Vegan")` → Vegan total
  - `=COUNTIF('Guest List'!E:E,"Gluten-Free") + COUNTIF('Guest List'!H:H,"Gluten-Free")` → Gluten‑Free total
  - `=COUNTIFS('Guest List'!D:D,"Yes",'Guest List'!E:E,"") + COUNTIFS('Guest List'!D:D,"Yes",'Guest List'!H:H,"")` → Missing Meal Choice count

**Google Sheets Click‑by‑Click Protection Steps**
1. Protect entire **Final** sheet via “Protect sheet” → permissions → owner only.
2. Protect only the **Final Headcount** cell via “Protect range” → set owner‑only editing.
3. Create **CATERER EXPORT** tab, reference the protected cells, then protect the tab to keep it immutable.
