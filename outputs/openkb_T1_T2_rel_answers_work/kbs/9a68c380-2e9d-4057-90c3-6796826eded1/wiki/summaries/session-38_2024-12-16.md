## Summary

This document captures a concise, device‑agnostic **grab‑and‑go** workflow for mornings spent on shared or loaner tablets. The core ideas are:

- **Standardize the first 2–3 minutes** with a *cloud‑anchor* that lives online and can be opened from any browser, making the routine independent of the specific device layout. [[concepts/cloud-anchor]]
- Use a **fill‑in‑the‑blanks “Morning Reset” template** that can be duplicated daily in any plain‑text note or email. The template includes fields for date, mood, a single noon‑goal, top task, support steps, workspace check, and block start time. [[concepts/morning-reset-template]]
- Follow a **short mental script**: power on tablet → connect Wi‑Fi → open browser → load the cloud note → complete the template → silence notifications → start the first work block. This keeps the routine consistent across locations. [[concepts/device-agnostic-routine]]
- End each session with a **compact shutdown script** that ensures no personal accounts remain logged in: save work, sign out of every site/app, close all tabs, close the browser fully, and verify the device is left clean for the next user. [[concepts/shutdown-script]]
