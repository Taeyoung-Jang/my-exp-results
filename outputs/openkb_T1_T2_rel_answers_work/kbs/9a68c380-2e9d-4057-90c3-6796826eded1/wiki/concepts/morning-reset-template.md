# Morning Reset Template

**Definition**: A plain‑text, fill‑in‑the‑blanks checklist designed to be duplicated each day and stored in an online *cloud anchor* so it can be accessed from any loaner tablet.

---

## Purpose
The template supports a **[[concepts/grab-and-go-workflow]]** by providing a consistent mental and written routine that does not depend on any specific device configuration. It is the core of the **[[concepts/device-agnostic-routine]]** described in [[summaries/session-38_2024-12-16]].

---

## Template Layout
```
Morning Reset
Date: __________
How I’m feeling (one line): __________
One thing I want done by noon: __________
Top task for the day: __________
Support steps (2–3 short actions): __________
Workspace check (Wi‑Fi, quiet mode, timer): __________
First work block starts at: __________
```

Each field is a single line that can be quickly filled in within the first 2–3 minutes of the session.

---

## How It Works
1. **Cloud Anchor** – Save the template in a cloud note, bookmarked page, or emailed copy. Because it lives online, any tablet with a browser can load it instantly (see [[concepts/cloud-anchor]]).
2. **Copy‑Paste Daily** – Duplicate the template each morning, fill in the blanks, and use it to set intentions and verify the workspace.
3. **Trigger Ritual** – Reading and completing the fields creates a mental cue that transitions you into focused work, reinforcing the grab‑and‑go habit.

---

## Relationship to Other Concepts
- Acts as the **anchor point** for the device‑agnostic start‑up routine ([[concepts/device-agnostic-routine]]).
- Complements the **shutdown script** ([[concepts/shutdown-script]]) by clearly delimiting the start and end of a shared‑device session.
- Helps mitigate **lock‑in** and **automation resilience** concerns by keeping the workflow simple and portable, though those concepts are not directly addressed here.

---

## Benefits
- **Zero setup friction** – works on any tablet, no app installation required.
- **Consistency** – same fields every day enforce a repeatable mental routine.
- **Security** – minimal personal data is stored on the device; everything lives in the cloud.
- **Scalability** – can be extended with additional sections without breaking the core flow.

---

## Usage Example
1. Power on the loaner tablet.
2. Connect to Wi‑Fi.
3. Open the browser and navigate to the cloud‑stored template.
4. Fill in the blanks (≈2 minutes).
5. Silence notifications, start a timer, and begin the first work block.
