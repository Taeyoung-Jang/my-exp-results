# Device‑Agnostic Routine

**Definition**: A repeatable, device‑independent start‑up process that lets you begin productive work within 2–3 minutes on any shared or loaner tablet.

---

## Overview
The routine is built around three pillars:
1. **Cloud Anchor** – a single online note or bookmarked page that hosts the daily checklist.
2. **Morning Reset Template** – a fill‑in‑the‑blanks form that can be duplicated each day.
3. **Shutdown Script** – a concise logout and cleanup procedure for shared devices.

These elements keep the workflow consistent across locations and devices, eliminating the need to rely on a specific app layout or personal hardware.

---

## Core Steps (First 2–3 Minutes)
1. Power on the tablet and connect to Wi‑Fi.
2. Open a web browser (avoid hunting through the home screen).
3. Navigate to the **cloud anchor** (e.g., a Google Docs note, Evernote, or emailed checklist).
4. Complete the **Morning Reset Template**:
   - Date, mood, noon goal, top task, support steps, workspace check, block start time.
5. Silence notifications, set a timer, and start the first work block.

---

## Cloud Anchor
The cloud anchor is a device‑agnostic entry point that lives online, ensuring the same checklist is reachable from any browser. It can be a simple plain‑text note, a bookmarked page, or an email to yourself. See [[concepts/cloud-anchor]] for more details.

---

## Morning Reset Template
A plain‑text, fill‑in‑the‑blanks form that can be duplicated daily. Example:
```
Morning Reset
Date: __________
How I’m feeling (one line): __________
One thing I want done by noon: __________
Top task for the day: __________
Support steps (2–3 short actions): __________
Workspace check (Wi‑Fi, quiet mode, timer): __________
First work block starts at: __________
```
This template is deliberately minimal to keep decision‑fatigue low. It aligns with the broader [[concepts/morning-reset-template]] pattern.

---

## Shutdown Script
At the end of the session, run this short script to leave the tablet clean for the next user:
- Save any work.
- Sign out of every site or app used.
- Close all browser tabs.
- Close the browser completely.
- Verify no personal information remains open.

This script supports shared‑device security and ties into [[concepts/shutdown-script]].

---

## Benefits
- **Consistency**: Same mental ritual regardless of hardware.
- **Resilience**: Reduces reliance on any single device or ecosystem (see [[concepts/automation-resilience]] and [[concepts/lock-in-mitigation]]).
- **Speed**: Enables a productive start within minutes.
- **Security**: Guarantees personal accounts are logged out before the device is handed over.
