# Cloud Anchor

**Definition**: A cloud‑anchor is a single online location (e.g., a note, bookmarked page, or self‑emailed checklist) that can be opened from any browser, providing a consistent launch point for a morning routine regardless of the physical device.

**Why it matters**
- Enables a [[concepts/device-agnostic-routine]] by decoupling the workflow from specific apps or UI layouts.
- Supports a [[concepts/grab-and-go-workflow]] where the user can pick up any loaner tablet and start immediately.
- Reduces reliance on personal hardware, mitigating [[concepts/lock-in-mitigation]] and enhancing [[concepts/automation-resilience]].

**Key characteristics**
1. **Universal accessibility** – stored in the cloud, reachable via a simple URL or search.
2. **Plain‑text format** – ensures compatibility across note‑taking apps, email clients, and browsers.
3. **Template embedding** – contains the [[concepts/morning-reset-template]]
