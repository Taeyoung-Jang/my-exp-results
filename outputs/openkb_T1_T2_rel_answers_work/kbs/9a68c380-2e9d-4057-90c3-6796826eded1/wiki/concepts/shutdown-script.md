# Shutdown Script

A **shutdown script** is a concise, repeatable set of actions executed at the end of a work session to ensure that no personal data, accounts, or open applications are left on a shared or loaner device. The goal is to protect privacy, maintain device hygiene, and prepare the hardware for the next user with minimal friction.

## Core Steps (as defined in the source)
1. **Save any work** – Ensure all documents, notes, or files you need are stored locally or in the cloud.
2. **Sign out of every site or app** – Explicitly log out of email, productivity tools, and any services you accessed.
3. **Close all browser tabs** – End the browsing session completely.
4. **Close the browser** – Exit the browser application so no background processes remain.
5. **Verify no personal content is open** – Do a quick visual scan for any lingering windows or notifications.
6. **Leave the tablet clean** – Set the device down ready for the next person.

These actions were crafted to be device‑agnostic, meaning they work the same whether you are on a loaner tablet from the office, a family member’s device, or any other shared hardware.
