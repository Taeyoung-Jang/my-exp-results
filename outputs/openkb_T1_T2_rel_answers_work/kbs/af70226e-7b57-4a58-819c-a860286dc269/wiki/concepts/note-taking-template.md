# Note‑Taking Template

**Definition**: A concise, repeatable note‑taking structure designed to capture the most important information from a study session while minimizing transcription time.

## Template Layout
```
Topic:
Key ideas (short sentences):
Examples or details I might need later:
Questions to resolve:
Quick summary in two or three lines:
```

## How to Use
- **During focused work blocks** (as described in [[concepts/study-routine]]), fill in each section in your own words.
- **For video lessons**, pause only when a key point or question arises, then jot it into the appropriate field.
- **For textbook chapters**, skim headings first, then summarize each chunk using the template.
- **At the end of the session**, review the completed template to reinforce recall and identify any unresolved questions.

## Benefits
- **Consistency**: Provides a uniform format across different subjects and media types.
- **Active processing**: Forces you to rephrase concepts, aiding comprehension and memory.
- **Quick review**: The concise sections make later spaced review (see [[concepts/spaced-review]]) efficient.

## Relationship to Other Concepts
- Works hand‑in‑hand with the **90‑minute study routine** outlined in [[summaries/session-10_2024-10-13]].
- Supports the **spaced‑review** workflow by producing clear, bite‑sized notes that are easy to revisit.
