# Curbside Pickup

**Definition**: A retail service that allows customers to place an order remotely and retrieve it from a designated curbside window or drive‑up lane, eliminating the need to enter the store and minimizing walking distance.

## Core Elements
- **Remote Ordering**: Customers order via an app or website before arriving.
- **Check‑in Timing**: A brief "I’m on my way" or "check‑in" step signals the store to stage the order.
- **Designated Pickup Spot**: A curbside window, drive‑up lane, or dedicated parking space where staff bring the order to the vehicle.
- **Rapid Handoff**: The transaction is completed at the vehicle, often with a QR code or order number.

## Benefits Highlighted in [[summaries/session-34_2025-10-08]]
- **Reduced Walking**: Critical for users with mobility constraints (e.g., a walking boot). 
- **Time Efficiency**: Allows precise timing windows (e.g., check‑in at 8:50 am for a Target order). 
- **Flexibility**: Can be combined with other errands; if a delay occurs, the user can bail to another stop and re‑check‑in.

## Practical Tips (from the source session)
1. **Check‑in early** – In the example, the user checks in at 8:50 am when leaving at 8:45 am, giving the store time to stage the order.
2. **Cancel if delayed** – If the pickup is delayed >5‑6 minutes, cancel the check‑in and handle another errand before returning.
3. **Combine with Drive‑Through** – Pair curbside pickup (Target) with drive‑through services (CVS) for a seamless, low‑walk experience.
