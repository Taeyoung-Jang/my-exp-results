## Old Navy

Old Navy is a U.S. clothing retailer owned by Gap Inc. It offers casual apparel for the whole family. In the context of **[[summaries/session-34_2025-10-08]]**, Old Navy is the location for a clothing return that **must be done in‑store**, unlike the curbside options available at Target and CVS.

### Role in the errand plan
- The return to Old Navy is scheduled after completing an Amazon return at **[[entities/kohls]]**.
- Because the line can become long, the plan recommends:
  1. Parking near Kohl’s (see **[[concepts/parking-strategy]]**) and walking a short distance to Old Navy.
  2. Asking an associate for a side register if the main returns line is backed up.
  3. If the line is too long, postponing the return to Sunday opening time.
