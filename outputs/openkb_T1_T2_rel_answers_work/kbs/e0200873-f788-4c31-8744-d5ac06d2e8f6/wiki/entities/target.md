# Target (Organization)

**Overview**
Target is a large U.S. retail corporation that provides a "Drive Up" curbside pickup service. In the context of the errand plan from [[summaries/session-34_2025-10-08]], Target serves as the primary grocery stop.

**Key Facts from the Session**
- **Service Utilized:** Drive Up curbside pickup, allowing the user to stay in the car while the order is brought to the vehicle.
- **Timing Recommendation:** Check‑in for Drive Up at 8:50 a.m. when leaving the house at 8:45 a.m., ensuring the order is ready shortly after arrival.
- **Backup Procedure:** If the order is delayed beyond ~6 minutes, the user should cancel the check‑in, run the CVS drive‑thru, then re‑check‑in on the return trip.
