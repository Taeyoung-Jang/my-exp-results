# Amazon

Amazon is a worldwide e‑commerce organization that offers customers the ability to return purchases at partner locations, such as Kohl’s, using QR codes and without the need for a physical box. In the errand plan outlined in [[summaries/session-34_2025-10-08]], the user will complete an Amazon return at the Kohl’s store within a larger [[concepts/errand-planning]] workflow that emphasizes minimal walking and efficient use of curbside‑friendly services.

The return process ties into the broader [[concepts/curbside-pickup]] strategy, even though the Kohl’s return is performed inside the store, because it leverages a quick, drive‑up style service. The plan also incorporates [[concepts/parking-strategy]] advice for the Kohl’s/Old Navy shopping center to keep walking distances short.

Related entities mentioned in the same plan include [[entities/kohls]], and the overall schedule is documented in the summary of the session.
