# Python (product)

Python is a high‑level, interpreted programming language known for its readability and extensive standard library. It is the primary language used in the study plan outlined in [[summaries/session-38_2024-12-13]], where students allocate practice sessions and build small projects such as a weather CLI tool and a JSON‑based habit tracker.

## Key facts from the session‑38 study plan
- **Practice focus**: The weekly schedule includes dedicated Python exercise blocks on Monday and Wednesday to reinforce core concepts like list comprehensions, data structures, and error handling.
- **Project work**: Two mini‑projects are suggested using Python:
  1. An **API project** that queries the Open‑Meteo weather service via HTTP requests (leveraging the [[entities/requests]] library) and parses JSON responses.
  2. A **file‑based project** that stores data in a JSON file (related to [[entities/json-format]]) or CSV (related to [[entities/csv-format]]) for habit tracking or bookmark management.
- **Tools & libraries**: The plan recommends using the `requests` library for HTTP calls and the built‑in `json` module for data persistence.
