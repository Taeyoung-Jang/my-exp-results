# Learning Log Template

A **learning log template** is a brief, repeatable format that captures what you did, where you got stuck, and what to focus on next. It turns a casual note‑taking habit into a reflection tool that drives continuous improvement.

## Core Sections
1. **What I worked on** – a short description of the topic, exercise, or project (e.g., *list comprehensions* or *Open‑Meteo weather script*).  
2. **What confused me** – specific roadblocks, error messages, or concepts that didn’t click.  
3. **What clicked** – the insight or solution that resolved a problem.  
4. **Next steps** – a concrete action for the following session (e.g., *review error handling* or *add caching*).

## Example Entry (from [[summaries/session-38_2024-12-13]])
```
Today I practiced list comprehensions, struggled with condition order, but it clicked after a few examples.
In the API project I fetched weather data and parsed JSON, though handling missing fields took longer.
Next time I’ll review error‑handling and add simple caching.
```

## Why Use It?
- **Focused review** – forces you to identify patterns and gaps.
- **Easy to skim** – a few lines per session keep the log lightweight.
- **Actionable** – the *next steps* line creates a clear agenda for the next study block.
