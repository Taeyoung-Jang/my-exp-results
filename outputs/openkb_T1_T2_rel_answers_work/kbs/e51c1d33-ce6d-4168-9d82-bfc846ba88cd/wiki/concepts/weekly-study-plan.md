# Weekly Study Plan

**Definition**: A recurring, time‑boxed routine that allocates a total of 5–7 hours per week to Python learning. It balances short practice sessions, a modest API‑driven project, a file‑based project, and a brief review/logging step.

## Core Structure (from [[summaries/session-38_2024-12-13]])
- **Monday – 1 h practice** – focused Python exercises on the week’s primary concept (e.g., list comprehensions).  
- **Wednesday – 1 h practice** – a different topic to reinforce variety and prevent stagnation.  
- **Friday – 3 h API project** – build a small command‑line tool using [[entities/open-meteo]] (weather) or another public API, following the [[concepts/api-project-workflow]].  
- **Sunday – 2 h file‑based project** – create a JSON‑backed habit tracker or bookmark manager (see [[entities/json-format]] vs [[entities/csv-format]] decision).  
- **End‑of‑week 10 min review** – answer a reusable checklist, record outcomes in a learning log (see [[concepts/learning-log-template]]).

## Reusable Session Checklist
**Start**
- What am I focusing on today?
- What is the smallest goal I want to finish?

**End**
- What did I complete?
- What confused me?
- What should I tackle next time?

## Learning Log Template
Capture for each session:
1. Topic / project name
2. Key actions taken
3. Points of confusion or error
4. Insight or breakthrough
5. Next steps

This template aligns with the [[concepts/learning-log-template]] concept and encourages meta‑cognition.

## Practical Implementation Details
- **Tools**: Python ( [[entities/python]] ), `requests` library ( [[entities/requests]] ) for API calls.
- **Data storage**: Prefer [[entities/json-format]] for hierarchical project data; use [[entities/csv-format]] when a flat table suffices.
- **Flexibility**: Adjust day order or total hours to fit personal schedules while preserving the ratio of practice : project : review.
