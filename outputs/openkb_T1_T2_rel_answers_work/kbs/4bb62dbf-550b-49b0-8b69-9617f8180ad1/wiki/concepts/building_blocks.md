# Building Blocks (Batch Cooking)

**Definition**: A meal‑prep strategy that creates a set of versatile base components—grains, proteins, and vegetables—each cooked in bulk and stored separately so they can be recombined into multiple, distinct dishes throughout the week.

## Core Principles
- **Separate base components**: Cook one grain (e.g., [[entities/quinoa]]), roast a sheet‑pan of mixed vegetables (e.g., [[entities/sheet-pan]] with broccoli, peppers, onions), and prepare two proteins (e.g., [[entities/chicken-thighs]] and [[entities/tofu]]). 
- **Uniform storage & labeling**: Place each component in its own clearly labeled container using a consistent "Prep — Use by" scheme (see [[concepts/meal_prep_labeling]]). 
- **Grab order**: Retrieve components in the same sequence each night—grain, veg, protein, sauce—to make the process automatic (see [[concepts/grab_order]]). 
- **Flavor diversification**: Apply a small set of sauces (e.g., [[entities/cilantro-lime-sauce]] and [[entities/soy-ginger-sauce]]) to the same base, creating distinct cuisines without extra cooking time.

## Application in Session 36 (2025‑02‑12)
The Sunday workflow outlined in [[summaries/session-36_2025-02-12]] is a concrete example of building blocks:

1. **Time‑boxed prep** – quinoa (2:00‑2:15), roasted veggies (2:15‑2:35), chicken thighs (2:20‑2:45), tofu (2:20‑2:35), sauces (2:40‑2:55). 
2. **Component labeling** – containers read "Quinoa — Sun Prep — Use by Fri" etc., supporting rapid identification. 
3. **Daily recombination** – five nights of meals each use the same grain, veg, and one protein, but differ in sauce and seasoning to achieve Mexican, Asian, curry, Mediterranean, and comfort‑style profiles.

## Benefits
- **Time efficiency**: Bulk cooking saves >1 hour of active cooking time per week.
- **Reduced waste**: Ingredients are used across multiple meals, minimizing leftovers.
- **Variety without complexity**: Flavor changes come from sauces and quick add‑ins rather than new cooking steps.
- **Predictability**: Consistent labeling and grab order eliminate decision fatigue on busy nights.
