# Lab Safety Protocol

**Definition:** A set of coordinated practices that ensure hands‑on lab activities remain exciting while preventing accidents and minimizing chaos.

## Overview
The protocol is designed for short, intensive lab openings (10‑15 minutes) and emphasizes:
- Clear *workspace zones* for materials, mess, and finished work.
- Assigned *roles* within each group to distribute tasks.
- A concise safety briefing that includes goggles, gloves, and proper handling of sharp tools.

## Core Elements
1. **Safety Demonstration** – Model the correct handling of a [[entities/scalpel]] (pointed down, set‑down motion) before students touch it.
2. **Protective Gear** – Require [[entities/goggles]] and [[entities/gloves]] for every student before any tool is distributed.
3. **Waste Management** – Identify the [[entities/waste-bin]] and the [[entities/sink]] for sharps and liquid waste; students must state where each belongs.
4. **Rapid Group Check** – A “group safety pass” where each group shows three items (scalpel set‑down, waste location, gear ready) before receiving tools.

## Step‑by‑Step Opening (0‑15 min)
| Time | Action |
|------|--------|
| 0‑1 min | Gather students, preview the specimen (curiosity hook). |
| 1‑3 min | Demonstrate the scalpel set‑down motion using a sheathed [[entities/scalpel]]. |
| 3‑4 min | Students mime the motion with empty hands. |
| 4‑6 min | Explain goggles, gloves, and clear workspace; point to [[entities/goggles]], [[entities/gloves]], [[entities/waste-bin]], and [[entities/sink]]. |
| 6‑10 min | Conduct a quick “group safety pass” – ask each group to: (a) demonstrate safe set‑down, (b) name the waste location, (c) show gear ready. |
| 10‑12 min | Uncover specimens, remind that tools follow the pass. |
| 12‑15 min | Distribute tool trays to groups that passed the check and begin the lab. |

## Group Safety Pass Card
- Demonstrate safe scalpel set‑down.
- Identify the correct waste‑disposal spot.
- Show goggles, gloves, and a tidy workspace.
