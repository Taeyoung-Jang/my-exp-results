# Relocation Timeline Milestones

**Definition**: A structured, month‑by‑month framework that breaks an international move into logical phases, distinguishing critical (must‑do) actions from optional (nice‑to‑have) tasks and estimating typical durations.

## Core Structure
| Phase | Typical Months before Move | Must‑do Tasks | Nice‑to‑have Tasks | Typical Duration |
|-------|----------------------------|--------------|-------------------|------------------|
| **Initial Planning** | 1‑2 months | Confirm program requirements, validate passport, start visa prep | Outline budget, basic savings target | 1‑4 weeks per task |
| **Visa & Finance** | 3‑4 months | Submit visa application, research banking options | Learn local housing norms | 1‑2 weeks for research, 6‑12 weeks for visa processing |
| **Housing & Healthcare** | 5‑6 months | Secure temporary housing, arrange immunizations/insurance | Sort belongings for sale or storage | 1‑3 weeks each |
| **Travel & Home Closure** | 7‑9 months | Book flights, close leases/utilities, network with future contacts | Deep‑dive housing market research | 1‑2 weeks for flight booking, ongoing for closures |
| **Final Preparations** | 10‑12 months | Final medical checks, pack, digitize documents, confirm arrival logistics | Create first‑week itinerary, contingency planning for visa delays | 1‑2 weeks per task |

### Key Features
- **Must‑do vs Nice‑to‑have**: Highlights actions that are essential to avoid legal or logistical roadblocks, while optional tasks improve comfort and efficiency.
- **Time Estimates**: Provides realistic windows (e.g., visa processing 6‑12 weeks) to help set deadlines.
- **Contingency Slots**: Includes optional rows for visa‑delay actions such as expedited review requests or refundable travel arrangements.
- **Simple Tracking Integration**: Designed to pair with a lightweight status‑tracking system [[concepts/task-status-tracking]] and a basic spreadsheet template (see [[entities/google-sheets]]). 

## How to Use
1. **Set a target move month** (e.g., November 2026) and work backwards to assign concrete dates to each deadline.
2. **Populate a tracking sheet** with columns for task, category, must‑do/nice, target deadline, status, and notes.
3. **Apply the 15‑minute weekly review routine** to keep the timeline current and address any delays promptly.
