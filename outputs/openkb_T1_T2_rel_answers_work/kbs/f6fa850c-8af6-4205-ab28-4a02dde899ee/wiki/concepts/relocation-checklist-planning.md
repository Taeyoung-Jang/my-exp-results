# Relocation Checklist Planning

**Definition**: A systematic method for designing a detailed, month‑by‑month relocation checklist that balances essential tasks (must‑do) with optional enhancements (nice‑to‑have), integrates contingency steps, and ties directly to a tracking tool.

## Core Elements
1. **Phase‑Based Timeline**
   - Break the preparation period into logical intervals (e.g., months 1‑2, 3‑4, 5‑6, 7‑9, 10‑12).  Each phase groups related tasks so the workload stays manageable.
   - Align tasks with typical processing times (passport renewal, visa processing, housing search, etc.).

2. **Must‑Do vs. Nice‑to‑Have**
   - Flag every item as *must‑do* (critical for a successful move) or *nice‑to‑have* (adds convenience but can be delayed).
   - This binary priority supports quick triage during weekly reviews.

3. **Contingency Planning**
   - Include backup actions for high‑risk steps, especially visa timelines (e.g., expedited review request, refundable flight booking).
   - Treat contingencies as *nice* items that become *must‑do* if a trigger occurs.

4. **Task Status Tracking**
   - Use a simple tool (e.g., a Google Sheet) with columns for task, category, priority, deadline, status, and notes.
   - Populate the **Status** column with a dropdown list: `Not started`, `In progress`, `Waiting on others`, `Completed`, `Blocked`.
   - See [[concepts/task-status-tracking]] for more detail.

5. **Weekly 15‑Minute Review Routine**
   - Scan tasks due in the next 2‑3 weeks.
   - Update statuses, add small new tasks, and pick one priority for the coming week.
   - Sort or filter by status to keep active items at the top.

## Example Alignment with Source Document
The checklist design mirrors the structure presented in [[summaries/session-31_2024-05-15]]:
- **Months 1‑2** focus on documentation and visa prep.
- **Months 3‑4** address visa submission, banking research, and housing norms.
- **Months 5‑6** cover temporary housing, healthcare, and early packing.
- **Months 7‑9** handle flight booking, domestic closures, and networking.
- **Months 10‑12** finalize medical checks, packing, digital backups, and arrival logistics.
