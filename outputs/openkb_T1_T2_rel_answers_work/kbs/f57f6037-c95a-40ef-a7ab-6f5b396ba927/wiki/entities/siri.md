# Siri (product)

**Overview**
Siri is Apple’s built‑in voice‑activated assistant that lets users control iPhone functions without touching the screen. It can launch apps, play media, adjust volume, and set timers using natural language commands.

**Key facts from [[summaries/session-34_2024-11-12]]**
- The document recommends enabling *Hey Siri* (Settings → Siri & Search) to allow hands‑free playback control for one‑handed evening routines.
- Siri is paired with the iPhone’s *Voice Control* (Settings → Accessibility → Voice Control) to issue commands like “Tap play,” “Pause,” “skip forward thirty seconds,” and “set a timer for 20 minutes.”
- The workflow uses Siri to start a silent sleep‑timer via the **Clock** app (Settings → Clock → Timer → *Stop Playing*) so audio stops automatically without a loud alarm.
- Siri is highlighted as a core tool for managing the curated free audio resources and maintaining a low‑effort, wrist‑brace‑friendly evening script.

**Setup steps (one‑time)**
1. Open **Settings → Siri & Search** and enable **Listen for “Hey Siri”** and **Allow Siri When Locked**.
2. Open **Settings → Accessibility → Voice Control** and toggle it on; let the download finish.
3. (Optional) Enable **Attention Aware** under Siri & Search for better responsiveness when the phone lies flat.
4. Adjust **Settings → Display & Brightness → Auto‑Lock** to a longer interval for the evening.

**Typical voice commands for the evening scripts**
- “Hey Siri, pause” / “Hey Siri, play”
- “Hey Siri, skip forward thirty seconds” / “skip back thirty seconds”
- “Hey Siri, volume up” / “volume down”
- “Hey Siri, set a timer for 20 minutes” (uses the pre‑configured *Stop Playing* timer)
- “Hey Siri, open YouTube” (or “open Safari”) to start the selected free audio track.

**Usage tip**
Place the iPhone on a stable surface (e.g., a mug or book) after starting the audio, then lock the screen. Siri will handle all subsequent play/pause, volume, and timer actions without needing the braced wrist.
