# Clock app (iOS)

The **Clock app** is a built‑in utility on the iPhone that includes an alarm, world clock, stopwatch, and a timer. In the context of [[summaries/session-34_2024-11-12]], it is highlighted for its *Stop Playing* timer option, which silently halts any audio (e.g., YouTube, Librivox) without emitting a loud alarm sound—ideal for one‑handed evening routines.

## Key facts from the session
- **Silent sleep timer**: Within the Clock app, go to the *Timer* tab, tap *When Timer Ends*, scroll to the bottom and select *Stop Playing*. This makes the timer act as a quiet cutoff for audio.
- **Hands‑free activation**: After enabling *Hey Siri* (via [[entities/siri]]) or *Voice Control* (via [[entities/iphone]]), you can say, “Hey Siri, set a timer for 30 minutes,” and the pre‑configured *Stop Playing* action will automatically stop playback.
- **Integration with one‑handed routines**: The timer supports the low‑effort, one‑handed evening scripts outlined in [[concepts/evening-routines]] and [[concepts/one-handed-activities]], allowing the user to relax without worrying about manually stopping audio.
