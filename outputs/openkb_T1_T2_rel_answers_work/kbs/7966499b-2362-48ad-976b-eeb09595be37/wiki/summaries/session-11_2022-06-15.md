# Summary of session-11_2022-06-15

**Context** – The user trains at sea level and wants concrete advice for 60–90 minute runs in warm, humid conditions, covering pacing, fluid/electrolyte intake, heat acclimation, and practical “if/then” rules.

## Key Points

- **Pacing**: No altitude‑related slowdown is needed; sea‑level runners can maintain or slightly increase pace compared to moderate‑altitude peers. Aim for an easy, conversational effort, especially in heat.

- **Hydration**:
  - Recommended fluid intake **300–500 ml / hour** in warm, humid weather (≈ a standard 500 ml bottle per hour).
  - Practical rule: sip every 10–15 minutes; adjust by thirst.
  - **Signs of under‑hydration**: rising heart rate at same effort, fatigue, fogginess, dry mouth.
  - **Signs of over‑hydration**: stomach sloshing, nausea, bloating.
  - See [[concepts/hydration_guidelines]] for broader guidance.

- **Electrolytes (Sodium)**:
  - Add **300–500 mg / hour** if run > 90 minutes, you’re a salty sweater, or you notice salt streaks on clothing.
  - For runs < 90 minutes, supplemental sodium is often unnecessary.

- **Heat Acclimation**: Independent of altitude; at sea level it’s easier. Begin with short, modest‑intensity exposures and allow 1–2 weeks for adaptation. See [[concepts/heat_acclimation]].

- **Simple “If/Then” Plan**:
  - **If** temperature ≥ mid‑70°F **and** humidity high → drink 350–500 ml / hr.
  - **If** run exceeds 90 min → add 300–500 mg sodium for the second hour.
  - **If** doing intervals (high HR) → lean toward the higher fluid range.
  - **If** easy run → stay closer to thirst‑guided intake.
  - **If** you want precise tuning → weigh before and after runs; aim for ≤ 1–2 % body‑weight loss.
  - This structured guidance follows [[concepts/if_then_planning]].

- **Practical Carry Strategy**:
  - Use a single 500 ml bottle with pre‑mixed electrolytes for hot, humid interval sessions.
  - Optionally split into water + electrolyte capsule if you tolerate mixes poorly.
