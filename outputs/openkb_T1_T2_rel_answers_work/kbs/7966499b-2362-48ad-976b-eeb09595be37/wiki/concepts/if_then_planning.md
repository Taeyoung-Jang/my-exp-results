# If/Then Planning

**Definition**

If/Then Planning is a concise, conditional decision‑making approach that translates environmental and workout variables into clear, actionable guidelines for runners. By framing advice as “if X then Y”, athletes can quickly determine fluid, electrolyte, pacing, and acclimation strategies without extensive calculation.

**Key Elements from session‑11_2022‑06‑15**

- **Temperature & Humidity** – If the temperature is at or above the mid‑70°F range *and* humidity is high, aim to drink **350–500 ml per hour**.
- **Run Duration** – If a run exceeds **90 minutes**, add **300–500 mg of sodium** for the second hour (or for any additional hour).
- **Effort Type** – If the workout involves **intervals or high heart‑rate effort**, lean toward the higher end of the fluid range; if it is an **easy, conversational run**, stay closer to thirst‑guided intake.
- **Weight‑Based Tuning** – If you choose to weigh yourself before and after, aim for a post‑run weight loss of **1–2 %** of body weight. Adjust fluid intake up if loss exceeds this range, down if you gain weight.
- **Practical Carry Strategy** – If the run is hot, humid, and includes intervals, a **single 500 ml bottle with mixed electrolytes** is the simplest option; otherwise, a split system (water + electrolyte capsule) can be used.

**Why It Works**

The format reduces cognitive load during runs, ensuring that hydration and electrolyte decisions are made consistently. It also integrates with broader concepts such as [[concepts/hydration_guidelines]] for fluid strategy and [[concepts/heat_acclimation]] for managing thermal stress.
