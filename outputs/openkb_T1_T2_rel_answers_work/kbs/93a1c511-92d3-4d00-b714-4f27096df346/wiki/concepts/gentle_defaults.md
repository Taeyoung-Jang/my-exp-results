# Gentle Defaults

**Definition**: Gentle defaults are intentional, low‑friction configurations that nudge users toward desired digital habits while preserving flexibility, making the habit‑change process feel natural rather than punitive.

## Core Principles
- **Low friction**: Small obstacles (e.g., moving apps off the home screen, brief app‑timer prompts) create a moment of reflection without forcing a hard stop.
- **Default settings over bans**: Settings such as [[concepts/fractional_friction]] or scheduled downtimes act as the *default* state, so the user only needs to deviate intentionally.
- **Preserve choice**: Users retain the ability to override when truly needed, but the default environment discourages casual mindless scrolling.
- **Automation**: Leveraging built‑in tools like [[entities/screen_time]] on an [[entities/iphone]] ensures the defaults stay in place without daily user effort.

## Application in Session‑34 (2024‑06‑15)
In the conversation summarized in [[summaries/session-34_2024-06-15]], gentle defaults were proposed as the cornerstone of a sustainable digital‑wellness routine:
1. **App placement** – moving social apps into a hidden folder or off the home screen creates a visual barrier, turning the default visual field into a healthier one.
2. **Screen Time limits** – configuring minimal daily allowances (e.g., 1 minute) for specific apps on weekdays while leaving weekends unrestricted establishes a default that aligns with the user’s weekly rhythm.
3. **Notification silencing** – turning off non‑essential notifications removes the constant pull, making the default state a quieter phone.
4. **Downtime scheduling** – setting a weekday‑only downtime period creates an automated block that only lifts on weekends.

## Benefits
- **Reduced reliance on willpower** – the environment does the heavy lifting, so the user isn’t constantly battling urges.
- **Consistency** – once set, the defaults operate autonomously, providing a "set it and forget it" experience.
- **Scalability** – the same approach can be extended to other apps or devices, adapting to changing habits.
