# Meal Prep Timeline

**Definition**: A structured schedule that breaks food‑preparation tasks into short, repeatable blocks (often 30‑minute intervals) across the day before and the day of service.

## Core Elements
- **Two‑day scope** – tasks are split between the evening before the event and the morning of the event.
- **30‑minute blocks** – each block is a focused work period, making the timeline easy to fit into busy schedules.
- **Clear start/end times** – the timeline lists exact clock times (e.g., 6:00 pm–6:30 pm) so users can plan around other commitments.
- **Task categories** – typically includes cooking grains, making dressings, chopping vegetables, assembling, and final packing.

## Example from [[summaries/session-40_2025-04-16]]
The session created a concrete timeline for a wheat‑berry salad intended for an [[entities/office-potluck]]:

| Day | Time | Activity |
|-----|------|----------|
| **Day before** (arriving home ~6 pm) | 6:00 – 6:30 pm | Cook wheat berries and let cool |
| | 6:30 – 7:00 pm | Make miso‑ginger dressing; prep sturdy veggies/herbs |
| | 7:00 – 7:30 pm | Chill components and tidy workspace |
| **Morning of** (leaving by 9 am) | 8:00 – 8:30 pm | Prep delicate ingredients; stir dressing |
| | 8:30 – 9:00 pm | Toss salad, adjust seasoning, pack, and head out |

## Benefits
- **Time efficiency** – breaking work into half‑hour segments reduces overwhelm and fits into typical personal schedules.
- **Flexibility** – optional blocks (e.g., extra veggie prep) can be added or removed without disrupting the whole plan.
- **Consistency** – using the same structure for different meals builds a repeatable habit.
