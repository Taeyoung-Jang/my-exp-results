# Mode Recommendation Matrix

**Definition**: A systematic framework that interprets responses from the 12‑question commuting‑preference checklist and maps dominant answer patterns (A, B, C) to the most suitable commuting mode.

## Source
This concept is derived from the analysis in [[summaries/session-34_2025-04-11]], which presented a checklist to gauge personality, lifestyle, and mood factors for commuting.

## How it works
1. **Collect Answers** – The user selects A, B, or C for each of the twelve questions covering structure, activity level, solitude, delay tolerance, convenience, noise sensitivity, predictability, cost, pace, eco‑motivation, and social desire.
2. **Identify Dominant Pattern** – Count the occurrences of each letter:
   - **Mostly A** → Preference for control, privacy, predictability → **Driving** (private car).
   - **Mostly B** → Balanced tolerance for crowds, moderate structure → **Public transit**.
   - **Mostly C** → Desire for movement, variety, eco‑orientation → **Biking/Walking**.
   - **Mixed A/B or A/C with high convenience** → **Ride‑share** as a hybrid fallback.
3. **Apply Fallback Logic** – If the primary mode is unavailable, the matrix references [[concepts/fallback-commuting-strategies]] to suggest the next best alternative (e.g., ride‑share → public transit).

## Relationship to Other Concepts
- The matrix operationalizes the traits captured in [[concepts/commuting-preferences]], turning qualitative preferences into actionable mode recommendations.
- It works hand‑in‑hand with [[concepts/fallback-commuting-strategies]] to create a resilient commuting plan that includes default, backup, and last‑resort options.

## Example Interpretation
A user whose answers are: A, B, A, A, A, A, A, A, B, A, B, A (as outlined in the session‑34 summary) shows a strong A dominance. The matrix therefore recommends **driving** as the default mode, with **ride‑share** as the primary backup and **public transit** as a last‑resort.
