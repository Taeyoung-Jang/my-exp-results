# Cover Letter Template

**Type:** work

**Related summary:** [[summaries/session-39_2025-04-14]]

## Overview
The *Cover Letter Template* is a concise, fill‑in‑the‑blank format designed to streamline the creation of customized cover letters for job applications. It incorporates the key elements identified in the [[concepts/cover-letter-checklist]] and can be quickly adapted for each role.

## Template Text
```
Hi [Name],

I’m applying for the [Role Title] position at [Company] because [brief, specific reason]. Your posting highlights [Key Requirement 1] and [Key Requirement 2]; my experience in [Your Experience] includes [short example] that directly addresses those needs.

I’m excited about contributing to [team/company initiative]. Thank you for your time – I look forward to discussing how I can help.
```

## Key Features
- **Personalized opening:** mentions the hiring manager’s name, role, and company.
- **Requirement alignment:** pulls 1‑2 key job requirements and maps them to a concrete example.
- **Concise closing:** expresses enthusiasm and invites further conversation.
- **Quick‑check steps:** aligns with the mental run‑through from the [[concepts/cover-letter-checklist]].

## Usage Context
The template is intended for daily job‑search workflows such as the [[concepts/daily-job-search-schedule]] and works well with a lightweight [[concepts/application-tracking-spreadsheet]] to track which version of the template was used per application.

## Benefits
- Reduces time spent drafting each cover letter while maintaining quality.
- Ensures consistent inclusion of essential elements, supporting higher response rates.
- Easy to copy‑paste and edit for each new opportunity.
