# Garage Door Opener

A **garage door opener** is a motorized product that allows a garage door to be opened and closed via remote controls, wall switches, or smart‑home interfaces. It typically includes a motor unit, an antenna, a remote transmitter, and optional keypad or safety sensors.

## Key Points from [[summaries/session-36_2024-07-15]]
- **Smart Home Handoff**: When transferring the home, the opener should have its remote cleared, be re‑paired with the new owner's remote, and any keypad code should be reset.
- **Documentation**: Include the make/model, location of the opener unit, and any warranty information in the house‑info packet.
- **Safety Checks**: Verify that the safety sensors and manual release mechanisms are functional before the handoff.

## Recommended Handoff Steps (see [[concepts/smart-home-transfer]])
1. **Factory Reset** – If supported, perform a factory reset to erase stored remotes.
2. **Remote Clearance** – Remove the seller’s remote(s) from the opener’s memory.
3. **Re‑pair New Remote** – Follow manufacturer instructions to add the buyer’s remote.
4. **Keypad Reset** – Delete existing codes and set a new default code for the new owner.
5. **Provide Documentation** – Supply user manual, warranty card, and any service records.

## Maintenance & Safety (see [[concepts/maintenance-scheduling]])
- **Lubricate** the chain or belt and roller bearings annually.
- **Test** the reversal mechanism and safety sensors every six months.
- **Inspect** the motor and mounting hardware for wear or corrosion during routine home maintenance.
