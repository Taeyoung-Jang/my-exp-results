# Summary of session-40_2025-06-15

**Main Topic**: Methods for recording personal address history and reliably confirming move‑in and move‑out dates when filling rental applications.

## 1. Simple system for address history
- Keep a **single living document** (spreadsheet or plain‑text note).
- Recommended columns: address, move‑in date, move‑out date, landlord name, landlord contact.
- Update the file every time a lease is signed or a move is completed.
- Store the file in a cloud drive for durability and easy access.
- This approach aligns with [[concepts/address-history-tracking]].

## 2. Reconstructing missing dates
- Look for **timestamped evidence**:
  - Lease or rental agreement
  - Email/text correspondence with landlord/property manager
  - Rent‑payment records (bank statements, [[entities/venmo]], [[entities/zelle]], checks)
  - Utility start/stop notices
  - [[entities/usps]] change‑of‑address confirmations
  - Updates to bank, employer, or delivery‑service accounts (e.g., [[entities/amazon]], [[entities/paypal]])
- If evidence is insufficient, contact the former landlord for official dates.
- This process follows [[concepts/move-date-verification]].

## 3. Proof‑source hierarchy (most precise → least precise)
| Source | Best for | Typical date reflected |
|--------|----------|------------------------|
| Lease / rental agreement | Both | Official move‑in & move‑out dates |
| Landlord emails/texts | Both | Exact day of key pickup, move‑out confirmation |
| Rent‑payment records | Both (lean toward move‑in) | First payment after move‑in, last payment before move‑out |
| Utility start/stop notices | Both | Service start ≈ move‑in, stop ≈ move‑out |
| USPS change‑of‑address | Move‑in | Forward‑mail start date |
| Account address updates (bank, employer, apps) | Move‑in | Date of address change |

- The ordering reflects [[concepts/proof-source-hierarchy]].

## 4. Cheat‑sheet format
```
Lease or rental agreement – both (top priority)
Landlord emails/texts – both (top priority)
Rent‑payment records – both (move‑in stronger)
Utility start/stop notices – both
USPS change‑of‑address – move‑in
Account/address updates – move‑in
```
- **Conflict resolution**: Default to the lease or landlord’s written confirmation; these are the official dates most applications rely on.

## 5. Application‑specific guidance
- List the **lease end date** as the move‑out date on rental applications; it is the official record.
- If you left early but kept utilities on, still use the lease end date.
- No need to flag the date as approximate unless the form explicitly asks for the physical move‑out day.
