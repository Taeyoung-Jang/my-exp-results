# Address History Tracking

**Definition**: A disciplined approach to documenting every residential address, associated move‑in and move‑out dates, landlord contacts, and supporting proof sources so that the information can be quickly retrieved for rental applications, background checks, or personal records.

## Core Elements
1. **Living Document**
   - Use a single spreadsheet or plain‑text note that you update every time you sign a lease or move.
   - Recommended columns: address, move‑in date, move‑out date, landlord name, landlord contact, notes.
   - Store the file in a cloud drive (Google Drive, Dropbox, OneDrive) for durability and access from any device.

2. **Timestamped Evidence**
   - Gather documents that provide reliable dates:
     - Lease or rental agreement (official dates) – see [[concepts/proof-source-hierarchy]].
     - Landlord/property‑manager emails or texts.
     - Rent‑payment records (bank statements, Venmo, Zelle, checks) – [[entities/venmo]], [[entities/zelle]].
     - Utility start/stop notices.
     - USPS change‑of‑address confirmation – [[entities/usps]].
     - Account address updates (e.g., Amazon, bank, employer). – [[entities/amazon]]

3. **Proof‑Source Hierarchy**
   - Prioritize sources from most precise to least precise when confirming dates (see [[concepts/proof-source-hierarchy]]).  The lease and landlord communications are top‑priority; other sources serve as secondary verification.

4. **Move‑Date Verification**
   - Apply the hierarchy to resolve conflicts and to fill gaps where a date is missing.  This process is described in [[concepts/move-date-verification]].

## Workflow Overview
1. **After each move**: Immediately add a new row to the living document with whatever information is available.
2. **Collect evidence**: Save copies of the lease, email threads, payment receipts, utility notices, and USPS confirmation in a dedicated folder linked to the spreadsheet.
3. **Verify dates**: Use the proof‑source hierarchy to confirm the move‑in and move‑out dates.  If sources disagree, default to the lease or landlord confirmation.
4. **Periodic audit**: Review the document quarterly to ensure all entries are complete and backed by at least one primary source.

## Benefits
- **Accuracy**: Reduces reliance on memory, limiting errors on rental applications.
- **Speed**: Quickly locate the exact dates and contacts you need.
- **Reliability**: Having multiple corroborating sources satisfies most application requirements.
- **Continuity**: A single, cloud‑based file prevents loss of data when devices fail.
