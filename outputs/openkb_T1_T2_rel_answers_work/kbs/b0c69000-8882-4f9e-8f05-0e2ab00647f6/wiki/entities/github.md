# GitHub (product)

GitHub is a cloud platform that hosts Git repositories, provides contribution graphs, and offers collaboration features such as pull‑requests, issues, and project boards.

## Key facts from [[summaries/session-10_2024-07-15]]
- Used as the **automatic log** for public code contributions, forming the backbone of a developer’s visible activity.
- The document recommends treating GitHub’s contribution graph as the *automatic log* while adding a lightweight “footnote” layer for private work and non‑code contributions.
- Suggested workflow separates GitHub’s visual timeline from a personal Markdown log that captures [[concepts/footnotes-to-graph]].
- Emphasized that developers should avoid duplicating information already shown on GitHub when creating their extra documentation.
