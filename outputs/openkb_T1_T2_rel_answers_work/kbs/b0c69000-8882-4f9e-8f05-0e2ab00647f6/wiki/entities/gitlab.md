# GitLab (Product)

GitLab is a cloud‑and‑self‑hosted platform that combines Git repository management, continuous integration/continuous delivery (CI/CD), issue tracking, and many other DevOps tools in a single application.

## Relevance in **session-10_2024-07-15**
The conversation recommends treating GitLab (alongside GitHub) as the *automatic log* for public code contributions. Developers are advised to keep the contribution graph from GitLab untouched and layer a lightweight human‑written “footnote” log on top of it for private work and non‑code activities.

## Key points from the document
- **Automatic log** – GitLab’s contribution history serves as the baseline record of public work. [[concepts/activity-tracking]]
- **Footnotes to the graph** – A separate, concise note set captures work that GitLab cannot display (e.g., internal repos, architecture decisions, mentoring). [[concepts/footnotes-to-graph]]
- **Non‑code contributions** – Items such as planning, design discussions, and mentoring are recorded separately to avoid duplication of what GitLab already shows. [[concepts/non-code-contributions]]
- **Template design** – The document provides a Markdown template (and a one‑page review variant) for these footnotes, illustrating how to structure the extra context. [[concepts/template-design]]
