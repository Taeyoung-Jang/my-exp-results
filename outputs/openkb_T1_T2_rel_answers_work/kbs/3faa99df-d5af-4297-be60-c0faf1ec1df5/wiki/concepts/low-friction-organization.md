# Low‑Friction Organization

**Definition**: A low‑friction organization approach consists of lightweight, repeatable habits that externalize memory without requiring extensive structures or constant upkeep.

---

## Core Components (as described in [[summaries/session-32_2025-02-15]])

1. **Single capture point** – use one place (a pocket notebook or a simple digital note) to dump names, reminders, and locations.
2. **External calendar** – any time‑bound item is immediately added to a calendar with an alert, keeping the brain free for ideas.
3. **Default home** – assign a permanent spot for frequently misplaced objects (keys, wallet, glasses) to reduce decision‑fatigue.

These pillars keep the system _minimal_ while still providing reliable retrieval.

---

## Supporting Micro‑Habits

- **Edge‑marking** – place a tiny dot or slash on the outer edge of a notebook page when you write something that will need later attention. This visual cue creates a quick index without extra pages.
- **End‑of‑day scan** – spend about one minute each night flipping through the day’s page, moving time‑sensitive items to the calendar, and using the edge marks to locate important notes. See [[concepts/end-of-day-scan]] for details.

When memory is compromised, combine the two by marking the page *as you close the notebook*, turning the capture action into a single motion.

---

## Relation to Other Concepts

- The **pocket notebook workflow** provides a concrete implementation of low‑friction capture; see [[concepts/pocket-notebook-workflow]].
- The **end‑of‑day scan** is the primary maintenance habit that prevents the capture system from devolving into an unreviewed pile of notes.

---

## Benefits

- **Low mental load** – no need to decide where to file each item.
- **Speed** – capture is a single, fast gesture.
- **Scalability** – works for both digital and analog tools.
- **Resilience** – even with memory lapses, the edge‑mark + nightly scan combo secures important information.

---

## Practical Tips

1. Keep the notebook chronological; avoid sections or elaborate indexes.
2. Reserve the back cover for a static quick‑reference map (important numbers, active tasks).
3. Use the calendar as the sole repository for appointments; treat it as your external memory for dates.
4. Assign a consistent “default home” for high‑use objects to eliminate daily search friction.
