# Summary of session-32_2025-02-15

**Main contribution:** Practical, low‑effort methods for capturing and revisiting daily details without turning a pocket notebook into a burdensome system.

## Key ideas
- **Three‑pillar habit** – a single running note (digital or paper), a calendar for time‑based items, and a “default home” for frequently misplaced objects.
- **Pocket‑notebook workflow** – keep the notebook chronological, avoid sections or heavy indexing, and use minimal visual cues.
- **Edge‑marking technique** – place a tiny dot or slash on the outer edge of any page that contains an item needing later attention. This creates a quick visual map without extra pages.
- **End‑of‑day scan** – spend ~1 minute each night flipping through the day’s page, transferring time‑sensitive items to a calendar and noting anything worth keeping via the edge marks.
- **Combined habit for memory‑impaired users** – when writing a detail, immediately add the edge mark while closing the notebook; the nightly scan then simply follows those marks, merging both habits without extra steps.

## Recommendations
1. **Keep the notebook simple** – write chronologically, no sections, no elaborate index.
2. **Reserve the back‑cover** for a static quick‑reference map (phone numbers, active tasks, etc.).
3. **Prioritize the nightly scan** as the primary habit; use edge marks as a lightweight cue during capture.
4. **Leverage the calendar** for any appointment or date‑specific entry; treat it as the external memory for time‑bound tasks.
5. **Assign a default spot** for keys, wallet, glasses, etc., to reduce decision‑fatigue.
