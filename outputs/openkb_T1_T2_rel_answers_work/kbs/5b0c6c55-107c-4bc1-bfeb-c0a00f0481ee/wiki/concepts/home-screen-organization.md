# Home Screen Organization

**Definition**: The deliberate arrangement of app icons, folders, and widgets on a mobile device’s home screen to support quick access, reduce visual clutter, and reinforce daily habits.

---

## Core Principles (from [[summaries/session-08_2024-06-15]])

1. **Utility First** – Prioritize apps that provide daily value or enable core routines.  
2. **Frequency Matters** – Keep apps opened today or within the past week front‑and‑center.  
3. **Separation of Contexts** – Group personal and work communication tools separately for mental clarity.  
4. **Limit Count** – Aim for a **6–12** item sweet spot (including widgets) to keep the screen a "command center" rather than a storage closet.
5. **Widget Evaluation** – Include a widget only if it delivers immediate, at‑a‑glance information; otherwise stick to icons.

---

## Typical Layout Blueprint (iPhone example)

| Zone | Recommended Items |
|------|-------------------|
| **Top (widget row)** | One medium widget for [[entities/google-calendar]] (or a task widget) – provides a daily overview without opening the app. |
| **Upper‑left row** | Personal communication apps: [[entities/imessage]] and [[entities/whatsapp]]. |
| **Upper‑right row** | Work communication apps: [[entities/slack]] and [[entities/microsoft-teams]]. |
| **Middle row** | Navigation & media: [[entities/google-maps]] and [[entities/spotify]]. |
| **Middle‑right** | Task manager: [[entities/todoist]]. |
| **Lower‑left** | Primary reading/news app (e.g., [[entities/apple-news]]). |
| **Lower‑right** | Security / utility app: [[entities/1password]]. |
| **Off‑screen folder** | Secondary reading apps (kindle, pocket) and any backup chat apps. |

This configuration results in **1 widget + 10 icons**, fitting the recommended 8–12 range.

## Benefits

- **Speed**: Faster access to the apps you need most, reducing friction in daily workflows.
- **Mental Clarity**: Clear visual separation between personal and work contexts minimizes decision fatigue.
- **Reduced Overwhelm**: Limiting the number of visible icons helps maintain focus and prevents the home screen from feeling like a “junk drawer.”
- **Adaptability**: The layout can be revisited after a few days to reflect actual usage patterns, ensuring the screen evolves with habits.

## Implementation Steps (derived from the source)

1. **Clear the Canvas** – Move all icons into a temporary folder on [[entities/iphone]].
2. **Populate with Today’s Apps** – Add back any app you opened today.
3. **Review Weekly Use** – Bring back apps used within the past week that support core routines.
4. **Folder vs. Delete Decision** – Place the remainder in a folder; delete any app not opened in weeks or that duplicates functionality.
5. **Fine‑Tune After a Few Days** – Observe real‑world usage and adjust positions or the widget choice accordingly.
6. **Apply the One‑Screen Template (session‑39)** – Limit the home screen to a single screen, one row of folders, and only the daily‑use apps: messenger, calendar, camera, and one media/reading app in the dock; utilities in row 1; a “Daily Utilities” folder in row 2.
7. **Temporary‑Install Reminder** – Re‑install an app only for a specific task and delete it immediately after; if you cannot name the task, do not reinstall.
