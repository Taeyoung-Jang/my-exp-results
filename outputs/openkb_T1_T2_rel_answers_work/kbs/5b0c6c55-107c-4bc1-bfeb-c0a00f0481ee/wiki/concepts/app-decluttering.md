# App Decluttering

**App decluttering** is the practice of evaluating, organizing, and possibly removing apps so that a mobile device’s home screen functions as a clear, intentional control panel rather than a cluttered storage space. The concept is detailed in [[summaries/session-08_2024-06-15]] and expanded with practical guidance from [[summaries/session-39_2025-02-13]].

## Decision Criteria
1. **Daily utility** – Apps used every day without thinking deserve a home‑screen spot.
2. **Habit support** – Apps that reinforce a personal goal or routine merit inclusion.
3. **Recent frequency** – Apps opened within the past week are candidates for the main view.
4. **Redundancy & inertia** – Apps not opened in weeks, duplicate functionality, or exist solely out of habit should be hidden or deleted.
5. **Checklist questions** –
   - Have I used this in the past week?
   - Does it solve a real problem for me right now?
   - Is there another app that already does the same job?
   - Does it genuinely improve my day, or just fill time?
   - Would I reinstall it immediately if I deleted it?
   These five prompts (from the recent session) provide a quick, repeatable filter for each app.

## Practical Checklist (from the source)
1. Move all icons into a temporary folder to start with a clean slate.
2. Re‑add only the apps you opened **today**.
3. Review apps used in the **past week** and keep those that support daily routines.
4. For the remaining apps, decide:
   - Keep in a secondary folder if occasionally useful.
   - Delete if unused for a long period.
5. Re‑assess after a few days and adjust as needed.

## Weekly Phone Maintenance
A low‑effort, two‑minute routine keeps clutter from returning:
1. Choose a consistent day (e.g., Sunday evening).
2. Open the app list and scroll with fresh eyes.
3. Apply the five‑question checklist; move any “no” apps to the trash.
4. Clear the *Downloads* folder, *Screenshots*, and dismiss pending notifications.
5. Verify the home‑screen still follows the one‑screen layout.

This routine aligns with the broader [[concepts/weekly-phone-maintenance]] mindset.

## Home‑Screen Size Recommendation
A balanced home screen typically holds **6–12** items (including at most one widget). This range provides enough room for essential tools while avoiding visual overload.

## One‑Screen Home‑Screen Template
A strict layout that limits re‑accumulation of apps:
- **Dock:** messenger, calendar, camera, and one daily media/reading app.
- **Row 1:** most‑used utility (e.g., notes or reminders) + maps if used daily.
- **Row 2:** a single folder “Daily Utilities” for alarms, quick‑settings, or other brief‑use tools.
- **No additional rows or second screens.**

This template embodies the principles of [[concepts/minimalist-phone-management]] and works hand‑in‑hand with the [[concepts/home-screen-organization]] approach.

## Temporary Reinstall Rule
Only reinstall an app for a specific, named task and delete it as soon as that task is finished. If you cannot name the task, do not reinstall. This rule is captured in [[concepts/temporary-reinstall-rule]].

## Grouping & Prioritization
- **Fast‑response apps** (e.g., personal and work chat) are grouped together for quick access.
- A **planning zone** combines a calendar widget with a task manager.
- **Consume/reading apps** sit lower‑right, reflecting a slower interaction pace.

## Widget Utility
Only introduce a widget if it delivers immediate, at‑a‑glance value. For many users a single calendar widget (e.g., Google Calendar) replaces the need to open the app repeatedly, aligning with the [[concepts/widget-utility]] principle.
