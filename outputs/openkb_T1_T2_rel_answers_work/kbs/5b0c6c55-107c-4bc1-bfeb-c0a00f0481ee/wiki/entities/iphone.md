## iPhone

The **iPhone** is Apple’s line of smartphones that runs iOS, providing a touch‑based interface and a customizable home screen. In the context of the *session‑08_2024‑06‑15* conversation, the iPhone serves as the device on which the user applies [[concepts/app-decluttering]], [[concepts/home-screen-organization]], and [[concepts/widget-utility]] strategies.

### Key points from [[summaries/session-08_2024-06-15]]
- The user follows a step‑by‑step cleanup process tailored to the iPhone’s home screen layout.
- Recommendations include using a single medium widget for [[entities/google-calendar]] to maximize quick‑glance information.
- Suggested grouping of apps (personal chat [[entities/imessage]], [[entities/whatsapp]]; work chat [[entities/slack]], [[entities/microsoft-teams]]; navigation [[entities/google-maps]]; music [[entities/spotify]]; password manager [[entities/1password]]) leverages the iPhone’s app organization capabilities.
- The iPhone’s App Library and folders are used to hide secondary apps like [[entities/pocket]] and [[entities/kindle]].
