# Slack

Slack is a cloud‑based messaging and collaboration tool used by teams to communicate in real time. In the context of [[summaries/session-15_2024-09-14]], Slack served as the medium for drafting informal yet firm scheduling messages that set personal and team-wide [[concepts/scheduling_boundaries]].

Key points from the document:
- The user requested several Slack‑style drafts to encourage [[concepts/team_norms]] around avoiding after‑hours meetings.
- The drafts emphasized clear communication templates, linking to [[concepts/communication_templates]] for reusable phrasing.
- Specific phrasing included an emergency exception clause, reinforcing that true emergencies would still be addressed through Slack.

Slack therefore functions as the primary channel for delivering these [[concepts/communication_templates]] and reinforcing the team's scheduling norms.
