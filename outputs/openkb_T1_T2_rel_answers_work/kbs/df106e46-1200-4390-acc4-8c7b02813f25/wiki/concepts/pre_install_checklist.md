# Pre‑Install Checklist

**Definition**: A quick, under‑a‑minute mental script that helps users evaluate whether an app is worth installing by checking key trust signals and flagging risky permissions.

## Core Elements
1. **Developer reputation** – Identify the app's creator (e.g., known company vs unknown publisher). 
2. **Recency of updates** – Prefer apps updated within the last few months; stale updates can signal abandonment. 
3. **Reviews & screenshots** – Scan a handful of user reviews for authentic language and examine screenshots for a realistic user interface. 
4. **Permission red flags** – Cross‑check requested permissions against the app’s claimed functionality; deny apps that request location, contacts, or photos without a clear purpose. 
5. **Gut check** – If the app feels rushed, overly hype‑driven, or spammy, skip the install.

These steps collectively form the [[concepts/pre_install_checklist]] that supports broader [[concepts/app_evaluation]] and aligns with [[concepts/app_trust_signals]] such as developer credibility and recent updates. When a permission request appears unjustified, it triggers the [[concepts/permission_red_flags]] alarm.
