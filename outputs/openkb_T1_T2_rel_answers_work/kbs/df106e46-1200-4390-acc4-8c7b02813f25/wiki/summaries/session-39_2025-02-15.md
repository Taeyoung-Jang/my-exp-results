# Summary of session-39_2025-02-15

**Main idea**: A concise mental checklist for deciding if a new app is worth installing and how to handle its permissions safely.

## Key concepts
- **"Download first, think later" habit** – the impulse to grab any newly‑heard app without scrutiny.  
- **Permission red flags** – permissions that do not align with the app’s core purpose (e.g., a notes app requesting location). [[concepts/permission_red_flags]]
- **Trust signals** – developer reputation, recent update date, authentic reviews, realistic screenshots. [[concepts/app_trust_signals]]
- **Pre‑install checklist** – a rapid, under‑a‑minute mental script to vet an app before download. [[concepts/pre_install_checklist]]
- **Post‑install permission strategy** – deny all permissions initially, then grant only when a clear, contextual need appears. *(no dedicated concept page)*

## Pre‑install mental checklist (under 1 minute)
1. **Who made it?** Identify the developer/organization.  
2. **Last update?** Prefer apps updated within the last few months.  
3. **Reviews & screenshots** – skim a few reviews for human tone and examine screenshots for a realistic UI.  
4. **Red‑flag permissions?** If the app advertises a function that doesn’t need location, contacts, or photos, treat that as a warning.  
5. **Gut check** – if anything feels rushed, spammy, or overly hype‑driven, skip the install.

## First‑run permission handling
1. Open the app, **deny every permission request** immediately.  
2. Observe the app’s behavior: does it need a permission for the feature you’re trying?  
3. **Grant only contextual permissions** that directly enable a needed function.  
4. If the app repeatedly asks for unrelated access, **close and uninstall**.

## Takeaway
By applying this quick two‑step script—pre‑install vetting and post‑install permission denial—you can curb impulsive app downloads and protect privacy without slowing down discovery. This approach aligns with broader [[concepts/app_evaluation]] frameworks for assessing mobile applications.
