# Commute Logging Template

**Definition**: A simple, fill‑in‑the‑blank table that captures key commute information each day, enabling systematic comparison of departure times and routes.

## Purpose
The template is designed to support [[concepts/timing-experiment]] by providing consistent data points for analysis. By recording the same fields every trip, users can track trends in [[concepts/commute-metrics]] such as total travel time, variability, and post‑arrival stress, and make informed decisions about optimal departure windows.

## Template Layout
```
Date: 
Departure time: 
Arrival time: 
Total minutes door‑to‑door: 
Traffic impression (light / normal / heavy): 
Stress on arrival (0–5): 
Anything unusual today: 
```

Each row corresponds to a single commute. The fields capture:
- **Date** – when the trip occurred.
- **Departure/Arrival times** – for calculating door‑to‑door duration.
- **Total minutes door‑to‑door** – the primary efficiency metric.
- **Traffic impression** – a qualitative note that can explain variations.
- **Stress on arrival (0–5)** – the subjective quality‑of‑life measure linked to [[concepts/stress-management]].
- **Anything unusual** – optional notes on accidents, weather, or other anomalies.

## How to Use
1. **Select two departure times** within your flexible window (e.g., usual time vs. 15 min earlier).
2. **Alternate** between them over a week, logging each trip with the template.
3. **Compare** the collected data to identify which timing yields lower travel time, less variability, and reduced stress.
