# 5K Run

The **5K Run** is a recurring short‑distance running event (5 kilometres) that the user incorporates into a daily morning routine. In the context of the conversation on 2025‑03‑14, the run is used as a benchmark for rebuilding a consistent, injury‑free habit after physical‑therapy clearance.

## Key Facts from [[summaries/session-32_2025-03-14]]
- **Typical duration:** 26–27 minutes, which corresponds to roughly 5:20‑5:30 min/km.
- **Goal:** Establish an *easy* run where the user can maintain a conversational pace.
- **Primary pacing cue:** The [[concepts/talk-test]]—the ability to hold a conversation without strain.
- **Optional physiological cue:** A **heart‑rate guardrail** of about **145 bpm**, derived from the “180 minus age” rule for a 34‑year‑old. This links to the [[concepts/heart-rate-guardrail]] concept.
- **Aerobic focus:** The run is kept within the aerobic zone, reinforcing endurance without excessive intensity (see [[concepts/aerobic-zone]]).
- **Guidelines for “too high for too long”:** Staying above the mid‑140 bpm range for several uninterrupted minutes early‑mid run, or experiencing labored breathing while trying to maintain the usual pace, signals the need to ease back.

## Practical Recommendations
1. Begin each 5K with a brief warm‑up (5‑10 minutes of walking or dynamic stretches).
2. Run at a deliberately slower pace than the typical 26‑27 minute finish—aim for 5:45‑6:00 min/km—to ensure the [[concepts/talk-test]] remains comfortable.
3. Occasionally glance at a heart‑rate monitor to confirm the reading stays under the ~145 bpm guardrail; treat occasional spikes on hills as acceptable.
4. After 1‑2 weeks of consistency, gradually tighten the pace while still satisfying the talk‑test and staying within the aerobic zone.
