# Summary of Session 33 (2025-08-15)

## Quick GPU‑Upgrade Verification Checklist
- **Device Manager**: Confirm the new discrete GPU appears under *Display adapters* with no warning icons; optionally disable the integrated GPU (iGPU) in BIOS for a clean setup. *(related: [[concepts/gpu-upgrade-checklist]])*
- **BIOS Settings**: Set *Primary Display* to PCIe or disable the iGPU. Verify the iGPU is not the default output device.
- **Power & Driver**: Install the latest NVIDIA driver; ensure Windows power plan is set to *High performance* or *Maximum performance* for the GPU.
- **Control Panel**: In the NVIDIA Control Panel, set the *Preferred graphics processor* to the high‑performance GPU globally and per‑app.
- **Windows Graphics Settings**: System > Display > Graphics → assign Photoshop, Premiere, Blender, etc. to *High performance* (see [[entities/windows-graphics-settings]]).
- **Benchmark / Monitoring**: Run a lightweight GPU monitor (GPU‑Z, Task Manager Performance tab) or a quick benchmark (Unigine Heaven, Blender benchmark) to see GPU load when launching a GPU‑intensive task. *(related: Task Manager GPU monitoring)*

## Display Connection Verification
- **Symptom**: Sluggish UI, missing high‑refresh rates, or no GPU load despite heavy workloads.
- **Check**: In Task Manager, select each GPU; the *Displays* list at the top shows which monitor is attached to which GPU. If a monitor appears only under the Intel GPU, it is plugged into the motherboard port. *(see [[concepts/display-connection-verification]])*
- **Fix**: Move the monitor cable to the discrete GPU’s output ports (HDMI/DisplayPort). Ensure the cable and monitor support the desired resolution/refresh rate.

## iGPU vs dGPU Considerations
- Leaving the iGPU enabled is harmless if **all monitors are connected to the dGPU**. It can be beneficial for Intel **Quick Sync** video encoding/decoding while the dGPU handles 3D rendering and effects. *(see [[entities/intel-quick-sync]])*
- **Downside**: Some apps default to GPU 0 (often the iGPU). Override with per‑app Windows graphics settings or the NVIDIA Control Panel to force the high‑performance GPU. *(related: app GPU selection)*

## Using Intel Quick Sync with Adobe Premiere/Media Encoder
- **Enable**: Keep the iGPU active in BIOS; install Intel graphics driver.
- **Confirm Usage**:
  1. Start an H.264/H.265 export in [[entities/adobe-premiere-pro]].
  2. Open Task Manager → *Performance* → *Intel GPU*; watch the *Video Encode* or *Video Decode* engine activity.
  3. Simultaneously, the discrete GPU should show load on its 3D/Compute engines for effects.
- **Premiere Settings**: Project Settings → *Renderer* should show *CUDA* (or *OpenCL*) for the dGPU; *Encoding* tab should list *Intel Quick Sync* as an available hardware encoder. *(see [[concepts/quick-sync-utilization]])*

## Reducing “GPU 0” Stickiness
- **Windows**: System > Display > Graphics → set *High performance* for each media app.
- **NVIDIA Control Panel**: Global *Preferred graphics processor* → *High‑performance NVIDIA processor*.
- **Power Options**: Ensure *PCI Express* Link State Power Management is set to *Off* to prevent Windows from throttling the dGPU.

## Common Gotchas After Upgrade
- Stale drivers or Windows auto‑installing generic drivers.
- Power plan set to *Balanced* causing the dGPU to stay in low‑power mode.
- Monitors still attached to motherboard video ports.
- Apps left on *Auto* renderer, defaulting back to the iGPU.
- BIOS not disabling the iGPU, leading to resource conflicts after driver updates.
