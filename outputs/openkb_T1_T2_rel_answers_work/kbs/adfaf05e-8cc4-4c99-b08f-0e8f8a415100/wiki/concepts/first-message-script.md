# First‑Message Script for Organizers

**Definition**: A short, polite message sent to a meetup organizer before attending an event, confirming newcomer‑friendliness and gathering any essential details.

## Core Elements
1. **Greeting** – Simple, friendly opener (e.g., “Hi!” or “Hello”).
2. **Self‑Identification** – State that you are new to the group.
3. **Intent** – Mention the specific event or group you’d like to join.
4. **Permission Check** – Ask if it’s okay to attend as a first‑timer.
5. **Info Request** – Invite any quick tips or expectations (e.g., dress code, equipment).
6. **Closing** – Brief thank‑you.

## Example from [[summaries/session-40_2025-02-13]]
> “Hi! I’m thinking about joining your next meetup and I’m new to the group. Is it okay if I just show up, and anything I should know ahead of time?”

## Usage Guidance
- **Keep it concise** – Organizers often handle many inquiries; a brief message respects their time.
- **Tone** – Polite and upbeat; avoid overly formal language.
- **Customization** – Swap the activity name (e.g., “walking group”, “board game night”) to make it relevant.
- **Timing** – Send the message a few days before the event to get a timely response.
