# Show‑up Script for Meetup Attendance

**Definition**: A set of short, context‑specific opening lines that help a newcomer introduce themselves and integrate smoothly into a meetup event.

## Why It Matters
A well‑crafted script reduces first‑time anxiety, signals friendliness, and encourages the group to welcome you. It complements other onboarding tools such as [[concepts/first-message-script]] and [[concepts/polite-exit-strategy]].

## Core Principles
1. **Be brief** – a single sentence or two is enough.
2. **Show intent** – indicate you’re new but eager to join.
3. **Ask a low‑effort question** – e.g., “Is there a spot open?” or “Can I walk with you?”
4. **Match the activity** – tailor language to the event type (board games, walking, etc.).

## Example Scripts (from [[summaries/session-40_2025-02-13]])
### Board‑Game Night
- "Hey, I’m new—mind if I hop into the next game?"
- "I’m just joining for the first time; is there a table that’s open for newcomers?"

### Walking Group
- "Hi, first time here—mind if I walk with you all?"
- "I’m new to the group, just checking I’m in the right spot."

### General Meetup (any activity)
- "Hi! I’m new—can I join you?"
- "Hello, I’m attending for the first time; is there anything I should know before we start?"

## Using the Scripts
1. **Observe the group** – arrive a few minutes after the start so conversation is already flowing.
2. **Choose the appropriate script** based on the activity.
3. **Deliver with a smile** – tone matters as much as words.
4. **Follow up** – if the group responds positively, stay engaged; if not, you can use a [[concepts/polite-exit-strategy]] to leave gracefully.
