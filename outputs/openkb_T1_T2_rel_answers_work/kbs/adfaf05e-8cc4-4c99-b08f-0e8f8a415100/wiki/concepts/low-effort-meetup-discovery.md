# Low‑effort meetup discovery

**Definition**: A set of simple, repeatable techniques for finding active, free local gatherings (e.g., walking groups, board‑game nights, volunteer events) without costly subscriptions.

## Core Elements
1. **Generic search phrases** – concise, copy‑pasteable queries that work on web search engines and the Meetup app (e.g., "walking group near [your town]", "board game meetup [your town]").
2. **Platform‑specific tweaks** – adding keywords for Facebook Groups ("group", "club", "locals") and for library or community‑center sites ("events", "programs", "workshops").
3. **Quick activity filters** – include the hobby, location, and a cue for community focus (e.g., "casual", "beginner‑friendly").

## Example Templates (Ready to copy)
- **Walking**: `walking group near [your town]`  
- **Board games**: `board game club [your town]`  
- **Volunteering**: `volunteer opportunities [your town]`  
- **Casual sports**: `adult rec sports meetup [your town]`  
- **Book clubs**: `book club [your town]`

### Facebook‑specific
Add "group" or "club" and optionally "locals":
- `walking group [your town] community`
- `board game club [your town] locals`

### Library / Community‑center sites
Add "events", "programs", or "calendar":
- `library events [your town] book club`
- `community center programs walking`
