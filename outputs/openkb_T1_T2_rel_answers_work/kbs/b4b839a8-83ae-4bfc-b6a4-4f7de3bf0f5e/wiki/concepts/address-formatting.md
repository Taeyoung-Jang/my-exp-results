# Address Formatting

## Definition
Address formatting refers to the way an applicant writes their residential address on paperwork, including the use of abbreviations, unit identifiers, and street suffixes.

## Key Points from [[summaries/session-31_2023-06-15]]
- **Minor variations are acceptable**: Differences such as "Apt" vs. "Unit" or "St" vs. "Street" are generally fine as long as the location is clearly the same.
- **Consistency matters**: While small formatting changes are tolerated, it helps to copy the exact version that appears on a government‑issued document (e.g., driver’s license) to avoid accidental mismatches across multiple forms.
- **Practical tip**: Keep a master copy of your address as it appears on an official ID and paste that into each onboarding form, adjusting only when a field explicitly requires a different format.

## Relationship to Other Concepts
- This concept supports [[concepts/form-consistency]], ensuring that address fields do not become a source of discrepancy.
- It aligns with [[concepts/legal-name-usage]] in that both advise using the exact representation from official documents for uniformity.

## Common Pitfalls
1. **Inconsistent unit labeling** – switching between "Apt", "Unit", "#", or leaving it out can create confusion if the rest of the address differs.
2. **Incorrect abbreviations** – using non‑standard abbreviations (e.g., "Str" for "Street") may be flagged by automated validation tools.
3. **Transposed characters** – a typo in the street number or zip code can cause the address to be interpreted as a different location.

## Recommendations
- Use the address format from your driver’s license or a recent utility bill as the baseline.
- When a form provides separate fields for street, city, state, and zip, fill each exactly as shown on the source document.
- Review all address entries in a final pass to ensure they match across the entire onboarding packet.
