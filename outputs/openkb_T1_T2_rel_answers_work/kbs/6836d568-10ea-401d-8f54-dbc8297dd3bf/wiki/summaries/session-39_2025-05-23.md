# Summary of session-39 (2025-05-23)

## Core Idea
A lightweight system for turning bureaucratic tasks into “paperwork milestones” with pre‑selected rewards, using a concise note‑template that can be stored on a phone. See [[concepts/paperwork_milestones]] and [[concepts/task_tracking_template]].

## Template
```
Task: 
Done when: 
Steps: 
Reward I’ll give myself: 
Date finished: 
How it felt:
```
The template captures the task, clear completion criteria, actionable steps, a pre‑chosen reward, and reflection on the outcome.

## Reward Scaling Principle
- **Match reward size to emotional weight**, not duration.  
- Small annoyance → coffee or snack.  
- Medium dread → dinner or movie night.  
- High‑stress milestone → mini‑getaway or travel.  
This prevents over‑rewarding while keeping the incentive proportional. See [[concepts/reward_scaling]].

## Example Entries
| Task | Done when | Steps | Reward |
|---|---|---|---|
| Update address on one account | Confirmation email shows new address | Log in → profile → edit → submit | Good coffee |
| Renew driver’s license | Temporary license downloaded | Gather docs → portal → upload → pay → submit | Nice dinner or solo movie night |
| File taxes | Return accepted, confirmation saved | Collect forms → import → review → fix → submit | One‑night mini‑getaway |

## Real‑World Milestone
```
Task: Final committee sign‑off at the department office.
Done when: I had the stamped confirmation sheet in hand.
Steps: Go to the office, check in, wait for review, receive the signed confirmation.
Reward I gave myself: Booked the weekend train trip I’d been putting off.
Date finished: Today.
How it felt: Like a huge exhale I’d been holding for months.
```

## Suggested Smaller Rewards
- **Medium task**: favorite pastry.  
- **Small task**: a cozy hour with a special drink or favorite show.  
These keep rewards enjoyable without defaulting to travel.
