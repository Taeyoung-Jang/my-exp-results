# Task Tracking Template

## Overview
The **Task Tracking Template** is a concise, phone‑friendly format for turning any bureaucratic or administrative task into a clear *milestone* with an attached reward. It captures the essential elements needed to define the work, know when it’s finished, break it into manageable steps, and plan a celebration.

## Template Structure
```
Task: 
Done when: 
Steps: 
Reward I’ll give myself: 
Date finished: 
How it felt:
```
- **Task** – a short description of the activity you need to complete.
- **Done when** – the concrete outcome that signals completion (e.g., confirmation email, downloaded document).
- **Steps** – bullet‑style or comma‑separated actions that move the task forward.
- **Reward I’ll give myself** – a pre‑chosen treat that matches the task’s emotional weight.
- **Date finished** – when you completed the task.
- **How it felt** – a brief reflection to reinforce the positive association.

## How It Supports [[concepts/paperwork_milestones]]
By pairing each task with a reward, the template creates a *paperwork milestone* that turns routine chores into motivating checkpoints. Regularly filling out the template builds a habit loop: **cue → action → reward**, making the completion of administrative work feel more satisfying.

## Reward Scaling and [[concepts/reward_scaling]]
The template’s reward line is deliberately vague to allow **proportional scaling**:
- **Small annoyance** → coffee, snack, or quick treat.
- **Medium dread** → dinner out, movie night, or a favorite pastry.
- **High‑stress milestone** → mini‑getaway or a weekend trip.
Choosing the reward **before** starting the task ensures the incentive is ready to trigger the moment the “Done when” condition is met, reinforcing the habit.

## Example Entries (from [[summaries/session-39_2025-05-23]])
- **Task:** Update my address on one account.
  - **Done when:** Confirmation email shows new address.
  - **Reward I’ll give myself:** A really good coffee.
- **Task:** Renew my driver’s license.
  - **Done when:** Temporary license downloaded.
  - **Reward I’ll give myself:** A nice dinner out or solo movie night.
- **Task:** File my taxes.
  - **Done when:** Return accepted, confirmation saved.
  - **Reward I’ll give myself:** A one‑night mini getaway.

These examples illustrate how the same template adapts to tasks of varying complexity while keeping rewards proportional.

## Practical Tips
1. **Write the reward first.** This creates a concrete reason to finish the task.
2. **Keep steps short.** One‑sentence actions prevent overwhelm.
3. **Reflect briefly.** The “How it felt” line reinforces the positive feedback loop.
