# Message Windows

**Definition**: Message windows are short, pre‑planned periods during a work sprint when you allow yourself to check and respond to communications, keeping the rest of the day free from interruptions.

**Purpose**
- Protect deep‑work blocks from constant notification noise.
- Provide a predictable rhythm for collaborators, reducing anxiety about missed urgent messages.
- Support mental focus and reduce cognitive switching costs.

**Guidelines (from [[summaries/session-13_2025-05-09]])**
1. **Schedule 1–2 windows per day** – e.g., 11:00‑11:15 and 15:00‑15:15.
2. **Communicate the windows** to anyone who might need to reach you (e.g., supervisor, friends and family).
3. **Silence all notifications** outside these windows; allow only a designated contact or app to bypass silence for true emergencies.
4. **Keep the windows brief** – just enough to triage urgent items and note non‑urgent ones for later.
5. **Align windows with natural breaks** in the daily rhythm, such as after the first deep‑work block and before the second.

**Relation to other concepts**
- Works hand‑in‑hand with [[concepts/deep-work-blocks]] by framing the blocks as uninterrupted periods.
- Complements the end‑of‑day [[concepts/daily-review]] where you capture any pending items that arose outside the windows.

**Implementation Example**
```
09:00 – Settle in
09:15 – Deep‑work Block 1 (focus)
10:45 – Break
11:00 – Message Window (check urgent messages only)
11:15 – Light admin / prep
12:00 – Lunch
13:00 – Deep‑work Block 2 (focus)
14:30 – Short break
15:00 – Message Window (second check)
15:15 – Wrap‑up tasks
16:00 – Daily Review
```

By consistently using message windows, you maintain high productivity during deep‑work periods while still staying reachable for critical communications.
