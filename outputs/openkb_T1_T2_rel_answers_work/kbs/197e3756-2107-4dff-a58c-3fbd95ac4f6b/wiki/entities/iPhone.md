# iPhone

The iPhone is a line of smartphones designed and marketed by Apple. In the context of [[summaries/session-32_2025-02-13]], the user relies on the iPhone to access and sync personal and work files alongside Windows devices.

## Role in the File Organization System
- Serves as the primary mobile platform for accessing the folder hierarchy described in the session, ensuring that the proposed [[concepts/folder_hierarchy]] works seamlessly on both iOS and Windows.
- Benefits from the [[concepts/cross_device_compatibility]] guidelines, such as using Windows‑safe characters (lowercase, dashes, no spaces) in filenames.
- Works with the same [[concepts/naming_conventions]] and [[concepts/date_based_filenames]] that the user adopts for consistent sorting and searching across devices.
- When combined with cloud services, the iPhone participates in the overall file syncing workflow, keeping the latest versions of documents available.

## Interaction with Other Entities and Concepts
- The iPhone syncs files with [[entities/windows_11]] computers, often via services supported by [[entities/microsoft]].
- It adheres to the same naming pattern that avoids issues with the iPhone’s file system, which mirrors the recommendations for Windows.
- While not directly involved in the project sub‑structure, the iPhone can browse the three‑folder layout inside each project ([[concepts/project_substructure]]) for quick reference.

## Relevant Concepts
- [[concepts/folder_hierarchy]] – the shallow two‑level structure applied uniformly on the iPhone.
- [[concepts/naming_conventions]] – the date‑first, lowercase, dash‑separated format that works on the iPhone.
- [[concepts/date_based_filenames]] – enables chronological ordering and easy searching on the device.
- [[concepts/year_subfolders]] – used for Personal → Documents → Finance → Taxes and Insurance, accessible from the iPhone.
- [[concepts/cross_device_compatibility]] – ensures the system works across iPhone and Windows.

## Summary
The iPhone is central to the user’s cross‑platform file syncing strategy, aligning with the naming and structural conventions outlined in the session to provide a simple, searchable, and low‑maintenance personal and work document system.
