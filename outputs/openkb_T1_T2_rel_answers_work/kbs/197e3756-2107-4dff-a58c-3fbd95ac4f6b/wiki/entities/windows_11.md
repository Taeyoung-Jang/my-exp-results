## Windows 11

Windows 11 is the latest desktop operating system released by [[entities/microsoft]]. It introduces a refreshed user interface, updated system settings, and improved integration with built‑in utilities such as [[entities/file_history]] for data protection and syncing.

### Mention in [[summaries/session-12_2024-06-15]]
In the "session-12_2024-06-15" conversation, Windows 11 is the platform on which the user wants to set up a simple, local‑only backup system. The advice focuses on using the OS's native **File History** feature to automatically back up user folders (Documents, Pictures, Videos, Desktop, and a custom Projects folder) to rotating external drives.

### Mention in [[summaries/session-32_2025-02-13]]
The "session-32_2025-02-13" discussion proposes a lightweight folder hierarchy and naming convention that works well on Windows 11. It suggests a shallow Personal/Work top‑level structure, year subfolders for Taxes and Insurance, and a three‑folder layout (Admin, Notes, Outputs) for each Work project. The recommended `yyyy‑mm‑dd_description[_optional‑context].ext` filename pattern is fully compatible with Windows 11’s file system and aids cross‑device syncing.

### Key Facts from the Sessions
- **Backup tool:** Use **File History** (Control Panel → System and Security → File History) for automatic versioned backups.
- **Folders to protect:** Standard user folders (Documents, Pictures, Videos, Desktop) plus a custom Projects folder.
- **Frequency & retention:** Daily backups, external drive plugged weekly, retention set to "Until space is needed".
- **Folder hierarchy:** Shallow Personal and Work top‑level directories with subfolders such as Finance, Health, Photos, and Projects.
- **Year subfolders:** Applied to Finance → Taxes and Insurance for better organization of high‑volume files.
- **Project layout:** Each project folder (`project‑name_YYYY`) contains Admin, Notes, and Outputs subfolders.
- **Naming convention:** `yyyy‑mm‑dd_description[_optional‑project‑or‑client].ext` using lowercase and dashes, ensuring Windows‑safe filenames and easy search.
- **Cross‑device compatibility:** The structure and naming work seamlessly on Windows 11 and iPhone, facilitating syncing via cloud services.
