# Summary of session-12_2024-06-15

**Date:** 2024-06-15

## Core Advice
- Use a **shallow, predictable folder hierarchy**: top‑level folders such as `Documents`, `Photos`, and `Projects` with year or year‑month subfolders. This keeps files discoverable without constant categorisation. [[concepts/file_organization]]
- Keep protection **entirely local** by employing **two external drives** that rotate (weekly & monthly) and rely on Windows 11’s built‑in **File History** for automated backups. [[concepts/local_backup_strategy]] [[entities/file_history]] [[entities/windows_11]]

## Recommended Backup Strategy
| Drive | Frequency | What to back up | Notes |
|------|-----------|----------------|-------|
| **Weekly drive** | Plug in once a week; let File History run automatically | User folders only – `Documents`, `Pictures`, `Videos`, `Desktop`, plus a custom `Projects` folder | Faster than full system image; protects personal data |
| **Monthly drive** | Swap in every month (or every few months) | Same set of folders, creates a second copy in case the weekly drive fails | Provides off‑site‑like redundancy without cloud |

## Windows 11 File History Setup (step‑by‑step)
1. Connect the external drive.  
2. Open **Control Panel → System and Security → File History**.  
3. Click **Turn on**; Windows will associate the drive.  
4. **Select folders** to back up:  
   - `Documents` and `Pictures` are included by default.  
   - Add your custom `Projects` folder via **Advanced settings → Add folder**.  
5. **Advanced settings** → set **Backup frequency** to **Daily** (File History will run when the drive is present).  
6. Set **Retention** to **"Until space is needed"** for simple version management. [[concepts/backup_retention_policy]]
7. Close the dialog – the system will now back up automatically whenever the drive is connected.

## Suggested Schedule & Retention
- **Backup frequency:** Daily (runs when drive present) – aligns with a weekly plug‑in routine.  
- **Retention policy:** Keep versions **until the drive fills up**; older versions are removed automatically, ensuring you always have recent copies without manual pruning. [[concepts/backup_retention_policy]]
