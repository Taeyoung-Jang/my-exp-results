# Summary

This document records a conversation that defines a lightweight, cross‑device file organization system. It proposes top‑level **Personal** and **Work** folders, a date‑centric filename pattern, selective use of year subfolders for tax and insurance documents, and a minimal three‑subfolder layout for each work project.

### Key Concepts
- **Folder Hierarchy** – A shallow two‑level structure for Personal and Work, avoiding deep nesting. [[concepts/folder_hierarchy]]
- **Naming Conventions** – Consistent `yyyy-mm-dd_description[_optional‑context].ext` format using lowercase, dashes, and no spaces for Windows‑safe compatibility. [[concepts/naming_conventions]]
- **Date‑Based Filenames** – Enables sorting and searching without relying on additional folder layers. [[concepts/date_based_filenames]]
- **Year Subfolders** – Applied only to *Taxes* and *Insurance* under Personal → Documents → Finance to keep high‑volume items tidy while keeping receipts flat. [[concepts/year_subfolders]]
- **Project Substructure** – Each project folder (`project‑<name>_YYYY`) contains three subfolders: **Admin**, **Notes**, and **Outputs**, providing just enough separation for contracts, meeting notes, and deliverables. [[concepts/project_substructure]]
- **Cross‑Device Compatibility** – Folder names and filenames avoid spaces and special characters, ensuring seamless syncing between Windows and iPhone. [[concepts/cross_device_compatibility]]

### Filename Pattern
```
yyyy-mm-dd_description_optional‑project‑or‑client.ext
```
- Use **lowercase** and **dashes**.
- Include the date for any time‑specific file.
- For non‑date files, start with the keyword (e.g., `contract_client‑alpha.pdf`).

### Example Files for a Work Project (`project‑beta_2026`)
- **Admin**: `2026-02-10_sow_project-beta_signed.pdf`
- **Admin**: `2026-03-01_contract-amendment_project-beta.pdf`
- **Notes**: `2026-03-05_meeting-notes_project-beta.txt`
- **Notes**: `2026-03-12_status-report_project-beta.docx`
- **Outputs**: `2026-04-20_final-deliverable_project-beta.pdf`

These examples illustrate the unified naming style across personal and work files, supporting easy search, chronological sorting, and minimal maintenance.
