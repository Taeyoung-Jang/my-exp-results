## Overview
A concise system for organizing software assets, including purchases, installers, receipts, license information, subscriptions, and device activations. The approach centers on a plain‑text / spreadsheet **software index** and a clear cloud‑based folder hierarchy, making migration to a new computer straightforward.

```
│   └─ Receipt.pdf
├─ FlowWrite Studio/
│   ├─ Installer.exe
│   └─ Receipt.pdf
└─ RetroSound Pack/
    └─ Receipt.pdf
```
Each product gets its own subfolder; file names mirror the product name for easy searching.

## Tracking Device Activations
Within the **Device Activations** column, list each machine using a simple pattern:
```
Device Name — Installed YYYY‑MM‑DD — Active/Deactivated
```
Multiple entries can be separated by line breaks or semicolons, keeping a historical view of where the license is active.

## Handling Account‑Based vs. Key‑Based Software
- **License Type** column identifies whether the software relies on a login/account or a serial/key.
- For **account‑based** entries, the **License Key** field contains “N/A” and the **Account/Email** field records the login.
- For **key‑based** entries, store the actual key location (e.g., password manager) in the **License Key** field.

## Benefits
- All critical information is self‑contained in the index, eliminating the need to search emails or old drives.
- Consistent naming aligns files with index rows, enabling quick lookup.
- Cloud storage ensures accessibility across devices and safeguards data during migrations.
- The template scales from a handful of apps to a large software collection.
