# Summary of session-37_2024-12-01

**Main Idea**: The document explains the signs that indicate a need for a [[concepts/fresh-start-decision]] (system reset/reinstall) on [[entities/windows]] or [[entities/macos]], and offers a step‑by‑step [[concepts/backup-checklist]] covering both obvious and “easy‑to‑forget” items such as 2FA recovery codes, license keys, local email archives, and SSH keys. It then details how to verify that nothing important was missed after a clean rebuild and how to safely import only the needed pieces.

## When to Choose a Fresh Start
- Persistent performance slowness, recurring crashes, or unclear root cause.
- Accumulated years of fragmented software, drivers, and background apps.
- When troubleshooting becomes guesswork and the time spent outweighs a reinstall.

## Comprehensive Backup Checklist ([[entities/windows]] & [[entities/macos]])
1. **Personal files** – Documents, photos, videos, Desktop, Downloads → external drive or cloud (Time Machine for macOS).  
2. **Browser data** – Sync bookmarks, passwords, extensions; export manually if no sync.  
3. **App settings & hidden data** – Export profiles for password managers, IDEs, games, custom `AppData` (Windows) or `Library` (macOS) folders.  
4. **Authentication materials** – Download/print 2FA recovery codes, export `.ssh` keys, VPN configs.  
5. **License & product keys** – Gather keys for paid software, export offline license files; see [[concepts/license-tracking]].  
6. **Local email archives** – [[entities/outlook]] PST/OST, [[entities/thunderbird]] profiles, [[entities/apple-mail]] local mailboxes.  
7. **Cloud‑sync status** – Ensure OneDrive, iCloud, Google Drive, Dropbox, etc., show *fully synced*; check for “not synced” flags.  
8. **App inventory** – Write a concise list of essential applications.  
9. **OS reinstall readiness** – Verify Microsoft account or Apple ID, create bootable media if desired.  
10. **Deactivate machine‑tied software** – [[entities/adobe]] and other pro apps may require deactivation before a reset.  
11. **Final sweep** – Scan secondary drives, VM images, Docker volumes, custom fonts, OBS profiles, etc.

## Post‑Rebuild Sanity‑Check
- **Inspect the old drive (read‑only)** for typical local‑only locations:  
  - **Windows**: `C:\Users\<user>\.ssh`, `Documents\Outlook Files`, `AppData\Local\Microsoft\Outlook`, `AppData\Roaming\Thunderbird\Profiles`, `AppData\Roaming\<vendor>`, `ProgramData\<vendor>`.  
  - **macOS**: `/Users/<user>/.ssh`, `/Users/<user>/Library/Mail`, `/Users/<user>/Library/Thunderbird`, `/Users/<user>/Library/Application Support/<vendor>`, `/Library/Application Support`.  
  - Common stash spots for **2FA recovery codes**: Documents, Desktop, Downloads, custom “Security” folders, Notes.  
- **Verify cloud sync completeness** by reviewing each provider’s web UI rather than relying on local caches.  
- **Copy only needed items**: transfer the exact file or subfolder (e.g., `id_rsa`, a single PST, a license file) to a neutral folder on the new system, then import via the application’s proper import routine.

## Safe Transfer Method
1. Mount the old drive read‑only.  
2. Locate the specific file/folder.  
3. Copy *just that item* to a temporary folder on the new machine.  
4. Use the target application’s import or restore function (e.g., Outlook → Import PST, SSH → place keys in `~/.ssh` with correct permissions).  

This approach aligns with [[concepts/data-migration-safety]] while preserving the clean rebuild.
