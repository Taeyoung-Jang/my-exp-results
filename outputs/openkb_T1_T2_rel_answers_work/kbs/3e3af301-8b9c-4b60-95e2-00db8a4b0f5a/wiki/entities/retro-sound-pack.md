# RetroSound Pack

RetroSound Pack is a cross‑platform software bundle acquired from **Humble Bundle**. It is managed using the **software inventory** approach described in [[summaries/session-08_2024-03-31]], with key information captured in a spreadsheet index and stored in cloud storage.

## Key Facts
- **Platform:** Cross‑platform (works on Windows, macOS, Linux)
- **License Type:** Account‑based (no serial key; authentication via the Humble Bundle account)
- **Purchase Source:** [[entities/humble-bundle]]
- **Installer:** Not stored separately (the bundle is delivered as assets, no dedicated installer file)
- **Receipt Location:** `Software/RetroSound Pack/Receipt.pdf`
- **Activation Limit:** None (unlimited activations)
- **Device Activations:** Tracked in the index (e.g., "Mac mini — Installed 2024‑04‑10 — Active")
- **Folder Structure:** Stored under the cloud folder `Software/RetroSound Pack/`, following the recommended [[concepts/cloud-storage-organization]] layout.
