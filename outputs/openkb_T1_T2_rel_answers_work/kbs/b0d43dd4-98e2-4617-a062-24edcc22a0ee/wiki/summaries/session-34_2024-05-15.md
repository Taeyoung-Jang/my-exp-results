# Purpose  
Provide a practical, low‑cost “commute experiment” to evaluate alternatives to the unreliable Northern Line and to generate data for negotiating schedule tweaks or extra work‑from‑home days.  

# Experiment structure  
A 2–3 week plan where each week isolates a different variable – departure time, alternative segment, then a combined best‑of‑both. Includes an example Mon‑Fri schedule for each week. This design follows the principles of [[concepts/commute-experiment-design]].  

# Variables to test  
- Departure‑time windows  
- Alternative lines, bus, or [[entities/london-overground]] segments (including walking to a nearby station)  
- Different stations (e.g., using a station on the [[entities/northern-line]] versus another nearby stop)  

# Tracking method  
Simple daily note template:  

```
Time:
Route:
Door‑to‑door minutes:
Crowding (low/med/high):
Stress on arrival (1–5):
Would I repeat this? (yes/no)
```  

The template captures quantitative and qualitative data for analysis and aligns with stress‑scoring.  

# Decision rule  
Adopt a routine if it yields consistently low stress (≤3 on the 1‑5 scale) and reasonable travel time on at least **three of five** days during the week‑three test. If no option meets this threshold, use the collected data to request a small start‑time shift or an additional WFH day.  

# Handling irregular mornings  
Label each commute as an “early‑start” or “normal‑start” day. Ensure each variation is tested at least twice within the same category. A total of **6–10** scored commutes across the experiment provides enough insight for a meaningful decision.  

# Negotiation angle  
Present the experiment results as evidence of proactive productivity management, framing the request as a data‑backed adjustment to maintain performance rather than a convenience perk. This approach aligns with hybrid‑work‑negotiation.
