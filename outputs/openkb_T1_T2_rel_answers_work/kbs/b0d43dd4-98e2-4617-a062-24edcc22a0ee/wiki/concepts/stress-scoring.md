# Commute Stress Scoring

**Definition**: A concise, repeatable method for measuring the subjective and objective difficulty of a daily commute, using a numeric stress rating combined with key travel metrics.

---

## Purpose
- Provides data for personal experiments such as the [[concepts/commute-experiment-design]] outlined in [[summaries/session-34_2024-05-15]].
- Supplies evidence when negotiating flexible work arrangements with managers, linking to the broader [[concepts/hybrid-work-negotiation]] framework.

---

## Core Scoring Template
Copy the block below into a note‑taking app after each journey:

```
Time:                (e.g., 08:10‑08:45)
Route:               (main line, alternative segment, etc.)
Door‑to‑door minutes: (total travel time)
Crowding:            low / med / high
Stress on arrival:   1–5 (1 = relaxed, 5 = highly stressed)
Would I repeat this? yes / no
```

- **Stress on arrival** is the primary metric; a score **≤ 3** is considered low‑stress.
- **Crowding** provides context for why a stress score may be high.
- The binary "Would I repeat this?" helps convert quantitative data into a clear preference signal.

---

## Decision Rule Integration
1. Run the experiment for three weeks as described in the source session.
2. Identify the configuration (timing + route) that yields a stress score ≤ 3 on at least **three of five** days in the final test week.
3. If no configuration meets this threshold, treat the data as justification for a schedule tweak or an extra work‑from‑home day.

---

## Handling Variable Mornings
- Tag each entry as **early‑start** or **normal‑start**.
- Ensure each route‑timing variant is tested **≥ 2** times within the same tag group.
- A total of **6–10** scored commutes across the whole experiment is sufficient to spot reliable patterns.
