# Code Pattern Memory

## Overview
Code Pattern Memory is a low‑risk strategy for remembering numeric security codes by encoding them as rhythmic taps, finger‑movement patterns, or short mnemonic phrases rather than storing the raw digits. The approach protects sensitive information while still giving the brain a reliable cue for fast recall.

## Methods
### Rhythm / Tap Pattern
- Break the code into a sequence of **strong** and **soft** beats (e.g., "strong‑soft‑soft‑strong").
- Practice the beat discreetly on your thigh, desk edge, or the keypad itself.
- The pattern is stored as a feeling, not as numbers.

### Phrase / Mnemonic
- Choose a short sentence where the stress pattern matches the rhythm of the code (e.g., "Here we go now" for a 4‑digit pattern).
- The words themselves do not reveal the digits; they only provide a cadence to latch onto.

## Low‑Risk Practice Plan
A 1–2 week schedule (see [[concepts/low-risk-practice-plan]]) helps cement the pattern without exposing the actual code:
1. **Days 1‑4:** 5 quick rhythm reps each morning and afternoon (tap on thigh or leg). < 30 seconds total.
2. **Days 5‑9:** Reduce to 2 reps in the morning and 1 in the afternoon.
3. **Days 10‑14:** One brief rehearsal per day.
4. **After week 2:** Optional every‑other‑day reminder.

**What NOT to do**: never speak the digits aloud, never type them anywhere but the genuine keypad, and avoid patterns that map directly to the numbers.

## Integration with Transition Support
When moving into a new living space, the need to remember a new building code is a common stress point. Pairing Code Pattern Memory with [[concepts/anchor-routines]] (tiny daily actions) and [[concepts/transition-support]] routines creates a comprehensive safety net for the whole transition.

## Anti‑Spiral Scripts
During moments of panic, brief self‑talk can reset the mental loop. Example scripts (also covered in [[concepts/anti-spiral-scripts]]):
- **At the keypad**: “I pause, I reset, and the pattern comes back. One breath, then try again.”
- **Entering a quiet apartment**: “I’m here, I’m safe, and it’s okay that this feels strange. I’m allowed to take this one moment at a time.”
