# Summary of session-37_2025-02-15

**Main focus:** How to enjoy TV/streaming content while multitasking and ensure audio description remains intelligible.

## Selecting shows for half‑watching
- Favor genres with clear, repetitive structure: comedies, procedurals, reality TV.
- Avoid dense world‑building or visual‑heavy dramas that punish missed details.
- Use subtitles and a modest volume boost to capture key dialogue. (See [[concepts/subtitle-distraction]])  
- Pause at natural breaks (scene changes, transitions) for quick mental recaps.

## Audio description usage
- Particularly useful for visually‑rich genres: mysteries, thrillers, character dramas, and animation.  
- High‑quality narration is common on premium streaming services such as [[entities/netflix]], [[entities/max]], [[entities/prime-video]], and [[entities/apple-tv-plus]].  
- Pair audio description with subtitles for dual reinforcement.  
- Adjust TV/app settings to prioritize narration (e.g., separate description track volume). See [[concepts/audio-description]].

## Recommended titles with strong audio description
- **Netflix:** [[entities/stranger-things]], [[entities/the-crown]], [[entities/arcane]] (note: Stranger Things can be busy).  
- **Max/HBO:** Succession, Station Eleven (plain text).  
- **Prime Video:** The Marvelous Mrs. Maisel (plain text), [[entities/reacher]] (very clear).  
- **Apple TV+:** [[entities/ted-lasso]], Severance (plain text; Severance can be a bit busy).  
- For the easiest half‑listening experience: [[entities/reacher]], [[entities/ted-lasso]], and [[entities/the-crown]].

## Audio‑setup tips for the kitchen
- Look for TV or soundbar settings: **dialogue enhancement**, **voice boost**, **speech clarity**, **night mode**, **dynamic range compression**, or **reduce loud sounds**. (See [[concepts/dialogue-enhancement]])  
- Enable night mode or compression to flatten loud‑quiet swings.  
- If available, a dedicated center channel can help, but strong processing often outweighs channel count.  
- Boost the description track volume slightly above the main mix.  
- Use a soundbar with a solid dialogue mode; a cheap 3.0 isn’t automatically better than a good 2.0 with processing, but both the processing and a center channel are ideal.
