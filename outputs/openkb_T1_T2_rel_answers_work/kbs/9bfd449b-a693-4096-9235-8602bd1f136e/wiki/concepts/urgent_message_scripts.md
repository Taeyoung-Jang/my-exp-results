# Urgent Message Scripts

**Definition**: A set of concise, reusable responses designed to acknowledge and triage messages labeled as “urgent” without breaking a protected focus window.

**Purpose**
- Preserve deep‑work blocks (see [[concepts/protected_focus_time]]) by deferring non‑critical interruptions.
- Communicate clearly that you are in a focus period while still offering a path for true blockers to be addressed.

**Core Scripts from [[summaries/session-12_2024-06-15]]**
1. **General acknowledgement** –
   > "Thanks for the note. I’m heads‑down until 10:45, but I’ll look at this as soon as I come up for air."
2. **Urgent‑but‑unclear** –
   > "I’m in a focus block right now. If this needs action before 10:45, let me know the deadline or what’s at risk so I can prioritize it properly."

**When to Use**
- Immediately after receiving a ping during a [[concepts/message_sweep]] or a brief mid‑focus glance.
- When the sender claims urgency but you cannot verify the impact within the first few seconds.

**How They Fit with Other Concepts**
- **Warm‑up ritual**: Scripts are typically sent after the warm‑up period and the first deep‑work block, reinforcing the boundary set at the start of the day (see [[concepts/warm_up_ritual]]).
- **Deep work**: By using these scripts, you minimize context switches, allowing the deep‑work intervals (see [[concepts/deep_work]]) to remain uninterrupted.
- **Triage checklist**: The scripts are the actionable output of the [[concepts/triage_checklist]] step that identifies a true blocker.

**Implementation Tips**
- Keep the scripts saved in a quick‑access note or template manager.
- Adjust the time reference (e.g., "until 10:45") to match your own schedule.
- If a true blocker is identified, follow the checklist: respond immediately if a one‑sentence reply resolves it, otherwise promise a specific follow‑up time.

**Benefits**
- Maintains productivity by reducing the mental load of crafting ad‑hoc replies.
- Sets clear expectations for colleagues about your availability.
- Enables rapid identification of genuine blockers without derailing focus.
