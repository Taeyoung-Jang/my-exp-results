# STG Presents

**Type:** Organization

STG Presents is a Seattle‑based organization that operates several prominent theater venues, including [[entities/paramount-theater]], [[entities/moore-theater]], and [[entities/neptune-theater]]. It maintains a centralized event calendar that lists live‑music shows, performances, and other cultural events across its venues.

## Key Facts from Session 02 (2024‑06‑15)
- Mentioned as a reliable source for live‑music schedules in Seattle.
- The calendar URL shared in the conversation: `https://www.stgpresents.org/calendar`.
- Recommended to cross‑check dates via the organizer’s page and to set reminders, aligning with the [[concepts/date-verification-workflow]].
- Highlighted for its **event‑calendar reliability**, making it a go‑to resource for up‑to‑date event information.
