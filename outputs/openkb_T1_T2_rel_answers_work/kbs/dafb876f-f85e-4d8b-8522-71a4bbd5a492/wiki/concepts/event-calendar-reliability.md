# Event Calendar Reliability

**Definition:** A set of criteria used to assess how trustworthy a local event calendar is for planning purposes.

**Key criteria (from [[summaries/session-02_2024-06-15]]):**
- **Source authority:** Calendars hosted by official city organizations (e.g., [[entities/visit-seattle]]) or major news outlets (e.g., [[entities/seattle-times]], [[entities/the-stranger]]) are generally more reliable.
- **Venue specificity:** Direct calendars from venues such as [[entities/paramount-theater]], [[entities/moore-theater]], [[entities/neptune-theater]] (grouped under [[entities/stg-presents]]) update quickly when dates shift.
- **Update frequency:** Sites that refresh listings regularly (e.g., [[entities/seattle-center]]) reduce the chance of outdated information.
- **Cross‑checking:** Verifying an event through the organizer’s own page and re‑checking a week before the date, as described in [[concepts/date-verification-workflow]].

**Practical tips:**
1. Start with a city‑wide calendar like [[entities/visit-seattle]] or [[entities/seattle-center]] for a broad overview.
2. Use news‑driven listings such as [[entities/seattle-times]] and [[entities/the-stranger]] for niche or nightlife events.
3. For live‑music schedules, rely on the venue’s own calendar (e.g., [[entities/stg-presents]]).
4. Add calendar reminders that link back to the original listing and revisit them a week before the event.
