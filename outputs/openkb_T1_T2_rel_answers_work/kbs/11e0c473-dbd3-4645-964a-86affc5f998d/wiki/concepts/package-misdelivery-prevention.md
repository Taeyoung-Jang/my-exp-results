# Package Misdelivery Prevention

**Type:** Concept

**Description:** Strategies and best practices for ensuring parcels are delivered to the correct new address during a residential move.

## Overview
When moving, the risk of packages being sent to the old residence spikes dramatically. Misdelivered parcels can lead to missed items, exposure of personal information, and added hassle for both the sender and recipient. This concept captures the practical steps outlined in the moving checklist from [[summaries/session-32_2025-02-15]] to prevent such issues.

## Key Strategies

1. **Consolidate Shipping Addresses**
   - Remove or deactivate the old address from major retailer accounts (Amazon, Target, Walmart, Instacart, etc.) for the first few weeks after the move. This forces all new orders to use the new address.
   - Keep only one active default shipping address until you are confident that all services have been updated.

2. **Pause Automatic Shipments**
   - Temporarily suspend recurring deliveries (meal kits, subscription boxes, pet supplies) until the new address is fully functional. Resume them only after confirming the new address is active in the service’s system.

3. **Leverage Carrier Reroute Services**
   - Use tools such as **UPS MyChoice**, **USPS Informed Delivery**, and **FedEx Delivery Manager** to reroute any shipments that are still heading to the previous location. These services allow you to redirect parcels to the new address or hold them at a local facility for pickup.

4. **Check Addresses at Checkout**
   - Make a habit of verifying the shipping address on every order, even if the default is set correctly. This extra step catches any lingering old addresses in saved profiles.

5. **Monitor Forwarded Mail**
   - Set up USPS mail forwarding and regularly review forwarded items for any missed package notifications. Update any overlooked services promptly.

6. **Communicate with Senders**
   - For expected high‑value or time‑sensitive items, contact the sender directly to confirm the correct delivery address well in advance of the move.

## Timeline Integration
These actions map onto the **moving checklist timeline**:
- **Now**: Set up USPS forwarding, delete old addresses from online retailer accounts, pause automatic shipments.
- **Before Movers**: Verify carrier reroute options are activated; ensure any pending shipments are redirected.
- **Moving Week**: Double‑check checkout screens; monitor forwarding notifications.
- **After Settled**: Review any remaining forwarded parcels; finalize any lingering address updates.
