# Summary of session-07_2022-09-15

**Context** – A caregiver with limited 30–60 minute evening slots seeks practical, interruptible ways to earn income and build skills while caring for a young daughter.

## Decision Rule
- Choose tasks that can be completed in a single sitting with **no meetings or phone calls**.
- If the task is **clearly scoped**, **file‑based**, and **finishable in ≤ 3 hours**, it passes. Otherwise, skip.
- This rule favours **spreadsheet cleanup** over writing because spreadsheets are more self‑contained.

## Micro 8–12 Week Plan
| Week(s) | Focus | Typical 30–60 min Session |
|--------|-------|---------------------------|
| 1‑2 | Refresh spreadsheet basics (one function per session) | Watch 5‑min tutorial → apply function on a mock sheet |
| 3‑6 | Find and complete one‑off tasks | Session 1: browse marketplace & vet tasks; Session 2‑3: execute task; Session 4: submit & log outcome |
| 7‑12 | Repeat task cycle + brief skill refresh | Continue pattern; use any spare slot for a new function or quick cleanup |

## Task Vetting Checklist
1. **Clear deliverable** – e.g., “clean this sheet,” “dedupe rows.”
2. **Single file/dataset** – no ongoing workflow.
3. **Communication limited to messaging** – no scheduled calls/meetings.
4. **Flexible deadline** – can fit into 1‑3 short sessions.
5. **Total effort ≤ 3 hours** – you can picture finishing it in that time.

If any item fails, discard the posting.
