# CSV (Comma‑Separated Values)

**Type:** other

## Overview
CSV (Comma‑Separated Values) is a simple, plain‑text file format for representing tabular data. Each line corresponds to a row, and fields within a row are separated by commas. It is widely supported by spreadsheet applications such as [[entities/google-sheets]] and [[entities/microsoft-excel]].

## Role in [[summaries/session-07_2022-09-15]]
In the caregiver‑focused planning session, CSV files are mentioned as the typical input for **interruptible** data‑cleanup gigs. The suggested micro‑planning approach involves short bursts of work to clean, deduplicate, or reformat CSV files, fitting the user’s limited 30–60 minute time slots.
