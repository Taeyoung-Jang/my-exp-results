# RemoteOK (Organization)

## Description
RemoteOK is a remote‑work job board that lists short‑term, one‑off projects, including spreadsheet cleanup and data tasks.

## Relevance to session‑07 (2022‑09‑15)
In the caregiver’s micro‑planning guide, RemoteOK is cited as a source for finding interruptible, low‑commitment spreadsheet tasks that fit into 30–60 minute sessions. It aligns with the [[concepts/interruptible_work]] and [[concepts/micro_planning]] approach.

## Typical Use Cases
- Search with keywords such as “spreadsheet cleanup”, “data cleanup”, “CSV formatting”, “one‑time”, “fixed‑scope”.
- Evaluate listings using the [[concepts/task_vetting_checklist]] to avoid hidden meetings or ongoing commitments.
