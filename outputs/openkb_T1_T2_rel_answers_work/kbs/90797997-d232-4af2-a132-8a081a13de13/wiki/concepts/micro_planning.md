## Micro Planning

**Definition**

Micro Planning is the practice of dividing a broader objective into very small, concrete actions that can be completed in 30–60 minute blocks. Each micro‑task is self‑contained, has a clear deliverable, and can be started or stopped without penalty. This approach aligns work with irregular schedules and minimizes the risk of overwhelm.

**Key Elements**
- **Time‑boxing**: Allocate a specific short window (e.g., 30–60 minutes) for each micro‑task.
- **Clear Scope**: Define a single, finishable outcome for the session.
- **Flexibility**: Tasks can be skipped or rescheduled without cascading delays.
- **Iterative Review**: Periodically assess progress and adjust the next micro‑tasks.

**Application in [[summaries/session-07_2022-09-15]]**

In the caregiver scenario of session‑07, Micro Planning structures an 8–12 week roadmap:
1. **Weeks 1‑2**: Refresh spreadsheet functions one per session.
2. **Weeks 3‑6**: Search for one‑off spreadsheet gigs, vet them using the checklist, and complete each in 1‑3 sessions.
3. **Weeks 7‑12**: Repeat the search‑execute‑review cycle, inserting brief skill‑refresh micro‑tasks as needed.

Each 30–60 minute slot is treated as a discrete micro‑task (e.g., “watch a 5‑minute VLOOKUP tutorial and apply it to a mock sheet”). This keeps progress steady despite weeks of zero availability.

**Practical Steps for Implementing Micro Planning**
1. **Create a micro‑task list** – write down all possible tiny actions (e.g., "practice SUMIF", "apply FILTER to dataset").
2. **Prioritize by impact and ease** – choose tasks that use existing skills and can be completed quickly.
3. **Schedule loosely** – block out tentative evening slots, but allow gaps.
4. **Execute and record** – after each session, note completion and any blockers.
5. **Review every 2‑3 weeks** – adjust the micro‑task list based on progress and changing caregiver constraints.
