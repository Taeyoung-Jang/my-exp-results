# Weekend Template

**Definition**: A flexible, rhythm‑based schedule that allocates distinct blocks for errands, restorative activities, and optional social engagements, helping the weekend feel intentional without becoming overloaded. [[concepts/intentional_weekend_planning]]

---

## Core Principles
1. **Anchor Activity** – Choose one primary activity (e.g., a workshop, hike, or coffee) that defines the weekend’s focus.
2. **Contain Errands** – Reserve a short, defined window (typically 1–2 hours) for chores so they don’t spill over.
3. **Energy‑Based Variants** – Provide a *minimum‑viable* (low‑energy) and a *higher‑energy* version that expand or contract optional blocks based on how you feel. [[concepts/energy_management]]
4. **Open Space** – Preserve unscheduled time for spontaneity or rest.
5. **Decision Rule** – Use a quick Friday checklist to decide which variant to apply. [[concepts/decision_rule]]
6. **Boundary Setting** – Simple scripts for declining additional invitations when the template is already full. [[concepts/boundary_setting]]

## Using the Template
1. **Identify the anchor** – schedule the workshop or primary activity first.
2. **Allocate a tight errand window** – keep it under two hours.
3. **Apply the energy variant** – answer the three decision questions (body feeling, social craving, capacity) to pick low or high.
4. **Protect open time** – treat any unscheduled slot as sacred; avoid adding tasks spontaneously.
5. **Communicate boundaries** – if friends suggest last‑minute plans, use a brief, kind decline (e.g., “I’m taking it slow this weekend so I don’t run myself down, but let’s plan soon”).
