# Task Vetting Checklist

**Purpose** – Provide a concise, repeatable filter for evaluating one‑off freelance opportunities so they remain compatible with limited, irregular time windows and avoid hidden commitments.

**Origin** – Derived from the guidance in [[summaries/session-07_2022-09-15]], which outlined a caregiver’s need for short, interruptible work.

## Checklist Items
1. **Clear Deliverable** – The posting must state a specific outcome (e.g., “clean this sheet,” “dedupe rows”).
2. **Single File / Dataset** – The work should involve one file or a bounded dataset, not an ongoing workflow.
3. **Communication Limited to Messaging** – No scheduled calls, meetings, or collaboration‑tool sessions; only asynchronous messages.
4. **Flexible Deadline** – The timeline must allow completion in 1‑3 short sessions (30–60 min each) without strict hourly constraints.
5. **Total Effort ≤ 3 hours** – You should be able to picture finishing the entire task within three hours of work.

If any item fails, the task should be skipped.

## How It Connects to Other Concepts
- Supports [[concepts/interruptible_work]] by ensuring tasks can be paused and resumed without penalty.
- Aligns with [[concepts/micro_planning]] by breaking a larger goal into tiny, time‑boxed sessions.
- Addresses [[concepts/caregiver_constraints]] such as limited evening windows and occasional zero‑time weeks.
- Works hand‑in‑hand with [[concepts/marketplace_search_keywords]] to locate suitable listings on platforms like [[entities/upwork]], [[entities/fiverr]], [[entities/remoteok]], and [[entities/weworkremotely]].

## Practical Use
When browsing a marketplace, quickly run through the five points before committing. This mental run‑through takes seconds and prevents taking on tasks that could evolve into meetings, ongoing projects, or time‑intensive work.
