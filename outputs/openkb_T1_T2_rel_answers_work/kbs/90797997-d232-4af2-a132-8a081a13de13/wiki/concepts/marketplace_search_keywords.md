# Marketplace Search Keywords

**Definition** – A set of search terms and modifiers that help users find short‑duration, interruptible spreadsheet or data‑cleanup gigs on various online marketplaces.

## Core Idea
When time is limited to 30–60 minute windows and there is a need to avoid meetings or ongoing commitments, using the right keywords is essential. The right phrasing surfaces listings that match the constraints of [[concepts/caregiver_constraints]] and the need for [[concepts/interruptible_work]].

## Typical Keywords & Modifiers
- "spreadsheet cleanup"
- "data cleanup"
- "CSV formatting"
- "Excel reformat"
- "Google Sheets tidy"
- "deduplication task"
- Adding qualifiers such as "one‑time", "one‑off", "fixed‑scope", or "short project" to filter out ongoing roles.

## Where to Search
- **[[entities/upwork]]** – Use the keyword list in the search bar and filter by "Project type: Fixed‑price".
- **[[entities/fiverr]]** – Look under the "Data Entry & Admin" category and include the modifiers.
- **[[entities/remoteok]]** – Search the job feed with the terms; look for "contract" or "freelance" tags.
- **[[entities/weworkremotely]]** – Occasionally posts one‑off gigs; use the same keyword set.
- **[[entities/discord]]** – Join freelancer or data‑cleaning Discord servers and search channel archives with the terms.

## How It Connects to Other Concepts
- The keywords support a [[concepts/micro_planning]] approach by allowing the user to locate tasks that can be completed in a single micro‑session.
- They complement the [[concepts/task_vetting_checklist]]: after finding a posting with these keywords, the checker confirms scope, communication limits, and time estimate.

## Example Search String
```
"spreadsheet cleanup" OR "data cleanup" OR "CSV formatting" "one‑off" "fixed‑scope"
```
Using this string on the platforms above yields listings that are more likely to be self‑contained and suitable for brief work bursts.
