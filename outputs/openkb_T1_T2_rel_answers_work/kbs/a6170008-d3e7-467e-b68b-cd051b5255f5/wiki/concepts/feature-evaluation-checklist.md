# Feature Evaluation Checklist

**Definition**: A systematic set of questions used to determine which subscription features are essential for a user's workflow, helping avoid paying for unnecessary extras.

## Core Questions (from [[summaries/session-14_2024-06-15]])
1. **What do you actually use every week?**
   - Identify the core editing tools, collaboration frequency, and version‑history needs you rely on day‑to‑day.
2. **What would you miss if it disappeared tomorrow?**
   - Pinpoint features whose absence would disrupt your productivity (e.g., real‑time collaboration, advanced security controls).
3. **Does the current tier already cover these needs?**
   - Compare your weekly usage against the feature list of your existing plan.
4. **Are higher‑tier features needed on a regular basis?**
   - Assess whether extras like deeper version history, enhanced admin tools, or priority support are used weekly or only occasionally.
5. **What is the cost impact over a year?**
   - Translate monthly prices into yearly totals to see the real financial effect of adding a tier or add‑on. See also [[concepts/cost-over-time]].

## Applying the Checklist
- **Step 1**: List the features you use most often.
- **Step 2**: Mark those that are *critical* (you would miss them if removed).
- **Step 3**: Map those critical features to the capabilities of each subscription tier.
- **Step 4**: Calculate yearly cost for your current plan vs. potential upgrades, using the cost‑over‑time perspective.
- **Step 5**: Decide based on the *value* each tier adds versus its price.
