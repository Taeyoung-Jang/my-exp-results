# Summary of session-39_2025-03-14

## Main contribution
A practical workflow for auditing software subscriptions, detecting hidden annual renewals, and tracking them with reminders.

## Audit workflow [[concepts/subscription_auditing]]
1. **Collect charge sources**: app store subscription pages, email receipts, bank/credit‑card statements.  
2. **Create a master list** (name, cost, frequency, renewal date).  
3. **Evaluate each entry** with questions: usage frequency, value vs. cost, alternatives.  
4. **Remove or downgrade** anything unused or replaceable.

## Spotting annual renewals [[concepts/annual_renewal_detection]]
- Search email for keywords like “annual”, “renewal”, “receipt”, “invoice”, “subscription”.  
- Compare the current bank statement with the same month from the previous year.  
- Look for transaction descriptions that hint at vendor vs. app‑store.

## Tracking options [[concepts/recurring_payment_tracking]]
- **Spreadsheet** – sortable by renewal date or cost.  
- **Notes/finance app** – centralised view if already in use.  
- **Calendar reminders** – set alerts a week‑two before each renewal; the most reliable fail‑safe.

## Determining charge source
- Transaction line mentions **[[entities/apple]]**, **[[entities/google]]**, iTunes, Play Store → app‑store subscription.  
- Vendor name or processor such as **[[entities/stripe]]**, **[[entities/paddle]]** → direct vendor billing.  
- Follow the clue to the appropriate subscription page:  
  - **App‑store** → device settings → subscriptions.  
  - **Vendor** → website account → billing section.

## Quick confirmation steps
1. Read the exact wording of the bank line.  
2. Open the corresponding app‑store or vendor account.  
3. Verify plan name, price, and renewal date.  
4. If still unclear, search email for the vendor name to locate the original receipt.

## Recommendations
- Keep the master list up‑to‑date; refresh every 3‑4 months.  
- Always add a calendar event for annual renewals; this prevents surprise charges.  
- Use the source‑identification cue to know where to manage the subscription.
