# Android (product)

Android is a mobile operating system developed by Google, used on a wide range of smartphones and tablets.

## Key facts from session-05_2025-06-15
- The conversation highlights how to manage location permissions on Android devices, including setting location access to "Allow only while using the app" to block background location retrieval.
- Android offers a special "Allow all the time" permission that grants continuous location access; users are advised to revoke this for privacy.
- The document mentions Android’s privacy features such as permission auto‑reset, which can automatically revoke permissions for apps that haven’t been used for a while.
