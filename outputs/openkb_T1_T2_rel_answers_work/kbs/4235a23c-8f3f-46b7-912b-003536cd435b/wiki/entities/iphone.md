# iPhone

Apple's flagship smartphone running the iOS operating system.  It provides granular location‑permission controls that let users balance privacy with app functionality.

## Key facts from [[summaries/session-05_2025-06-15]]
- **Location permission models**: Settings → *App* → *Location* offers *Never*, *Ask Next Time*, *While Using the App*, and *Always* options.  The *While Using* mode restricts location access to foreground use and blocks widgets, Live Activities, and Background App Refresh.
- **Precise vs. Approximate location**: A toggle beneath the permission choices lets users turn off **Precise Location**, giving apps only a coarse estimate.
- **System location services**: Features such as **Significant Locations**, **Location‑Based Alerts**, and **Find My** can cause the location indicator to appear even when third‑party apps lack permission.  Disabling Significant Locations reduces system‑level tracking while keeping useful services.
- **Privacy vs. functionality trade‑off**: Apps that rely on location for core functions (maps, ride‑hailing, weather) work best with *While Using*.  Others (shopping, social media, games) can usually be set to *Never* without loss of core features.
