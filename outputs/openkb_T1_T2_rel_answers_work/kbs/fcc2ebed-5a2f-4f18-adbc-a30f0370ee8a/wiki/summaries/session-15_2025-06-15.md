# Summary of session-15_2025-06-15

**Main recommendation** – Build a backup system that is *reliable* and *convenient* first, then layer *privacy*, *cost* and *redundancy*.

## Priorities & Common Mistakes
- Prioritize **reliability** (automatic, runs without manual effort) and **convenience**. [[concepts/backup-reliability]]
- Typical errors: single backup location, trusting cloud as infallible, never testing restores, ignoring app‑data backups, and postponing manual backups. (common mistakes)

## Core Offline Backup Architecture
- **Two‑drive + primary device** model:
  1. Primary device (computer/phone) holds the live data.
  2. **Drive A** – always connected for automatic local backups.
  3. **Drive B** – connected occasionally and stored in a separate physical location.
- Guarantees that a single hardware failure or power surge cannot erase all copies. [[concepts/backup-redundancy]]

## Encryption Strategy
- Prefer **full‑disk encryption** of the external drives for simplicity (single password, protects everything). (encryption)
- Use per‑category encrypted containers only if you need separate passwords or selective sharing. (encrypted containers)

## Testing Restores
- Perform a quick restore check **every 2‑3 months**: retrieve a few files from each backup to confirm readability and currency. (backup testing)

## Handling Photos & Notes without Cloud
- **Phone photos** → plug phone via USB (or MTP) and let the computer auto‑import to a designated folder tree. Weekly imports keep the flow simple. [[entities/usb]] [[entities/mtp]]
- On iOS use the regular USB connection and the Photos app to pull everything into your chosen directory. [[entities/ios]]
- On Android use MTP so the phone mounts like a camera. [[entities/android]]
- Optional local‑network transfer apps can automate this when both devices share Wi‑Fi, still avoiding cloud services.
- **Notes** – ensure the note‑taking app stores plain files; if not, export notes periodically (e.g., weekly) so they are captured by the backup routine. (manual export)

## Optional Tweaks
- A NAS adds convenience only if you want a always‑on central box; otherwise it introduces extra maintenance. [[entities/nas]]
- Encrypted disk images are a viable alternative to full‑disk encryption but add an extra step.

## Action Checklist
- [ ] Set up two external drives with automatic backup software. [[concepts/offline-backup]]
- [ ] Enable full‑disk encryption on both drives.
- [ ] Schedule weekly photo imports via USB/MTP.
- [ ] Export notes from proprietary apps at least weekly.
- [ ] Perform a restore test every two months.
