# Network-Attached Storage (NAS)

**Type:** product

Network-Attached Storage (NAS) is a dedicated hardware device that offers centralized file storage and sharing over a local network. It acts as a self‑contained server, allowing multiple computers, phones, and tablets to read and write data without needing a separate computer to be on.

## Key points from [[summaries/session-15_2025-06-15]]
- Mentioned as an optional tweak to the basic two‑drive backup strategy.
- Suggested only if the user wants extra convenience of an always‑on central box.
- Not required for a purely offline backup workflow; adds extra maintenance overhead.

## Related concepts
- [[concepts/backup-redundancy]] – NAS can provide an additional physical location for redundant copies.
- [[concepts/offline-backup]] – While NAS is typically online, it can be part of an offline backup plan when paired with encrypted external drives.
