# Microsoft Windows

Microsoft Windows is a widely used desktop operating system for personal computers. In the context of the conversation **session‑03_2025-07-21**, Windows is mentioned as a target device for applying sleep‑optimising display settings.

## Key facts from the session
- **Brightness**: Recommended to keep the screen at roughly **20 %–30 %** brightness in a dim environment.
- **Night Light**: Enable Windows’ *Night Light* feature and push the warmth slider **almost to the maximum** to reduce blue‑light exposure.
- **Dark Mode**: Use dark mode to minimise bright UI elements that can be stimulating before sleep.
- **Additional steps**: If the screen still feels bright, a further small reduction in brightness is more effective than other tweaks.
