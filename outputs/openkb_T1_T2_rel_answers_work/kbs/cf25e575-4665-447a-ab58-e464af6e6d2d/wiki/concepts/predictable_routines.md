# Predictable Routines

## Definition
Predictable routines are the agreed‑upon, day‑to‑day patterns that both parents maintain in each household—such as bedtime, homework habits, screen limits, and basic rules. By keeping these elements consistent, children know what to expect regardless of which home they are in.

## Key Details from [[summaries/session-33_2025-04-13]]
- **Core routines**: Parents should align on bedtime, homework, and screen time so the child experiences the same expectations in both homes.
- **Regular check‑ins**: Brief text updates about schedules, mood changes, or unusual events help keep the routine seamless.
- **Low‑drama consistency**: When routines stay steady, transitions become smoother and the child feels safer.

## Benefits
- Reduces anxiety and behavioral issues by providing a stable environment.
- Supports smooth [[concepts/handoff_routine]] exchanges because the child’s daily expectations are unchanged.
- Limits conflict between parents, as disagreements over everyday rules are minimized.

## Implementation Tips
1. **Create a joint routine checklist** covering bedtime, meals, homework, and screen time.
2. **Synchronize calendars** and share any changes promptly via text.
3. **Use the same language** and cues (e.g., “It’s time to pack for the handoff”) in each home.
4. **Revisit the routine regularly** during [[concepts/low_drama_transitions]] check‑ins to adjust for growth or schedule shifts.
