# Weekly Progression

**Definition:** A systematic approach to increase training stimulus week‑by‑week while keeping the overall structure of hard and low‑activity days unchanged.

**Why it matters** – In the plan described in [[summaries/session-13_2025-05-03]], the athlete has three hard sessions per week that each require a full 24‑hour low‑activity recovery window. Adding another hard day would break the recovery rhythm, so progress must come from small, controlled upgrades inside the existing days.

## Core principles

1. **Keep the schedule static** – The pattern hard / low‑activity / hard / low‑activity / … remains the same (see [[concepts/hard-day-structure]]).
2. **Make incremental load changes** – Each week add a minimal amount to one variable:
   - Cardio: +1‑2 interval rounds **or** +2‑4 min to a steady‑state effort.
   - Strength: increase weight by ~5 % **or** add 1‑2 reps per set.
   - Mixed day: extend circuit time by 2‑3 min or tighten rest intervals.
3. **Respect the low‑activity cap** – Recovery days stay at 20‑40 min of very easy movement (effort 2‑3 / 10) as defined in [[concepts/low-activity-cap]].
4. **Use recovery markers** – Before deciding to apply the weekly increment, check sleep quality, resting heart rate, and mood (see [[concepts/recovery-markers]]). If any marker is off, hold the progression for that week and prioritize recovery.
5. **Progress only if ready** – The simple two‑question rule (refreshed on waking? feels ready during warm‑up?) from the source guides whether to execute the full hard session or substitute a low‑activity day. Only when both answers are “yes” should the planned increment be applied.

## Sample 4‑week progression (based on the session‑13 schedule)

| Week | Cardio change | Strength change | Mixed day change |
|------|---------------|----------------|------------------|
| 1 | Baseline | Baseline | Baseline |
| 2 | +1 interval round (or +3 min steady) | +5 % load on all lifts | +2 min circuit |
| 3 | +1 more interval round (or +3 min steady) | +5 % load or +1 rep per set | +2 min circuit |
| 4 | Evaluate markers – repeat Week 3 load if recovery is good, otherwise maintain Week 2 load |

The progression is intentionally modest so that the 24‑hour recovery window remains sufficient each time.

## Interaction with other concepts

- Aligns with [[concepts/recovery-first-scheduling]] by never adding stress on designated low‑activity days.
- Relies on the structure described in [[concepts/hard-day-structure]].
- Uses the effort limits from [[concepts/low-activity-cap]] and the monitoring framework from [[concepts/recovery-markers]].

*The weekly progression approach provides a clear, low‑risk pathway to improve fitness while honoring the body’s need for full recovery after each hard effort.*
