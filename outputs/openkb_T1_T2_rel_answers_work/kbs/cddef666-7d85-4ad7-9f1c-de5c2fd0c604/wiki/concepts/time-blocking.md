# Time Blocking

**Definition** – Time Blocking is a scheduling technique that groups activities into broader, purpose‑driven blocks (e.g., "office work", "client site", "gym") rather than listing every single task. Each block has a clear start, core work, and closing steps, which simplifies transitions and reduces decision fatigue.

## How it works
1. **Identify anchor points** – Fixed routines that frame the day, such as a morning setup and an evening shutdown. (See [[concepts/daily-anchors]])
2. **Create blocks by location or goal** – For example, an "office" block, a "client site" block, a "co‑working call" block, etc.
3. **Insert buffers** – Small cushions (5‑10 minutes) before and after each block to absorb overruns and provide mental reset time. ([[concepts/buffers]])
4. **Label core vs. trim‑first activities** – Within each block, mark which items are essential (core) and which can be shortened or moved (trim‑first). ([[concepts/core-vs-trim-first]])

## Example from a real day
The approach is illustrated in [[summaries/session-40_2024-12-16]], where a schedule from 8:30 am–9:00 pm is broken into five main blocks:
- Morning setup (anchor)
- Office work block
- Client site block
- Co‑working call block
- Gym block
- Dinner block (anchor)

Each block contains a brief buffer, a core activity period, and optional trim‑first tasks (e.g., quick admin, shower). When a meeting overruns, the buffer mitigates impact, and any needed adjustments are made to the next trim‑first segment rather than the core commitments.

## Benefits
- **Predictable transitions** – Fewer frequent context switches.
- **Flexibility** – Overruns are absorbed by buffers, preserving core commitments.
- **Focus** – By treating a block as a container, you can concentrate on the primary purpose of that time chunk.
- **Reduced stress** – Clear structure and anchor points give the day rhythm.
