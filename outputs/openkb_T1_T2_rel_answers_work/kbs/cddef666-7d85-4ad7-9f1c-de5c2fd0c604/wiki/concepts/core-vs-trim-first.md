# Core vs Trim‑First

**Core vs Trim‑First** is a decision‑making framework for daily planning that classifies activities into two categories:

- **Core** – tasks that must happen as scheduled because they affect other people’s time, commitments, or critical outcomes. Missing or shifting a core item can cause downstream disruptions.
- **Trim‑First** – tasks that are optional or internal to your workflow. When time runs short, these are the first elements to shorten, postpone, or drop.

## Why it matters
In highly fragmented days, like the one described in [[summaries/session-40_2024-12-16]], the schedule is built from multiple location‑based **blocks**. Each block contains a mix of core responsibilities (e.g., meetings, client visits, dinner) and supporting activities (e.g., quick debriefs, admin notes, shower). By labeling each element, you gain a clear hierarchy for handling overruns without collapsing the entire day.

## How to apply
1. **Identify core items** – Anything that involves another person’s schedule (meetings, appointments, social events) or a non‑negotiable commitment.
2. **Mark trim‑first items** – Administrative follow‑ups, optional prep, personal routines that can be compressed.
3. **Insert [[concepts/buffers]]** – Small time cushions before and after each block absorb minor delays, protecting core items.
4. **Use [[concepts/daily-anchors]]** – Fixed routines (morning setup, evening shutdown) are core because they frame the day.
5. **Integrate with [[concepts/time-blocking]]** – When you group tasks into larger blocks, assign core vs trim‑first status within each block.

## Practical example (from the session‑40 day)
| Time | Block | Core / Trim‑First | Notes |
|------|-------|-------------------|-------|
| 8:30‑9:00 | Morning setup (anchor) | **Core** | Sets the day’s rhythm |
| 9:15‑11:00 | Office work | **Core** | In‑person duties that require badge access |
| 11:00‑11:05 | Transition buffer | – | [[concepts/buffers]] |
| 11:05‑11:10 | Quick admin notes | **Trim‑First** | Can be moved later |
| 13:30‑14:30 | Co‑working call | **Core** | External meeting |
| 14:30‑14:35 | Post‑call buffer | – | [[concepts/buffers]] |
| 15:15‑16:45 | Gym workout | **Core** (self‑care) | Flexible if needed |
| 16:45‑16:55 | Shower / transition | **Trim‑First** | Shorten if running late |
| 18:00‑20:00 | Dinner with partner | **Core** | Affects another person |
| 20:15‑20:30 | Night shutdown (anchor) | **Trim‑First** | Review can be brief |

When a meeting overruns by 20‑30 minutes, the buffers absorb the spill. If the overrun still encroaches on the next block, you first trim the **Trim‑First** items (e.g., shorten the post‑meeting debrief or shower) before cutting into any **Core** activity like dinner.

## Decision rule summary
- **Protect anything that impacts others** → keep as **Core**.
- **Flex internal or personal tasks** → treat as **Trim‑First**.
- Use buffers and anchors to give the system breathing room.

By consistently applying the **Core vs Trim‑First** lens, you can maintain a predictable rhythm even on days packed with transitions and commitments.
