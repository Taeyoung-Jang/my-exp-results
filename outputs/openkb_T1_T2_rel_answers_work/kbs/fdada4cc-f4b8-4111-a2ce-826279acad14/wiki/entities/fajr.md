# Fajr (work)

Fajr is the first of the five daily Islamic prayers, performed before sunrise. In the context of a typical 9 am–5 pm workday, it serves as the anchor for the morning portion of a new Muslim’s daily routine.

## Key points from [[summaries/session-33_2024-06-15]]
- **Timing**: Wake up 20–30 minutes before Fajr to allow for wudu (ritual ablution) and a calm start to the day.
- **Preparation**: Performing wudu before Fajr helps ensure the prayer can be completed quickly and without disruption.
- **Routine integration**: Fajr marks the start of the [[concepts/daily_prayer_routine]], setting the tone for subsequent prayers ([[entities/dhuhr]], [[entities/asr]]) throughout the workday.
- **Consistency tips**: Treat Fajr as a non‑negotiable daily habit; if missed, pray as soon as possible without self‑criticism.

## Practical advice for the workplace
- **Morning schedule**: Set an alarm slightly earlier than usual to accommodate waking, wudu, and the Fajr prayer before commuting.
- **Mindset**: View Fajr as a grounding moment that prepares you for the day’s responsibilities.
- **Flexibility**: If travel or scheduling delays occur, perform the prayer as soon as you can within the prescribed time window.
