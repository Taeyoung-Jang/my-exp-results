## Daily Scheduling

**Definition**: A concise, repeatable morning routine that helps you pick 2–3 priority tasks, set an energy or time cap, and protect buffer time for the day.

### Core Elements
1. **Three‑task template**
   - *Non‑negotiable*: the one thing that must happen today.
   - *Week‑easing*: a task that smooths the rest of the week.
   - *Wellbeing*: a habit or chore that supports personal health or daily functioning.
2. **Energy cost rating** – label each task low, medium, or high.
3. **Cap definition** – specify a concrete limit, e.g., "max 3 hours scheduled" or "only 2 high‑energy tasks".
4. **Buffer protection** – reserve an explicit free slot (e.g., one hour) or limit back‑to‑back high‑energy work.
5. **Postponement list** – capture tasks you are choosing to delay without guilt.

### Process (≈5 minutes each morning)
```markdown
Today’s non‑negotiable task (must happen today): _______
One task that would make the rest of the week easier: _______
One task that supports my wellbeing or keeps life running smoothly: _______
Energy cost for each task (low / medium / high):
• Non‑negotiable: _______
• Week‑easing task: _______
• Wellbeing task: _______
My cap for today (e.g., max 3 hours scheduled or only 2 high‑energy tasks): _______
Built‑in buffer I’m protecting (e.g., one free hour): _______
Tasks I’m postponing without guilt: _______
```

### Decision‑Making Gates
1. **Consequence** – Does missing this task cause real fallout?
2. **Wellbeing** – Does it protect or enhance health/stability?
3. **Energy cost** – Prefer lower‑cost tasks when the first two gates are met.

### Handling Mid‑Day Interruptions
- Evaluate the new request against the three gates.
- If it outranks an existing task, swap; otherwise, add it to the postponement list.
