# Slack After‑Hours Management

**Definition**: A set of practices, Slack settings, and communication scripts designed to protect personal time while maintaining professional reliability.

## Core Elements

1. **Scheduled Do Not Disturb (DND)**
   - Set a nightly window (e.g., 6:30 pm – 8:30 am) via *Preferences → Notifications → Schedule*.
   - Enable the option allowing “urgent” messages to override DND only when the sender selects **Notify anyway**.
   - Pair with a clear custom status such as "Offline—back in the morning 🌙".

2. **Dedicated Urgent Channel**
   - Create a private channel (e.g., `#urgent‑team‑only`).
   - Define it as a *last‑resort* space for true blockers that prevent work from progressing.
   - Communicate the purpose clearly to the team to avoid abuse.

3. **Copy‑Paste Reply Templates**
   - **Quick question**: "Just saw this—offline for the night, but I’ll jump on it first thing tomorrow."
   - **Pressing but not emergency**: "Got it. I’m off for the evening, but if this is blocking anything, let me know and I’ll take a quick look in the morning."
   - **True emergency**: "On it. Give me two minutes to get my laptop."
   - **Manager‑specific**: "Thanks for the note—I’m offline now, but I’ll start with this first thing. If you need it sooner, just say so and I can hop on for a few minutes."

4. **Emergency vs. Can‑Wait Checklist**
   - **Emergency (use DND override or urgent channel)**:
     - System down or work blocked until you respond.
     - Customer/partner issue with immediate risk.
     - Decision affecting ongoing work now.
     - Any delay would cause real harm or rework.
   - **Can wait until morning**:
     - Context or clarification questions.
     - Reviews/approvals that aren’t blocking.
     - Scheduling, planning, FYI updates.
     - Non‑critical annoyances.

5. **Boundary Communication**
   - Team message example: 
     > "I’m shifting into a new rhythm with the promotion so I can be fully present during the day. If anything urgent or blocking comes up after hours, please still ping me—otherwise I’ll pick things up first thing in the morning. This helps me stay sharper and move faster for all of you."
   - 1:1 manager version mirrors the same structure with a collaborative tone.
