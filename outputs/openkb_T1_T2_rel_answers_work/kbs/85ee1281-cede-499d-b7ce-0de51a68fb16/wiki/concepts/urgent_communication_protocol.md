# Urgent Communication Protocol

**Definition**: A set of practices for distinguishing truly time‑critical messages from routine ones, and handling them through Slack settings, scripted replies, and a dedicated urgent channel.

---

## Core Elements

1. **Slack Configuration**
   - Schedule a nightly **Do Not Disturb** window (e.g., 6:30 pm – 8:30 am).
   - Use a custom status such as "Offline—back in the morning 🌙" during DND.
   - Enable the *"Notify anyway"* override so only messages marked urgent can break through.

2. **Urgent Channel**
   - Create a private channel (e.g., `urgent‑team‑only`).
   - Define it explicitly as a place for *true blockers* that stop work or pose immediate risk.
   - Communicate the purpose to the team and remind members to use it sparingly.

3. **Copy‑Paste Scripts**
   - Quick question: "Just saw this—offline for the night, but I’ll jump on it first thing tomorrow."
   - Slightly pressing: "Got it. I’m off for the evening, but if this is blocking anything, let me know and I’ll take a quick look in the morning."
   - True emergency: "On it. Give me two minutes to get my laptop."
   - Manager‑specific: "Thanks for the note—I’m offline now, but I’ll start with this first thing. If you need it sooner, just say so."

4. **Emergency vs. Can‑Wait Checklist**
   - **Emergency** (use *notify anyway* or urgent channel):
     * System down or work blocked.
     * Customer/partner issue with immediate risk.
     * Decision affecting ongoing work now.
     * Any delay causing real harm or rework.
   - **Can wait** (handle in the morning):
     * Context or clarification questions.
     * Non‑blocking reviews/approvals.
     * Scheduling, planning, FYI updates.
     * Non‑critical annoyances.

5. **Norm‑Setting Messaging**
   - Team announcement example: "I’m shifting into a new rhythm with the promotion so I can be fully present during the day. If anything urgent or blocking comes up after hours, please still ping me—otherwise I’ll pick things up first thing in the morning. This helps me stay sharper and move faster for all of you."
   - 1:1 manager version mirrors the same structure with a slightly more collaborative tone.
