# Minimum Viable Workflow

**Definition**: A lightweight, single‑source‑of‑truth process for tracking people, ownership, and pending items using only OneNote, Outlook, and Teams.

## Core components (from [[summaries/session-34_2024-12-14]])

- **OneNote page** – Create a page (e.g., “People + Ownership”) with two headings: “Who owns what” and “Active waiting items”. Under “Who owns what” place a four‑column table:
  - Name
  - Domain / Ownership
  - What I’m waiting on
  - Last touchpoint (date or brief note)

- **30‑second capture checklist** – add the name, a short ownership phrase, and a brief “what I need” phrase plus today’s date. This aligns with [[concepts/quick-capture-checklist]].

- **10‑minute daily sweep checklist** – skim for aged or resolved rows, move true priorities to the “Active waiting items” area, and park stale rows.

- **Searchability** – Use OneNote’s built‑in search (Ctrl + F) to quickly answer “who owns X”. Keeping a single master table (instead of splitting by workstream) makes lookup fast.

## Optional lightweight extensions

- **Outlook categories** (Owner = blue, Waiting = orange, FYI = green) can be added without altering the table.
- **Outlook search folder** “Waiting this week” to surface pending items.
