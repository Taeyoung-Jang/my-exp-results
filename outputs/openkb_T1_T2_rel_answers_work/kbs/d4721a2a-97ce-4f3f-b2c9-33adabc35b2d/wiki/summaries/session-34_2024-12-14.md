# Session 34 – Lightweight People & Ownership Tracker (2024-12-14)

## Main contribution
A step‑by‑step, copy‑paste‑ready workflow for tracking who owns what and what you’re waiting on, built entirely on Outlook, Teams, and OneNote with minimal maintenance.

## Proposed setups
- **Minimum‑viable** – a single OneNote page with a four‑column table (Name, Ownership, What I’m waiting on, Last touchpoint). Quick lookup via Ctrl+F. [[concepts/minimum-viable-workflow]]
- **Slightly structured** – same table plus an Outlook category column (Owner, Waiting, FYI) and a Teams “pinned chat” habit. [[concepts/lightweight-tracking-system]]

## Tool specifics
- **OneNote page layout** – headings “Who owns what” and “Active waiting items”, table as described, plus an “Inactive / Parked” section. [[entities/onenote]]
- **Outlook categories** – Owner (blue), Waiting (orange), FYI (green). [[entities/outlook]]
- **Outlook search folder** – “Waiting this week” – filters messages with the Waiting category received in the last 7 days.

## Checklists
- **30‑second capture** (3 bullets): add name, ownership phrase, what‑I‑need phrase + date. [[concepts/quick-capture-checklist]]
- **10‑minute daily sweep** (3 bullets): clean aged rows, move true priorities to Active area, park stale rows.

## Example rows
```
Alex R. | Vendor contracts | Waiting on updated SOW for Q2 | 3/12 – draft coming this week
Priya T. | Build pipeline dependency | Need status on blocker (looped in by Sam) | 3/14 – replied in Teams thread
```

## Parked / Archive rule
Move a row to **Parked** when it has had no touch for ≈ 14 days and no pending request; otherwise keep active. Archive whole inactive blocks monthly.

## Searchability tip
Keep one master table (not split by workstream) and use collapsible headings (Active, Parked, Archive) to retain fast OneNote search. [[entities/teams]]
