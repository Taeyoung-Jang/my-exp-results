# Microsoft OneNote

Microsoft OneNote is a digital note‑taking application that serves as the central repository for the **lightweight tracking system** described in [[summaries/session-34_2024-12-14]]. It is leveraged to store a single‑page table that captures:

- Name of the person
- Domain or ownership area
- What the user is waiting on
- Last touchpoint date

The page is organized with headings for **Active waiting items**, the main **Who owns what** table, and an **Inactive / Parked** section for stale entries. The workflow relies on quick capture and daily sweeps, both of which are outlined in [[concepts/quick-capture-checklist]] and [[concepts/minimum-viable-workflow]].

## Integration with other Microsoft tools
- **Outlook**: Uses Outlook categories (Owner, Waiting, FYI) to tag related emails, which are then reflected in the OneNote table. See [[entities/outlook]].
- **Teams**: Pinned Teams chats provide contextual notes that complement the OneNote rows. See [[entities/teams]].
- **Microsoft**: OneNote is part of the broader Microsoft 365 suite, enabling seamless cross‑app search and linking.

## Key benefits in the session‑34 workflow
- **Single source of truth**: All ownership and waiting‑on information lives in one searchable OneNote page.
- **Low maintenance**: The table is minimal (four to five columns) and supports quick 30‑second captures.
- **Scalability**: By moving rows to an "Inactive / Parked" section after 14 days of no activity, the table remains manageable.
- **Searchability**: OneNote’s built‑in search works best with a single, consolidated table rather than split workstreams.
