## Microsoft
Microsoft is a global technology organization best known for its Windows operating system, Office productivity suite, and cloud services. In the context of **session‑34 (2024‑12‑14)**, Microsoft’s tools—**Outlook**, **Teams**, and **OneNote**—are the core applications used to implement the lightweight people‑and‑ownership tracking system.

* **Outlook**: Used for categorising emails (Owner, Waiting, FYI) and creating a saved search folder for weekly "Waiting" items. [[entities/outlook]]
* **Teams**: Serves as the chat platform where pinned threads hold contextual notes that mirror entries in the OneNote table. [[entities/teams]]
* **OneNote**: Hosts the single source of truth table (Name, Ownership, What I’m waiting on, Last touchpoint) and the active/parked sections for quick reference. [[entities/onenote]]

The document proposes a **[[concepts/lightweight-tracking-system]]** that leverages these Microsoft products to keep coordination manageable after a re‑org. It also references the **[[concepts/minimum-viable-workflow]]**, the **[[concepts/quick-capture-checklist]]**, and the **[[concepts/quick-capture-checklist]]** for rapid data entry. For a full overview of the suggested workflow, see the session summary: [[summaries/session-34_2024-12-14]].
