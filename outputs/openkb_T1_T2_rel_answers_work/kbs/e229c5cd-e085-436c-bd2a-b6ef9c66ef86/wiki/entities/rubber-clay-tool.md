# Rubber Clay Tool (Chunky Handle)

A rubber‑coated clay tool with a large, ergonomic handle designed for **air‑dry clay hand‑building**. The chunky grip reduces the need for fine finger control, making it ideal for users with shaky hands and for a **low‑mess creative setup**.

## Key Facts from [[summaries/session-37_2025-03-11]]
- **Purpose:** Enables broad, palm‑based motions when shaping air‑dry clay, minimizing the reliance on precise finger work.
- **Ergonomics:** The oversized, rubberized handle provides a comfortable grip that absorbs tremor, aligning with [[concepts/shaky-hand-accommodations]].
- **Mess Management:** Works well on a [[entities/silicone-baking-mat]] work surface, keeping clay crumbs contained and easy to clean.
- **Recommended Pairings:**
  - Use with **DAS** or **Crayola Air‑Dry** clay ([[entities/das-clay]], [[entities/crayola-air-dry-clay]]).
  - Combine with a damp kitchen sponge for smoothing without sanding, supporting the [[concepts/air-dry-clay-hand-building]] workflow.
- **Project Examples:** Ideal for creating pinch pots, river‑stone bowls, flower‑petal dishes, and cloud‑shaped dishes as described in the session.

## Usage Tips
1. Grip the tool with the palm rather than the fingers; press the rubber edge against the clay to shape or flatten surfaces.
2. When smoothing, glide the tool along the clay while simultaneously using a slightly damp sponge for a mess‑free finish.
3. Store the tool on the silicone mat after use to keep the workspace tidy.
