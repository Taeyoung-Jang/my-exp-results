# Mail Organization System

**Definition**: A Mail Organization System is a set of habits, tools, and physical structures designed to capture, sort, store, and track incoming correspondence and deliveries so that nothing is missed or lost.

---

## Core Components (from [[summaries/session-04_2024-06-15]])

1. **Inbox Triage**
   - Use one or two physical inbox trays to collect all incoming mail the moment it arrives.
   - Sort daily (or every other day) into three categories: *needs action*, *to file*, and *recycle*.
   - Process the *needs action* pile on a set weekly block.

2. **Unified Tracking**
   - Capture every carrier tracking number in a single app that aggregates UPS, USPS, FedEx, and other services.
   - Enable push notifications for delivery status changes.
   - [[concepts/unified-tracking]]

3. **Digital & Physical Archiving**
   - Scan important letters/documents into simple digital folders (e.g., tax, insurance, personal).
   - For paper‑only items, keep an accordion folder or small filing box with the same top‑level categories.

4. **Address‑Related Checklist**
   - Maintain a concise checklist of accounts that require an updated physical address (banks, insurance, DMV, employer HR).
   - Review the checklist once or twice a year, and set calendar reminders for updates after each move.
   - [[entities/dmv]]

5. **Permanent Address Strategy**
   - Adopt a stable “official” mailing address that does not change with each move (e.g., a private mailbox service, a trusted friend/family member, or a commercial mail‑forwarding service).
   - Use the stable address for banks and government agencies, while directing day‑to‑day packages to the current residence.
   - [[concepts/permanent-address-strategy]]

## Supporting Practices

- **Designated Package Spot**: Keep a dedicated area at home for unopened parcels to avoid misplacement.
- **Routine Calendar Reminders**: Schedule brief weekly reviews for inbox sorting and monthly checks for address‑related account updates.
- **Provider Selection**: When choosing a private mailbox, ensure it offers a true street address, accepts all carrier packages, and provides prompt arrival notifications.
- **Bank & ID Verification**: Be prepared to supply a separate residential proof (lease, utility bill) for institutions that flag commercial mailbox addresses.
