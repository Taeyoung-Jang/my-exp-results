# Windows (product)

Windows is a family of operating systems developed by Microsoft, widely used on personal computers, laptops, and tablets.

## Role in session-38_2025-10-15

In the discussion, Windows is mentioned as the laptop platform paired with an iPhone while using Google as the central **source of truth** for contacts and calendars. The user is advised to access Google services via the web or desktop apps on Windows, ensuring seamless cross‑platform synchronization without creating duplicates.

## Key points from the document
- **Cross‑platform sync**: Windows acts as the non‑Apple device that relies on Google services to stay in sync with an iPhone.
- **Duplicate avoidance**: By disabling iCloud sync for contacts and calendars on the iPhone and using Google on Windows, the user prevents duplicate records.
- **Ecosystem choice**: The recommendation highlights choosing a single ecosystem (Google) and using Windows as the platform to consume that ecosystem's services.
