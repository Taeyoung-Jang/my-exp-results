# UPS (United Parcel Service)

UPS (United Parcel Service) is a major international logistics provider offering parcel delivery, freight forwarding, and supply chain solutions.

## Key Facts from session-35_2024-12-13

- **Carrier‑preference tools**: The user can use **UPS My Choice** to set a *Default Delivery Location* (e.g., front door) and enable *Driver Release* for unattended deliveries.
- **Delivery instructions**: Recommended short note format: "Please buzz 3B for access—directory not updated."
- **Notifications**: Enable delivery alerts for all packages to stay informed of attempts and statuses.
- **Gotchas**: A blanket "leave at door" setting can increase package‑theft risk if the building is not secure.
