# Communication Style

**Definition**: Communication style refers to the manner in which information is conveyed, encompassing tone, formality, structure, and clarity. It determines how a message is perceived by the audience and can range from highly formal to casual, while still maintaining effectiveness.

## Key Elements
- **Tone** – The emotional quality (friendly, neutral, professional).
- **Formality** – Level of corporate diction versus conversational language.
- **Structure** – Use of paragraphs, bullet points, or concise sentences.
- **Clarity** – Ensuring the core intent is unmistakable.

## Application in [[summaries/session-01_2024-06-15]]
In the referenced conversation, the user requested multiple message drafts with varying communication styles:
- A **friendly but clear** version suitable for everyday team updates.
- A **more casual** variant that sounds relaxed while still conveying the schedule.
- A **structured bullet‑point** version that improves readability.

These drafts illustrate how shifting tone and structure can tailor the same content for different audience expectations.
