# Todoist

Todoist is a cloud‑based to‑do list and task‑management application. In the conversation **session‑33_2024‑04‑15**, the assistant recommends Todoist as a concrete example of a “lightweight to‑do app” that can serve as the single home for all tasks, supporting the three‑section layout of **Today / This Week / Later**.

## Key points from the session
- **Simplicity** – The assistant emphasizes using a tool that the user will actually open every day; Todoist fits this need because of its clean UI and cross‑platform availability.
- **Single‑source task hub** – Todoist helps keep all tasks in one place, avoiding fragmented systems that hurt focus.
- **Supports the three‑item "Today" rule** – Users can quickly create a short list of three priority items, aligning with the [[concepts/task-list-structure]] recommended in the session.
- **Integration potential** – While not detailed in the conversation, Todoist can be combined with notification‑batching practices like checking Slack at set intervals, tying into [[concepts/notification-batching]].
