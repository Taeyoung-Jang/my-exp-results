# Consistent Running

Consistent Running is the practice of establishing a repeatable, low‑intensity running routine that prioritises habit formation, gradual adaptation, and injury prevention over speed or mileage spikes. The concept is grounded in the guidance from [[summaries/session-40_2025-06-15]], which outlines a four‑week post‑half‑marathon schedule designed to keep runners showing up without over‑reaching.

## Core Elements

1. **Fixed Weekly Slots** – Run on the same days each week (e.g., Monday, Wednesday, optional Friday, and a Sunday long run). This anchors the habit to the calendar rather than to a moment‑by‑moment decision.
2. **Easy Effort** – Each run should feel conversational. Use [[concepts/easy-day-cues]] such as the talk test, heart‑rate zone, or a pace ceiling to verify the effort stays low.
3. **Gradual Progression** – Increase total run time by ~10 minutes per week for the long run only; all other runs stay at 30‑40 minutes.
4. **Recovery Emphasis** – Off‑days are true rest or light activity (walking, gentle stretching). If soreness or warning pain appears, downgrade or skip the next run.
5. **Handling Missed Sessions** – Missing a single day does not reset the plan; continue with the next scheduled run. Repeating a week is advised when multiple sessions are missed or when lingering discomfort persists.
6. **Post‑Half‑Marathon Adjustment** – After a race, the focus shifts from building endurance to protecting the fitness already earned. The plan reduces intensity, adds optional low‑impact “strides” on Fridays, and incorporates [[concepts/post-half-marathon-recovery]] strategies for shin soreness and overall fatigue.

## Practical Cues for Easy Days

- **Talk Test** – You should be able to speak in full sentences without gasping.
- **Heart‑Rate Zone** – Stay in a comfortable, controlled zone (often 60‑70 % of max HR).
- **Pace Caps** – Treat any pace faster than your typical easy run as a ceiling, not a target.

## Injury Awareness

Distinguish normal post‑run muscle soreness (dull, fades within a day) from warning pain (sharp, localized, worsens with continued movement). When warning signs appear, apply extra rest and consider gentle mobility work before resuming the schedule.

## Benefits

- Builds a reliable running habit.
- Minimises risk of overuse injuries.
- Allows flexibility for life’s interruptions while keeping overall volume steady.
- Supports long‑term progression once the base is solid.
