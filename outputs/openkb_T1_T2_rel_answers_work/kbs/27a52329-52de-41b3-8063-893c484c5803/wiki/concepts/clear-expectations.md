# Clear Expectations

**Definition**: A shared, written description of what "done" looks like for each household chore, including quality standards, timing, and any required steps.

## Why it matters
In the conversation captured in [[summaries/session-03_2025-06-15]], the assistant highlights that vague expectations lead to repeated debates about whether a task has been completed satisfactorily. By codifying expectations, partners can:
- Quickly verify completion without discussion.
- Align on effort levels, supporting fair workload distribution.
- Reduce the mental load of remembering implicit standards.

## Key components
1. **Specific criteria** – List concrete actions (e.g., "wipe all surfaces, empty trash, and mop the floor" for kitchen cleanup).
2. **Quality level** – Define acceptable neatness (e.g., "no crumbs left on countertops").
3. **Frequency** – State how often the task should be performed (daily, weekly, monthly).
4. **Location of the note** – Store in a shared digital note (Google Docs, Notion, etc.) that both partners can edit.

## How to create the expectations list
1. Identify each chore role (see [[concepts/chore-roles]]).  
2. For each role, write the three‑point criteria above.  
3. Review together to ensure mutual understanding, then save.

## Using expectations in practice
During the **monthly reset** process (see [[concepts/monthly-reset]]), the list serves as a reference point to:
- Check whether any chore feels heavier because its standards are unclear.
- Adjust expectations if a partner’s schedule changes, keeping the workload balanced.

## Benefits
- **Speed**: Quick verification of task completion.
- **Fairness**: Objective standards help balance effort across roles.
- **Stress reduction**: Less need for on‑the‑spot negotiations.
