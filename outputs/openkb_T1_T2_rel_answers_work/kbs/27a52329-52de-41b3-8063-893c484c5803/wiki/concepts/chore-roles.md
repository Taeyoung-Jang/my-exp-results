# Chore Roles

**Definition**: Assigning recurring household chores as stable, time‑bound roles rather than ad‑hoc tasks, to minimise daily negotiation.

**Key ideas**
- Roles are grouped clusters of chores (e.g., kitchen cleanup + trash) assigned to one partner for a set period (often a month).
- At the end of the period partners swap or adjust roles.
- Stable roles create predictability and reduce the need for constant renegotiation.

**Supporting practices**
- Pair role definition with [[concepts/clear-expectations]] by documenting what “done” looks like for each chore.
- Use occasional [[concepts/monthly-reset]] meetings to review satisfaction and make light adjustments.
