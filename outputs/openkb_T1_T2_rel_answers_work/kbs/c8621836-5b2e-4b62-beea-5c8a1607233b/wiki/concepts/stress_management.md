# Stress Management

**Definition**: A set of simple, repeatable practices that help new clinicians maintain composure, focus, and safety when entering a fast‑paced hospital environment.

## Core Practices from [[summaries/session-38_2025-02-13]]

1. **Micro‑breathing pause** – Taking a single slow breath before moving to the next task reduces immediate stress and improves decision clarity.
2. **Shift‑start routine** – Spend 2–3 minutes reviewing assignments, noting time‑sensitive items, and filling a pocket‑note template. This creates a mental foothold for the rest of the shift.
3. **Single running to‑do list** – Write every new instruction in one place and cross it out when completed. The visual cue of crossing items removes mental clutter.
4. **Three‑step triage decision tree** (unsafe → workflow‑impact → all‑others) provides a rapid mental hierarchy for prioritising when pulled in multiple directions.
5. **Preceptor communication scripts** – Using prepared one‑liners signals engagement and reduces anxiety about appearing unsure.

## Practical Takeaways

- **Integrate a breathing cue** before each major hand‑off.
- **Adopt a pocket‑note template** (see the summary) to externalise memory load.
- **Apply the triage script** instantly when three tasks compete for attention.
- **Use the preceptor one‑liners** to seek guidance without hesitation.

By embedding these micro‑habits into daily workflow, new clinicians can transform the chaotic early days into a manageable, learning‑rich experience.
