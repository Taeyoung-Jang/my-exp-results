# Summary of Session 38 (2024‑12‑15)

**Main advice**: Prioritize *consistency* when starting distance running, then gradually introduce *run‑walk intervals*, *easy runs*, a modest *long run*, and occasional *quality* work.

## Key points
- **Consistency first** – make running a regular habit before chasing pace or distance. [[concepts/consistency]]
- **Run‑walk structure** – start with 1‑2 min run, 1‑2 min walk for 20‑30 min, every other day; increase only one variable at a time. [[concepts/run-walk-intervals]]
- **Weekly layout for three runs** –  
  1. **Easy run**: 30‑45 min at a conversational pace.  
  2. **Quality run**: same duration but include 10‑20 min of “comfortably hard” effort (≈1 min / mi faster than easy).  
  3. **Long run**: 80‑120 min, kept easy; can be trimmed if already >2 h.
- **Progression** – add a few minutes to the long run each week, but stop if soreness lasts >1 day. [[concepts/progressive-overload]]
- **Cap long‑run duration** – once a half‑marathon distance is comfortably covered, longer runs give diminishing returns; focus on quality work instead.
- **Recovery** – ensure full recovery before the next session; incorporate stretching or light walks on off‑days.

## Practical example
| Day | Session | Duration | Effort |
|-----|---------|----------|--------|
| Mon | Easy run | 30‑45 min | conversational |
| Wed | Quality run | 30‑45 min | warm‑up easy → 10‑20 min “comfortably hard” → cool‑down easy |
| Sun | Long run | 80‑120 min | easy, steady |
