# Summary of session-33_2024-10-15

**Main recommendation** – Use a *low‑stress* backup setup that combines [[concepts/cloud_backup]] with a single external drive that runs automatically when plugged in. This gives an off‑site copy and a local copy without requiring daily attention.

## Key concepts
- [[concepts/low_stress_backup]]: A system that runs with minimal user interaction.  
- [[concepts/cloud_backup]]: Keep important folders continuously synced to a reputable cloud service for off‑site protection.  
- off‑site copy: Store a second copy (cloud or another drive) for irreplaceable items like photos.  
- [[concepts/offline_backup]]: Keep an external drive unplugged most of the week; run a backup each Sunday.  
- backup verification: Have the backup software verify the backup after each run.  
- restore testing: Perform a quick restore check every few months and a deeper test once or twice a year.  
- [[concepts/auto_run_backup_software]]: Choose software that starts the backup automatically when the drive appears.  
- [[concepts/hybrid_backup_approach]]: Combine full‑disk imaging with file‑level backups for both quick bare‑metal recovery and easy file retrieval.  
- full disk image vs file‑level backup: Images give fast whole‑system restore; file‑level backups are simpler for individual files.

## Recommended tools
- **Windows**: *[[entities/macrium_reflect]]* or *[[entities/easeus_todo_backup]]* – both can auto‑run when the drive is connected.  
- **macOS**: *[[entities/time_machine]]* (built‑in) or *[[entities/carbon_copy_cloner]]* for more control.

## Practical workflow
1. **Cloud sync** continuously for primary folders.  
2. **Sunday routine** – plug in the external drive; the chosen backup software starts automatically and creates:  
   - a full system image (optional but recommended), and  
   - a file‑level copy of user folders.  
3. **Verification** – let the software verify the backup after completion.  
4. **Restore test checklist (5‑10 min)**:  
   - Restore 1‑2 recent files to a temporary location and open them.  
   - Browse the backup drive to confirm expected folders are present.  
   - Check the backup software’s job log for a successful status.  
   - (If using images) mount an image and verify you can browse its contents.

## Common mistakes to avoid
- Relying on a single backup location.  
- Treating cloud sync as a true backup without verification.  
- Forgetting to plug in the external drive after setting it up.  
- Not testing restores, leading to silent backup failures.

By following this hybrid, auto‑run approach and regular restore checks, personal files stay safe with minimal ongoing effort.
