# Summary of session-08_2024-06-15

**Main contribution:** A concise, practical backup workflow that balances convenience, cost, and security for both Mac and Windows users.

## Core backup layers
- **Primary layer:** Daily work on the main computer (local files).
- **Automatic cloud layer:** Continuous, versioned upload to a reputable cloud service (already in use) – [[concepts/cloud_backup]].
- **Offline layer:** One encrypted external hard drive kept at home and plugged in roughly **once a month** for a full backup – [[concepts/offline_backup]].

## Offline‑layer considerations
- **Device choice:** Single external drive is the cheapest adequate option; a NAS is optional for multi‑device or shared storage.
- **Location:** Home storage is sufficient for most; off‑site rotation (friend’s house, safe deposit) adds extra fire‑theft protection but is not mandatory.
- **Redundancy:** Two drives provide peace of mind for long‑term archival, but a single drive meets the 3‑2‑1 principle when combined with cloud backup.

## Backup frequency & workflow
- Plug in the drive **monthly** (or every 6‑8 weeks if activity is low).
- Run the backup, then **unplug and store** the drive in a safe place.
- Encrypt the drive and enable **two‑factor authentication** for the cloud account.

## Software recommendations
- **Mac:** Use **[[entities/time_machine]]** (built‑in) for automated, versioned file/folder backups to the encrypted drive.
- **Windows:** 
  - **[[entities/file_history]]** for personal files.
  - Periodic **full system image** with the built‑in “Backup and Restore (Windows 7)” tool or a free third‑party like **[[entities/macrium_reflect]]** or **[[entities/aomei_backupper]]**.
- **Backup type:** Prefer **file/folder backups** for routine monthly runs; schedule a **full disk image** once or twice a year for extra resilience.

## Security best practices
- Enable **encryption** on both cloud storage and the external drive.
- Use **strong passwords** and **two‑factor authentication** for cloud accounts.
- Keep a **simple folder hierarchy** to aid consistency.
