## Macrium Reflect

Macrium Reflect is a Windows backup product that can create full system images as well as scheduled or manual file‑level backups. It supports an **auto‑run backup** workflow that starts the backup job automatically when the external drive is connected, fitting a low‑stress, hybrid backup strategy.

### Key points from the documents
- Works alongside the built‑in **File History** tool for routine file/folder backups.
- Ideal for creating a **full system image** once or twice a year, providing an extra safety net beyond cloud and offline drive backups.
- Can be configured to **auto‑run backup software** when the external drive is plugged in, reducing manual steps.
- Supports a **hybrid backup approach**: a full disk image plus a simple file‑level copy of user folders in the same session.
- Fits a **low‑stress backup** model by requiring only a weekly plug‑in, after which the software handles the rest.
- Recommended as part of a broader **backup strategy** that includes cloud sync, an offline drive, and periodic imaging.
