# EaseUS ToDo Backup

EaseUS ToDo Backup is a **Windows backup product** recommended for users who keep an external drive unplugged for most of the week and run a backup on a weekly schedule.

## Key facts from [[summaries/session-33_2024-10-15]]
- **Auto‑run capability** – The software can be configured to start the backup automatically as soon as the target drive appears, fulfilling the [[concepts/auto_run_backup_software]] pattern.
- **Fits a low‑stress approach** – It supports a set‑and‑forget workflow that aligns with [[concepts/low_stress_backup]] and [[concepts/offline_backup]] strategies.
- **Hybrid backup option** – While primarily a file‑level backup tool, it can also create full‑disk images, making it suitable for a [[concepts/hybrid_backup_approach]] that balances quick file restores with whole‑system recovery.
- **Comparison** – Mentioned alongside other Windows options such as [[entities/macrium_reflect]] for similar use‑cases.

## Typical workflow
1. **Cloud sync** – Keep primary folders continuously synced to a cloud service (see [[concepts/cloud_backup]]) as the first line of protection.
2. **Weekly offline backup** – Plug the external drive on Sunday; EaseUS ToDo Backup detects the drive and runs the predefined backup job without further user input.
3. **Verification** – After each run the software can verify the backup integrity, supporting regular [[concepts/backup_strategy]] checks.

## Why choose EaseUS ToDo Backup?
- Simple UI and straightforward setup.
- Supports both file‑level copies and optional full‑disk images.
- Works well within the [[concepts/low_stress_backup]] model by minimizing manual steps.
