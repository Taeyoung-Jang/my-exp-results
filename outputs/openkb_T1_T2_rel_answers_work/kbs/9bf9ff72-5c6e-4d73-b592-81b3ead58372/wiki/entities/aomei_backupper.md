## AOMEI Backupper

AOMEI Backupper is a Windows backup and recovery tool that offers both file‑level backup and full system imaging. In the *session‑08_2024‑06‑15* conversation it was suggested as a low‑cost, user‑friendly alternative to the built‑in Windows backup utilities for creating scheduled or manual backups to an encrypted external drive.

**Key points from the document**
- Recommended for Windows users alongside File History.
- Supports creating regular file/folder backups and occasional full disk images.
- Free version is sufficient for most personal backup needs.
