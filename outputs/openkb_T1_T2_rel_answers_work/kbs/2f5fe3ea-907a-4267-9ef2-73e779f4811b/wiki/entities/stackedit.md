## StackEdit

StackEdit is a **browser‑based Markdown editor** that runs entirely client‑side, allowing users to write, preview, and export Markdown documents without installing heavyweight software. It is often chosen for its simplicity, automatic saving, and ability to work offline, making it suitable for low‑maintenance personal note‑taking workflows.

### Key facts from [[summaries/session-37_2025-02-15]]
- Recommended as a **low‑maintenance option** for editing notes stored as plain Markdown files in a self‑hosted home hub.
- Works well alongside **Syncthing** for syncing Markdown files across devices, supporting the [[concepts/cross-device-syncing]] goal.
- Provides a read‑only friendly interface that complements a lightweight web file browser such as [[entities/file-browser]] or a static‑site preview generated by [[entities/mdbook]] or [[entities/mkdocs]].
- Fits the [[concepts/low-maintenance-file-sync]] strategy by requiring no server‑side components and minimal configuration.

### Usage notes
- Because StackEdit runs in the browser, it does not require a dedicated backend, keeping the overall system **simple** and **secure**.
- It can export to HTML, PDF, or plain Markdown, making it easy to integrate with static‑site generators like [[entities/mdbook]] or [[entities/mkdocs]] for read‑only browsing.
