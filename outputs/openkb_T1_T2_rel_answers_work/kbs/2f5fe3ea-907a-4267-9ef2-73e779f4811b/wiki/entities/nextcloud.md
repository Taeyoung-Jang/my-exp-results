# Nextcloud (product)

Nextcloud is an open‑source, self‑hosted suite that provides file synchronization, a web‑based file manager, note‑taking, calendar, and many other collaboration apps. It can be installed on a low‑power device such as a Raspberry Pi or a mini‑PC, turning the machine into a private cloud that you control.

## Key points from [[summaries/session-37_2025-02-15]]
- **More feature‑rich than Syncthing**: While Syncthing offers simple peer‑to‑peer file sync, Nextcloud adds a full web UI, apps for notes, contacts, calendars, and extensibility via plugins.
- **Higher maintenance**: The assistant notes that Nextcloud “needs more updates, tuning, and occasional fixing,” making it less suitable when the primary goal is minimal upkeep.
- **Use case**: Recommended when you need an integrated platform rather than just file sync; otherwise, Syncthing plus a lightweight file browser is preferred for low‑maintenance scenarios.

## When to choose Nextcloud
- When you need a unified platform for files, notes, calendars, and other collaborative tools.
- When you are comfortable managing updates, database maintenance, and possible security hardening.
- When you prefer an ecosystem that can grow with additional apps rather than a single‑purpose sync tool.
