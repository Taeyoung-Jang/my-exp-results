## MkDocs

MkDocs is an open‑source **product** that converts a collection of Markdown files into a static documentation site. It is designed for simplicity: you write plain Markdown, configure a straightforward YAML file, and run a single command to generate a tidy HTML site that can be served by any web server.

### Key facts from [[summaries/session-37_2025-02-15]]
- Recommended as a low‑maintenance way to browse and search personal Markdown notes.
- Can run in **watch mode** to automatically rebuild the site whenever notes change, keeping the served content in sync with the underlying folder structure.
- Works well together with client‑side search tools like [[concepts/client-side-search]] to provide fast, read‑only navigation without a database.
