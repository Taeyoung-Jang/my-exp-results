# mdbook (product)

mdbook is an open‑source command‑line utility for generating static documentation sites directly from a folder of Markdown files. It watches source files, rebuilds HTML on change, and serves the result via a built‑in web server, making it well‑suited for low‑maintenance personal knowledge bases.

## Key facts from [[summaries/session-37_2025-02-15]]

- **Use case**: Recommended as a lightweight static‑site generator to browse and search personal Markdown notes without needing a full Nextcloud stack.
- **Workflow**: Point mdbook at the existing notes folder; it produces a navigable site that can be served by the same web server used for file browsing.
- **Maintenance**: Runs as a single binary, requires only occasional updates, and works with the plain‑folder structure already in place.
