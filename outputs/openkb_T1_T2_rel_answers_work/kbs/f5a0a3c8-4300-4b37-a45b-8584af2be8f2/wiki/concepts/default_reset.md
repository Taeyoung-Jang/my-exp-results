# Default Reset System

A **default reset system** is a minimal‑effort organisational framework that keeps a living space aligned with a deliberately bare baseline by defining fixed storage locations, hard category limits, and short daily/weekly routines. It is designed to reduce [[concepts/decision_fatigue]] and support the personal [[concepts/organizing_mindsets]] that favor simplicity.

## Core Elements (from [[summaries/session-03_2023-06-15]])

- **Category caps** – set strict limits for clothes, kitchen tools, decor, and papers (e.g., only the weekly‑wear wardrobe, one of each daily‑use kitchen item, a single decor surface, one paper tray).
- **One‑touch placement** – everyday items live in obvious, open spots; everything else has one permanent home, usually a closed bin or shelf.
- **Daily reset** – spend 1–2 minutes returning items to their defined spots and clearing primary surfaces.
- **Weekly reset** – scan closed storage for stray items, empty the paper tray, and verify category limits are still respected.

## How It Works

1. **Define the baseline** – decide the minimal set of items needed for each core category.
2. **Assign fixed homes** – give each item a single, obvious location to eliminate decision points.
3. **Establish routines** – short, repeatable actions that restore the baseline each day and week.
4. **Monitor and adjust** – if a category overflows, either digitise, store elsewhere, or remove the excess.

## Benefits

- **Sustains a bare environment** with minimal mental overhead.
- **Prevents clutter creep** by making deviation obvious during the weekly scan.
- **Aligns space with personal preferences**, reinforcing the chosen organizing mindset.

Implementing a default reset system turns the desired tidy state into the default state of the home, requiring only brief, automatic actions to maintain it.
