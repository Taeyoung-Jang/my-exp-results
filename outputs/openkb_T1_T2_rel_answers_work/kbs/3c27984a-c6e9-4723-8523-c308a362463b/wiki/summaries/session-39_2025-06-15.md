# Summary of session‑39 (2025‑06‑15)

## Overview
This conversation provides a practical workflow for keeping a compact ultrabook responsive while juggling a browser, docs, Slack, and a lightweight editor. The advice centers on minimizing simultaneous heavy processes, using the browser as a hub, and applying targeted [[concepts/resource-management]] techniques.

## Main Recommendations
1. **Browser as central hub** – Pin essential tabs, close or bookmark the rest. Consider a tab‑manager extension to suspend inactive tabs.
2. **Docs & spreadsheets** – Prefer web versions; keep only one document open at a time.
3. **Slack** – Use the web version in a dedicated Chrome window, enable notifications only for mentions/DMs, and avoid the standalone app unless required.
4. **Editor** – Choose a lightweight editor and close unused project windows.
5. **General rhythm** – Keep only one “heavy” app active (browser or a document) and treat other tools as short‑lived sessions. This aligns with [[concepts/lightweight-workflow]].

## Detailed Slack Setup (Chrome)
- Open Slack in its own Chrome window (background windows are throttled).
- **Slack notification settings**: enable *Mentions & Direct Messages* only; disable channel‑wide notifications; keep thread replies on; turn off keyword alerts; disable “Leave app running in background” if available.
- **Chrome settings**:
  - Allow site notifications for Slack only.
  - Disable *Continue running background apps when Chrome is closed*.
  - Enable *Memory Saver* and *Discard tabs automatically*.
  - Add Slack and Google Docs/Sheets to the *Always keep these sites active* whitelist.

## Tab Management
- **Recommended extensions**: Auto Tab Discard (automatic sleep) vs. Tab Session Manager (manual grouping). For 30‑60 tabs, Auto Tab Discard is preferred.
- **Auto Tab Discard configuration**:
  - Discard timer: 15‑20 minutes of inactivity.
  - Whitelist: Slack, Google Docs, Sheets, Meet, any site with active form entries.
  - Preserve pinned tabs and tabs with unsaved input.

## Chrome Performance Tweaks
- No special flags needed; rely on built‑in *Memory Saver*.
- Ensure *Background apps* are disabled.
- Use the *Always keep active* list to protect critical sites from being frozen.
