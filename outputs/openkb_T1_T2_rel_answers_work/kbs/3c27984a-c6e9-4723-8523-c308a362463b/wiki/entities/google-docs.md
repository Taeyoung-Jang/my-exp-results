# Google Docs

Google Docs is a cloud‑based word‑processing product that lets users create, edit, and collaborate on documents directly in a web browser.

## Key points from [[summaries/session-39_2025-06-15]]
- Recommended as a **lightweight‑workflow** alternative to heavyweight desktop editors, helping to reduce RAM usage on a compact ultrabook.
- The advice suggests keeping only one Google Docs file open at a time to minimise resource consumption.
- When using the **Auto Tab Discard** extension, Google Docs should be added to the whitelist so active documents are never suspended, preserving in‑progress edits.
- Google Docs works well alongside other tools like [[entities/chrome]] (the browser platform) and [[entities/slack]] for communication, fitting into an overall [[concepts/resource-management]] strategy.

## Related concepts and entities
- Part of a broader [[concepts/lightweight-workflow]] aimed at keeping a single heavy application active.
- Interacts with [[concepts/tab-management]] when configuring tab‑discard rules.
- Often used together with [[entities/google-sheets]] for spreadsheet work and [[entities/google-meet]] for video meetings.
- The setup described in the session relies on Chrome’s performance settings and the Auto Tab Discard extension to keep the experience snappy.
