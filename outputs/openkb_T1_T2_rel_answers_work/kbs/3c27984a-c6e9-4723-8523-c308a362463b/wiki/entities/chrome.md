# Google Chrome (Product)

Google Chrome is a cross‑platform web browser developed by Google. In the context of **session‑39 (2025‑06‑15)** it is recommended as the primary hub for managing a compact ultrabook’s workload.

## Key Facts from the Session
- **Central hub**: Chrome is used to host web‑based versions of productivity tools (e.g., [[entities/google-docs]], [[entities/google-sheets]], [[entities/google-meet]]) and the Slack web client.
- **Resource management**: Settings such as disabling *Continue running background apps when Chrome is closed*, enabling *Memory Saver*, and allowing Chrome to *discard tabs automatically* help keep RAM and CPU usage low. These tactics align with [[concepts/resource-management]] and the overall [[concepts/lightweight-workflow]].
- **Notification handling**: The browser is configured to allow site notifications only for Slack, with all other sites muted, to reduce background activity.
- **Tab management**: Chrome works with extensions like [[entities/auto-tab-discard]] and [[entities/tab-session-manager]] for suspending or grouping tabs. The recommended choice for heavy tab users (30–60 tabs) is Auto Tab Discard, set to a 15‑20‑minute inactivity timer and whitelisted for critical sites (Slack, Google Docs/Sheets, Meet).
- **Performance tweaks**: No special Chrome flags are required; built‑in features (Memory Saver, background‑app throttling) provide sufficient performance gains on a low‑spec laptop.
