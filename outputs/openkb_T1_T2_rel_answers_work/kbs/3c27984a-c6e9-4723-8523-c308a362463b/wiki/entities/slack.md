# Slack (product)

Slack is a cloud‑based collaboration and messaging tool used for real‑time team communication. It offers channel‑based organization, direct messages, and integrations with a wide range of productivity apps.

## Key facts from [[summaries/session-39_2025-06-15]]
- **Resource‑friendly usage**: The conversation recommends running Slack in the browser rather than the desktop app on a compact ultrabook to reduce CPU and memory load.
- **Notification tuning**: Enable only *Mentions & Direct Messages* (and thread replies) while disabling channel‑wide alerts to keep interruptions low and resource usage minimal.
- **Window management**: Keep Slack in a dedicated Chrome window; background windows are throttled, which further limits its impact on performance.
- **Chrome integration**: Allow site notifications for Slack only, disable *Continue running background apps when Chrome is closed*, and add Slack to Chrome’s *Always keep these sites active* whitelist.
- **Tab management**: Use the [[entities/auto-tab-discard]] extension to discard inactive tabs, but whitelist Slack so it never gets suspended.
