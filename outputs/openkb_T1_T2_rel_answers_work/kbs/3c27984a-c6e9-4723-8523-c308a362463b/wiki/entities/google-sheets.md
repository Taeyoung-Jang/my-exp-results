# Google Sheets

**Type:** product

Google Sheets is a cloud‑based spreadsheet application that is part of Google Workspace. It allows users to create, edit, and collaborate on spreadsheets directly in a web browser.

## Role in Session 39 (2025‑06‑15)
In the conversation, Google Sheets is recommended as a lightweight alternative to the desktop spreadsheet app. Using the web version helps reduce RAM and CPU load on a compact ultrabook, fitting the overall [[concepts/lightweight-workflow]] and [[concepts/resource-management]] strategy.

## Recommendations from the Session
- Prefer the browser version of Google Sheets over a native desktop client to keep the system responsive.
- Keep only one Google Sheets document open at a time; close or suspend other tabs using a tab‑manager like [[entities/auto-tab-discard]] or [[entities/tab-session-manager]].
- Add Google Sheets to Chrome’s “Always keep these sites active” whitelist so it isn’t automatically discarded while you are editing.
