# Summary of session-15_2023-06-15

**Context** – The user has an older Windows 10 machine (quad‑core CPU, 8 GB RAM, 2 GB GPU) and wants a smooth workflow for 1080p 60 fps phone footage, basic 3D work, and minimal system strain.

## Core Recommendations

- **Editor choice** – Prefer **[[entities/shotcut]]** for the lightest footprint, with **[[entities/kdenlive]]** as a reliable backup. DaVinci Resolve is mentioned but deemed too heavy for the given specs.
- **[[concepts/proxy-workflow]]** – Central to achieving smooth playback. Convert source clips to low‑resolution, low‑bitrate proxies before editing.
- **Proxy format** – Use **[[entities/prores-proxy]]** (MOV) or **[[entities/dnxhr-lb]]** (MXF). **[[entities/dnxhr-lb]]** is generally faster on Windows, while **[[entities/prores-proxy]]** offers broader cross‑platform compatibility.
- **Proxy resolution** – 720p is the sweet spot for 1080p source; drop to 540p only if performance remains an issue.
- **Timeline settings** – Keep project resolution at 1080p, match the source frame rate (59.94 fps is a safe default), and set preview scaling to half or quarter quality.
- **Export settings** – H.264 at 12‑16 Mbps for 1080p, medium encode speed, avoid “slow” or “max quality” presets.

## Detailed Step‑by‑Step Guides

### Kdenlive Proxy Setup (current Windows builds 22.x‑24.x)
1. **Project → Project Settings → Proxies tab** – enable *Use Proxies* and select a profile (e.g., *DNxHR LB 720p* or *ProRes Proxy 720p*).
2. **Settings → Configure Kdenlive → Project Defaults → Proxy** – set the *Proxy folder* to an SSD location.
3. **Settings → Configure Kdenlive → Miscellaneous** – set the *Cache data folder* (preview/render cache) to the same SSD.

### Shotcut Proxy Limitations
- Modern **[[entities/shotcut]]** only offers an on/off proxy toggle and storage location; codec/resolution selection is not exposed in the UI, making Kdenlive the more controllable option for this hardware.

### Converting Variable‑Frame‑Rate (VFR) Phone Clips
- **Tool**: **[[entities/handbrake]]**.  
- **Preset**: *Fast 1080p30* (adjusted).  
- **Video tab**: set *Framerate* to **59.94** or **60**, enable **Constant Framerate**.  
- **Encoder**: H.264, RF 18‑20 (≈20‑25 Mbps).  
- Verify CFR with **[[entities/mediainfo]]** – look for a single fixed “Frame rate” value and no “Variable” flag.

## Windows 10 Performance Tweaks for 8 GB RAM
- Place project files, proxies, and cache on the fastest drive (SSD).  
- Close background apps (browsers, launchers, chat clients).  
- Disable visual effects such as transparency in *System → Personalization*.  
- Point Shotcut/Kdenlive cache directories to the SSD via their respective settings.  
- These adjustments are covered by [[concepts/windows-performance-tweaks]].

## 3‑D Considerations
- Use **[[entities/blender]]** with **Eevee** for real‑time preview; keep **Cycles** samples low and enable denoising.  
- Render 3D elements at modest resolution, upscale later if needed.
