# Summary of session-37_2024-06-15

**Main contribution** – A comprehensive, cross‑NLE (Premiere, DaVinci Resolve, Final Cut) workflow guide for structuring folders, bins, naming conventions, and asset handling in large multi‑camera, effects‑heavy projects.

## Key concepts & recommendations
- **Folder‑bin mirroring** – Keep a top‑level project folder with sub‑folders *Footage, Audio, Graphics, Exports, ProjectFiles* and create identically‑named bins inside the NLE. This one‑to‑one mapping prevents lost media and simplifies relinking. [[concepts/folder-bin-mirroring]]
- **Naming patterns** –  
  - Clip: `CamX_Roll_Clip_Desc` (e.g., `A001_C003_interviewWide`).  
  - Sequence/Timeline: `EP01_Main_v01`, `EP01_Main_v02` … version numbers keep old cuts separate.  
  - Multicam: `MC_A‑B‑C` or `MC_Interview01`.  
  - Export: `EP01_Main_v03_1080pReview` or `EP01_Final_MasterProRes`.
- **Track organization** – Consistent track order: A‑Cam → B‑Cam → C‑Cam → Effects → Adjustment Layers → Audio (VO, Music, SFX). Label tracks and collapse or nest dense sections. *(track organization)*
- **Adjustment‑layer strategy** – Use adjustment layers for global or semi‑global treatments (overall look, colour grade, noise reduction). Apply per‑clip effects only when a shot requires a unique correction. [[concepts/adjustment-layer-strategy]]
- **Nesting/compounding** – Once a section is locked (multicam swaps, graphics, retimes), nest or create a compound clip to keep the main timeline readable while retaining editability. *(nesting workflow)*
- **Audio & graphics handling** – Separate disk folders and bins for VO, Music, SFX, LowerThirds, Logos, Templates. Group each type on dedicated tracks in the timeline for easy mute/solo and swapping. *(audio routing)*
- **Series template approach for Resolve** – Create a master project **Series_Template** containing reusable assets in a *SeriesAssets* bin. Duplicate this project for each episode (EP01, EP02, …) and rename timelines accordingly. [[concepts/series-template-workflow]]
- **Updating template assets** – Freeze old episodes; let the template evolve for future episodes. Use Power Bins for assets that truly need live updates (e.g., lower thirds), but expect manual import for retrofitting older timelines. [[concepts/series-template-workflow]]

## Practical template (copy‑paste ready)

```
ProjectName
├─ Footage
│   ├─ A‑Cam
│   ├─ B‑Cam
│   ├─ C‑Cam
│   ├─ ScreenRecords
│   └─ Other
├─ Audio
│   ├─ VO
│   ├─ Music
│   └─ SFX
├─ Graphics
│   ├─ LowerThirds
│   ├─ Logos
│   └─ Templates
├─ Exports
│   ├─ Review
│   └─ Final
└─ ProjectFiles
    ├─ Premiere_or_Resolve
    └─ Autosaves
```

Corresponding NLE bins mirror the folder names. Timeline naming examples:
- `EP01_Main_v01`
- `EP01_Interview_MC01`
- Export: `EP01_Main_v03_1080pReview`

## When to apply each rule of thumb
| Situation | Recommended tool |
|-----------|------------------|
| Global colour/grade, noise reduction | Adjustment layer |
| One‑off exposure fix | Per‑clip effect |
| Dense multicam section with graphics | Nest/compound clip |
| Re‑using graphics across episodes | Power Bin (or Series_Template → SeriesAssets) |
| Updating future episodes only | Freeze old projects, evolve Series_Template |
