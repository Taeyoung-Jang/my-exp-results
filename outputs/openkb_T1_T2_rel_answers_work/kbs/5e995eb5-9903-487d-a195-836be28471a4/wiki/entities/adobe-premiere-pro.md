# Adobe Premiere Pro

**Type:** product

**Description:** A professional non‑linear video editing application from Adobe, widely used in post‑production.

**Key points from [[summaries/session-37_2024-06-15]]:**
- Recommended for the same “tidy and intentional” workflow described in the session, including clear naming, bin organization, and track order.
- Works well with the [[concepts/folder-bin-mirroring]] approach: matching drive folders to project bins helps keep media linked and easy to relink.
- Supports the [[concepts/adjustment-layer-strategy]]: global colour grades or effects are best applied via adjustment layers rather than per‑clip effects.
- Can utilize a [[concepts/proxy-workflow]] (e.g., ProRes Proxy) to improve playback performance when editing high‑resolution 4K multicam footage.
- Compared alongside other NLEs such as [[entities/davinci-resolve]] and [[entities/final-cut-pro]]; the advice in the session is applicable to all three, but the example habits map naturally to Premiere's UI.

**Typical use‑case scenarios mentioned:**
- Organizing bins like *Footage, Audio, Graphics, Exports, ProjectFiles*.
- Naming clips with camera roll numbers and descriptive tags.
- Nesting or creating compound clips for dense multicam sections.
- Using adjustment layers for overall looks, and per‑clip effects only when needed.

**Related concepts:** [[concepts/folder-bin-mirroring]], [[concepts/adjustment-layer-strategy]], [[concepts/proxy-workflow]].
