# Inbox Management

## Overview
Inbox management is the practice of treating the inbox (or Downloads) folder as a transient holding area that is regularly cleared. The goal is to prevent it from becoming a permanent dumping ground for files.

## Core Rules (from [[summaries/session-10_2025-06-15]]])
- **Keep it empty**: Move every file out of the inbox as soon as you touch it.
- **Daily processing**: Set a schedule (e.g., once per day) to review and relocate items.
- **Single "To Sort" folder**: When a file’s destination is unclear, place it in a dedicated *To Sort* folder for later batch processing.
- **Use tags**: If a file belongs to multiple top‑level categories, assign tags rather than duplicating it.

## Typical Workflow
1. Open the inbox.
2. For each item, decide its proper home among the top‑level folders defined in [[concepts/folder_hierarchy]].
3. Move the item; optionally rename using the [[concepts/naming_conventions]] date pattern.
4. If unsure, drop it into *To Sort* and revisit on the next scheduled pass.

## Relationship to Folder Hierarchy
Effective inbox management relies on a clear top‑level folder structure (e.g., Work, Personal, Finances, Media, Reference, Archive, Apps/Utilities). A well‑defined hierarchy makes the decision‑point in step 2 straightforward.

## Naming Conventions
When moving files, apply a consistent naming scheme such as `Category_Description_YYYY‑MM‑DD` to aid later searching and sorting.
