# Media (Top‑Level Folder)

**Entity type:** other

The **Media** folder is a top‑level bucket intended to store all visual and audio content such as photos, videos, music, and other creative assets. It is defined in the file‑organization guidance of [[summaries/session-10_2025-06-15]] and forms part of the overall [[concepts/folder_hierarchy]] used to keep a digital workspace tidy.

## Scope and boundaries
- **What belongs:** Images, video clips, audio recordings, graphic design files, and any media‑related assets.
- **What does *not* belong:** Text documents, spreadsheets, project files, or any non‑media content (those belong in [[entities/work]], [[entities/personal]], [[entities/finances]], [[entities/reference]], etc.).

## Naming conventions
Files inside the Media folder follow the general pattern described in [[concepts/naming_conventions]]: `Category_Description_YYYY‑MM‑DD.ext`. For example, `Photo_Vacation_2025‑06‑15.jpg` or `Audio_PodcastEpisode_2025‑07‑01.mp3`.

## Relationship to other top‑level folders
- Works alongside [[entities/work]] for project‑related media, but media that is purely personal should be placed under [[entities/personal]].
- Financial records (e.g., receipts with embedded images) belong in [[entities/finances]], not Media.
- Reference‑type media (e.g., manuals, templates) can be stored in [[entities/reference]] if they are meant for long‑term lookup.
- Archived media that is no longer actively used should be moved to [[entities/archive]] to keep the Media folder current.
- Utility scripts or installers that handle media processing belong in [[entities/apps_utilities]].

## Example tree (excerpt)
```
Media
 Photos
  Vacation_2025‑06‑15.jpg
 Video
  FamilyReunion_2025‑07‑01.mp4
 Audio
  Podcast_Episode01_2025‑07‑02.mp3
```

By keeping Media focused on its core content type and applying clear naming rules, the folder hierarchy remains simple, searchable, and free from cross‑category clutter.
