# Summary of session-12_2024-06-15

**Main contribution** – A practical decision framework and workflow for organizing digital assets using a mix of cloud storage and external drives on macOS, with emphasis on one‑way backups, versioning, and handling online‑only files.

---

## 1. Choosing between cloud, external drive, or a hybrid
- **Cloud storage**: best for convenience and anywhere access; acts as a safety net.
- **External drive**: provides fast local access, one‑time cost, and full ownership of data.
- **Hybrid approach**: combines strengths; cloud is the source of truth while the drive is a snapshot for redundancy.
- **Pitfalls** to watch: hard‑drive failure, cloud account lockout or cost creep, and lack of a regular sync routine.

## 2. Adding an external‑drive backup without creating duplicates
- Treat the drive as a **snapshot** of the cloud’s folder hierarchy – keep the same structure.
- Choose a single direction for organization decisions (usually cloud → drive).
- Decide whether to **mirror everything** or **subset** based on what you’d miss if the cloud vanished.

> Related concept: backup strategies (plain text)

---

## 3. One‑way backup workflow on macOS
- **Tools**:
  - **Time Machine** – simple, built‑in, versioned backups; works only if cloud files are fully downloaded locally. ([[entities/time-machine]])
  - **Carbon Copy Cloner** – one‑way copy tasks with SafetyNet for archived versions. ([[entities/carbon-copy-cloner]])
  - **ChronoSync** – left‑to‑right backup mode with deletion disabled. ([[entities/chronosync]])
- **Key settings**:
  - Disable any mirror or delete‑missing‑source options.
  - Enable SafetyNet (Carbon Copy Cloner) or archive mode (ChronoSync) to retain older copies.

> Related concept: [[concepts/one-way-backup]]

---

## 4. Handling “online‑only” cloud files
- Backup tools can only copy files that exist locally; online‑only placeholders must be downloaded first.
- Strategy:
  1. Mark critical folders as **“always keep on this device”** in the cloud app.
  2. Run the one‑way backup while those folders are present locally.
  3. Optionally, temporarily download large folders, back them up, then clear local copies.
- Trade‑off: either keep key data local for automatic backup or accept manual steps for a full offline copy.

> Related concept: [[concepts/online-only-file-handling]]

---

## 5. Recommended practical workflow
1. **Set cloud as source of truth** and keep its folder hierarchy.
2. **Enable local sync** for essential folders (or use a temporary download step). ([[entities/macos]])
3. **Configure a one‑way copy task** in Carbon Copy Cloner or ChronoSync with safety/archive settings.
4. **Run the task periodically** (e.g., weekly) by connecting the external drive.
5. **Review version history** in the archive if needed; no reverse sync occurs.
