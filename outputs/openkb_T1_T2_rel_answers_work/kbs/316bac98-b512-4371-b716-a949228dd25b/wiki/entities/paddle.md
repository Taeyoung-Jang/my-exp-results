# Adjustable SUP Paddle

An **adjustable paddle** designed for stand‑up paddleboarding (SUP). It features a telescoping shaft that can be lengthened or shortened to suit the rider’s height and preferred paddling style.

## Key Facts from [[summaries/session-03_2024-07-11]]
- **Purpose**: Provides a versatile, ergonomic option for beginners and experienced paddlers alike, aligning with the recommendation to keep SUP gear lightweight and easy to set up.
- **Adjustability**: Allows quick length changes, making it suitable for solo sessions where the user may want to experiment with different techniques.
- **Portability**: The telescoping design reduces bulk, fitting well with the low‑maintenance gear checklist (inflatable board, leash, PFD, etc.).
- **Compatibility**: Works with standard SUP boards, including the [[entities/inflatable-board]] mentioned in the conversation.

## Usage Tips
1. Adjust the paddle length so that the top of the shaft reaches roughly the rider’s wrist when standing on the board.
2. Secure the adjustment mechanism before each session to ensure safety.
3. Pair the paddle with a comfortable grip and a leash for added security.
