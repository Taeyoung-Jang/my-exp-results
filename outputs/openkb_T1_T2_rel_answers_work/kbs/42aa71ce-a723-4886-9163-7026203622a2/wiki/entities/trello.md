# Trello

Trello is a web‑based Kanban board tool that helps individuals and teams visualise work, organise tasks, and track progress. In the **session‑14** workflow it is recommended as the primary platform for a **one‑page weekly dashboard**.

## How it is used in the session‑14 workflow
- Create a single board with three lists:
  - **This Week** – cards for each active client project.
  - **Waiting/Feedback** – items that are pending external input.
  - **Done** – completed tasks.
- Each client gets one card in the **This Week** list. The card follows a simple template:
  ```
  Current Deliverable:
  [brief description]

  Deadline:
  [date]

  Next Action:
  [single next step]

  Parking Lot (Later Tasks):
  - item 1
  - item 2
  ```
- The board provides a lightweight visual overview that aligns with the [[concepts/weekly_dashboard]] concept.

## Relationship to other tools and concepts
- Trello is presented as an alternative to **Notion** for the same lightweight tracking purpose. See [[entities/notion]] for the Notion‑based version of the dashboard.
- The board structure supports the **deep work** rhythm by clearly separating focus tasks (in the card’s *Next Action*) from lower‑priority items (the *Parking Lot*).
