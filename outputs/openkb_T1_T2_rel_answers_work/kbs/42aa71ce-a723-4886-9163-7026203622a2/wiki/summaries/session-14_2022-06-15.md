# Summary of Session 14 (2022-06-15)

## Core Weekly Rhythm
- **Deep‑work mornings** (9:00‑12:00) for focused client design work. [[concepts/deep_work]]
- **Afternoon flow** (1:00‑3:00) for revisions, feedback, and small requests.
- **End‑of‑day admin** (3:00‑4:00) for email, invoicing, file organization.
- **Flex/overflow** (4:00‑5:00) for spill‑over tasks.
- **Friday learning hour** (1:00‑2:00) dedicated to skill‑building.

## Weekly Checklist (run Friday afternoon or Monday morning)
- Confirm project priorities & upcoming deadlines.
- Send status updates.
- Archive old files.
- Review finances / invoices.
- Choose a skill to focus on this week.
- Identify one workflow/tool improvement.

## Urgent Request Triage
1. **Does it block someone else’s progress now?**
2. **Does it need my creative/technical input immediately?**
- If *both* answers are yes → treat as **urgent**; otherwise queue for the afternoon. [[concepts/triage_rule]]
- Additional filter: *Will handling it now materially improve outcome or timeline?* 

### Quick Response Script
```
Got this! I’m in a focused work block at the moment, but I’ll review it this afternoon and get back to you. If this is blocking anything urgent on your end, just let me know.
```

## Managing Multiple Projects (3‑5 clients)
- **Rotating primary project** each morning rather than fixed theme days.
- Keep a **secondary project** as a fallback if the primary finishes early.
- Prioritise by deadline, then impact, then creative load. (priority hierarchy)
- When two deadlines are equally close, apply the **30‑second tie‑breaker**: *Which hour of progress today will save the most stress later?* If still tied, pick the more creative‑intensive task. (quick tie‑breaker)

## One‑Page Dashboard (lightweight tracking)

### Trello Layout
- Board with three lists: **This Week**, **Waiting/Feedback**, **Done**. [[entities/trello]]
- Card template (copy‑ready):
  ```
  Current Deliverable:
  [brief description]

  Deadline:
  [date]

  Next Action:
  [single next step]

  Parking Lot (Later Tasks):
  - item 1
  - item 2
  ```
- Example card for *Client A* shown in the conversation.

### Notion Database "Weekly Projects"
- Create a simple table/database. [[entities/notion]]
- Each row includes:
  - **Name** (Title)
  - **Deadline** (Date)
  - **Priority** (Select: High/Medium/Low)
  - **Current Deliverable** (Text)
  - **Next Action** (Text)
