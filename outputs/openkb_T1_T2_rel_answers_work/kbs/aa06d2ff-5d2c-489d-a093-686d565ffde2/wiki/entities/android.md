# Android

Android is a mobile operating system developed by Google, used on a wide range of smartphones.

## Role in the session‑39 discussion
- The document describes how Android devices under **Mobile Device Management** may present restricted icons that can be moved into folders or to the last home‑screen page as part of [[concepts/home-screen-organization]].
- When a Work Profile is available, managed apps appear in a separate section marked with a briefcase badge, keeping personal apps clean.
- If no Work Profile exists, the same folder‑or‑page technique used for iOS can be applied, though Android launchers sometimes allow more flexible hiding of managed icons.
- The presence of a Work Profile can be verified in Settings → Accounts, where a separate profile is listed.

## Management considerations
- Android devices can be enrolled in [[concepts/mobile-device-management]] either device‑wide or with a scoped Work Profile.
- In supervised mode, the MDM may restrict the ability to delete or hide managed apps, but moving them is usually permitted.
- Users often ask the [[entities/it-department]] for a Work Profile or consider a second device to keep personal apps separate.
