## Summary

This document provides a step‑by‑step procedure for cleaning up supervised [[entities/ios]] home‑screen icons placed by [[concepts/mobile-device-management]], discusses why automatic hiding isn’t possible, and compares quick‑move tricks with Android work‑profile options.

### Key concepts
- **Mobile Device Management (MDM)** – [[concepts/mobile-device-management]]
- **Supervised / Managed iOS device** – [[concepts/supervised-mode]]
- **Work Profile (Android)** – plain text (no link)
- **Home‑screen organization** – [[concepts/home-screen-organization]]
- **App Library** – plain text

### iOS clean‑up steps
1. Enter edit mode by long‑pressing any app icon.
2. Create a [[concepts/staging-folder]] (or use an existing one) and drag every gray “restricted” icon into it.
3. While still in edit mode, drag the whole [[concepts/staging-folder]] to the far‑right edge of the screen until it lands on the last home‑screen page.
4. Ensure your personal apps occupy the leftmost page; iOS always treats the leftmost page as the default home screen.
5. (Optional) Move each restricted icon individually to the rightmost page instead of using a [[concepts/staging-folder]].

### Managing new managed apps
- No iOS setting exists to stop newly pushed managed apps from appearing on the first page; they must be moved manually after installation.
- Quick “catch” tip: new apps usually appear on the last page that has free space, so swipe once or twice and drag the icon straight into the work folder/page.

### App Library considerations
- The App Library does **not** prevent supervised apps from showing on active home‑screen pages.
- It can be used to keep personal apps out of sight after you have organized the managed icons, but it won’t block newly deployed icons.

### Android alternatives (brief)
- If a Work Profile is present, managed apps appear in a separate work‑profile section (briefcase badge) and do not clutter the personal side.
- Without a Work Profile, the same folder‑to‑last‑page technique used on iOS can be applied, but Android also offers launchers that may hide managed icons more flexibly.

### Recommended next actions
- Verify the device’s supervision status via **Settings → General → VPN & Device Management**.
- Ask [[entities/it-department]] whether a separate work/personal profile can be enabled (Android Work Profile or iOS Managed Apple ID).
- If not possible, adopt the folder‑to‑last‑page workflow as the standard maintenance routine.
