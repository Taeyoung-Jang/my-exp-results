# Summary of session-09_2024-06-15

## Main idea
A lightweight [[concepts/app-decluttering-process]] for periodically decluttering [[entities/smartphone]] apps by combining a **[[concepts/staging-folder]]** (“Decide Later”) with a simple 0‑4 **[[concepts/app-scoring-rubric]]**.

## Key concepts
- **Staging folder** – move apps whose purpose is unclear into a temporary folder to test need later.  
- **Scoring rubric** – evaluate each app on four criteria: function uniqueness, ease of reinstallation, intended usage pattern, and friction.  
- **Function uniqueness** – points for apps that perform a task no other app on the device can replace.  
- **Friction** – negative points for storage‑heavy or notification‑noisy apps.  
- **Usage vs usefulness** – prioritize the role an app plays rather than raw launch frequency.

## Rubric table

| Criterion                | Points | Description |
|--------------------------|--------|-------------|
| Function uniqueness      | 0‑2    | Higher if the app provides a capability that no other installed app replaces. |
| Ease of reinstallation   | 0‑1    | Higher if data is synced to the cloud and the app can be re‑installed without loss. |
| Intended usage pattern   | 0‑1    | Gives a point for apps designed for occasional use (e.g., travel, creative tools). |
| Friction (storage, notifications) | 0 or ‑1 | Subtract one point if the app consumes a lot of space or generates annoying alerts. |

**Decision thresholds**  
- **Keep** – total score **3–4**  
- **Stage** – total score **1–2**  
- **Delete** – total score **0 or below**

## Example evaluations

| App                            | Function uniqueness | Re‑install ease | Intended use | Friction | Total | Decision |
|--------------------------------|----------------------|------------------|-------------|----------|-------|----------|
| Field recorder                 | 2                    | 0                | 1           | 0        | **3** | Keep |
| Transit app (occasional)      | 1                    | 1                | 1           | 0        | **3** | Keep |
| Password manager               | 2                    | 1                | 1           | 0        | **4** | Keep |
| Redundant photo editor         | 0                    | 1                | 0           | -1       | **0** | Delete |

## Practical takeaways
1. **Check usage history** (last 30‑60 days) to spot dormant apps.  
2. **Stage ambiguous apps** in a “Decide Later” folder and review after 2‑3 weeks.  
3. **Apply the rubric** to each app; keep only those scoring ≥3.  
4. **Re‑install safely** by confirming cloud sync before deletion.  

These steps help maintain a lean, functional app set while protecting niche but valuable tools.
