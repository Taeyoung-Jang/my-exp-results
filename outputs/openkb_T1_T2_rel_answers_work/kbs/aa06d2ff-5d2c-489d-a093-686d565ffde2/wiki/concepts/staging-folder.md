# Staging Folder

**Definition**  
A temporary folder on a smartphone where apps of uncertain value are moved while the user decides whether to keep or delete them.

**Purpose in the app‑decluttering process**
- Provides a low‑risk way to test an app’s necessity without immediate removal.
- Allows the user to observe whether the app is needed over a short period (e.g., 2‑3 weeks).
- Works together with the [[concepts/app-scoring-rubric]]: apps scoring low or ambiguous are placed here before a final decision.

**How it works (from [[summaries/session-09_2024-06-15]])**
1. Review usage history on the [[entities/smartphone]].
2. Identify apps whose purpose cannot be named quickly or that duplicate another app.
3. Move those apps into a folder named “Decide Later” (the staging folder).
4. After the staging period, if the folder is still empty of opened apps, proceed to delete; otherwise, keep the app.

**Benefits**
- Minimises accidental loss of niche but valuable tools.
- Reduces decision fatigue by handling many apps in a batch.
- Complements the broader [[concepts/app-decluttering-process]] by adding a safe “hold” step.

**Typical naming**
Users often label the folder “Decide Later”, “Staging”, or “Hold”.

**Relation to other concepts**
The staging folder is a practical implementation detail of the app‑decluttering workflow and is evaluated using the scoring rubric.
