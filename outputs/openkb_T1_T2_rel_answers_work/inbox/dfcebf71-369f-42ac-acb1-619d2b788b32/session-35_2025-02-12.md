**User:** I’m on an iPhone—could you walk me through exactly how to set up the Focus mode with an “allowed people” list and the repeated-calls thing? Also, how would you set it up so the home aide can always reach me, but the rest of the family gets silenced unless it’s a true emergency?

**Assistant:** On an iPhone, you can set this up with just a few screens, and I’ll keep it simple so you don’t have to dig through menus.

Open Settings, tap Focus, and create a new Focus (you can call it “Caregiving”). Inside that Focus, tap People, then tap “Allow Notifications From.” Add your home aide first so they always get through, then add the doctor and pharmacy if you want them in the same lane. Leave the other family members out for now. When you back out of that screen, there’s a toggle for “Allow Repeated Calls.” Turn that on. That way, if someone you didn’t approve calls twice within three minutes, the second call will break through as an emergency.

If you want the rest of the family silenced except for true emergencies, just keep them off the allowed list. They’ll only get through if they call twice in a row. You can also tap Options inside the Focus and make sure “Silence Notifications” is set to “From silenced people” so it behaves exactly the way you want.

After that, return to the main Focus screen and set a schedule if you want it to turn on automatically in the evenings or overnight. Otherwise, you can toggle it from Control Center by pressing and holding the Focus icon.
